## 1. 게임 파일 규격 (실제 파일 분석 + 게임 확인)

| 항목 | 값 |
|---|---|
| 위치 | Windows **문서** 폴더 아래 `마비노기\그림대화`. OneDrive가 문서 폴더를 옮겼을 수 있으므로 OS에서 문서 경로를 받는다(Qt `QStandardPaths.DocumentsLocation`) |
| 형식 | PNG, 팔레트 방식 **2비트(4색)**. 색 4개는 자유 |
| 크기 | 최대 256×96. 우리 앱은 **256×96 고정**(사용자 결정) |
| 청크 순서 | `IHDR`, `PLTE`(4색), `zTXt authid`, `zTXt author`, `IDAT`, `IEND` (게임 파일과 같게) |
| 서명 | `authid`(숫자 문자열), `author`(캐릭터 이름, **CP949**). 게임은 서명이 올바른 파일만 목록에 보여준다. 가짜 번호(`0`)나 서명 없음은 안 보였다 |
| 파일 이름 | **`chat_YYYYMMDD_HHMMSS_서명이름.png`**. 같은 서명이어도 `애드온서명테스트.png`는 안 보였고 `chat_20261031_130000_잡곡.png`는 보였다. 이름이 겹치면 초 단위를 올려 피한다 |

## 2. 서명 (사칭 방지)

- 서명은 **내가 마지막에 그린 `recentchatimage.png`에서만** 가져온다. 이 파일의 `zTXt authid`, `zTXt author` 청크를 **바이트 그대로** 옮긴다.
- 받은 그림(`chat_…png`)에서는 고를 수 없게 한다. 다른 사람 서명으로 그림을 만드는 것을 막기 위해서다.
- 화면에 `서명 잡곡 · 마지막에 그린 그림대화(recentchatimage.png)에서 가져와요`를 보여준다. 저장 전에 `이 서명으로 저장해요: 잡곡` 확인 창을 띄운다.
- `recentchatimage.png`가 없거나 서명이 없으면 저장 버튼을 끄고 `게임에서 그림대화를 한 번 그리면 서명을 가져올 수 있어요`를 안내한다.
- 앱은 서명을 만들거나 바꾸지 않는다. 숫자를 지어내거나 이름을 고쳐 넣지 않는다.

## 3. 화면: 편의기능 › `그림대화` (계산기 탭들 뒤)

위에서 아래로 배치한다.

1. 제목 `그림대화 만들기`, `?` 도움말, 회색 안내 `흰 캔버스에 바로 그리거나 이미지를 불러와 다듬은 뒤, 게임의 그림대화 목록에 넣어요.`
2. **도구 줄**: `펜 · 지우개 · 채우기 · 직선 · 네모 · 스포이드`(하나만 선택), `굵기 1 · 2 · 4 · 8`. 도구 구성은 써 보고 조정한다(사용자).
3. **캔버스**: 256×96을 약 3배로 확대해 표시한다. 마우스 휠로 확대·축소하고, 커서 위치에 펜 크기 원을 미리 보여준다.
   - 아래에 회색 `256 × 96 · 3배로 크게 보는 중`을 표시하고, 오른쪽에 **실제 크기** 미리보기를 둔다.
4. **색 4칸** 1~4와 `색 묶음`(흑백 / 자동 / 선명 / 직접 고르기).
   - 칸을 두 번 누르면 색을 고르는 창이 열린다. 칸 색을 바꾸면 그 칸으로 그린 곳이 한꺼번에 바뀐다.
   - 회색 안내: `칸을 두 번 누르면 색을 바꿀 수 있어요. 바꾸면 그 색으로 그린 곳이 한꺼번에 바뀌어요.`
5. **편집 줄**: `되돌리기 · 다시 하기 · 전체 지우기`(Ctrl+Z / Ctrl+Y), 오른쪽에 `이미지 불러오기…`
6. **`게임에 넣기`** 상자: 서명, 저장 위치(`문서\마비노기\그림대화`, 바꿀 수 있음), `그림대화로 저장`(강조 버튼), 회색 `저장한 그림은 게임의 그림 대화 이미지 보기에 서명 이름으로 나타나요.`

- 기본 4색은 흑백 `#000000 #808080 #C0C0C0 #FFFFFF`(게임 기본과 같음). 캔버스는 흰색(4번 칸)으로 시작한다.
- 펜 필압은 넣지 않는다(사용자). 펜 태블릿은 마우스처럼 동작한다.

## 4. 이미지 불러오기

- 불러오는 방법: 파일 선택, 캔버스에 끌어 놓기, 붙여넣기(Ctrl+V).
- 불러오면 작은 창에서 다음 순서로 진행한다.
  1. **256×96 비율 박스로 자르기**: 박스를 옮기고 휠로 확대한다.
  2. **밝기·대비**
  3. **4색 정하기**: 흑백 / 자동(많이 쓰인 색) / 선명(서로 다른 색 우선) / 직접
  4. **점묘** 켜기·끄기
  5. 결과를 실제 크기와 확대본으로 미리보기
  6. `캔버스에 넣기` → 캔버스를 덮어쓰며, 되돌리기로 이전 상태에 돌아갈 수 있다.
- 컬러 이미지는 "4색 포스터" 느낌까지만 나온다. 도움말에 "색이 적은 그림(선화·이모티콘)이 잘 나와요"를 적는다.

## 5. 구현 원칙

- 캔버스는 **픽셀마다 0~3(색 칸 번호)** 배열로 들고, 화면 표시만 4색으로 칠한다. 흐림 처리를 하지 않으므로 저장 시 변환이 필요 없다.
- 채우기는 OpenCV `floodFill`, 점묘·색 줄이기는 numpy·OpenCV로 처리한다. Python 픽셀 반복문 금지 규칙을 지킨다.
  - 오차 확산 점묘를 벡터화하기 어려우면 격자 점묘로 대체해도 된다. 이 경우 결과 비교 렌더를 사용자에게 확인받는다.
- 되돌리기는 획 단위 사본(1장 24KB)으로 하고, 최대 100단계까지 기억한다.
- PNG 2비트 쓰기는 직접 만든다(OpenCV는 2비트 팔레트 쓰기를 지원하지 않는다). 청크 순서는 1절 표를 따른다.
- 파일 형식·서명 처리는 Qt와 무관한 순수 함수로 두고 맥에서 테스트한다. 게임 화면·입력·메모리와는 무관하다.
- 문서 폴더 경로 찾기는 Qt(`QStandardPaths`)를 쓰므로 `system/`에 두지 않아도 된다. 다만 Windows 실경로는 Windows에서 확인한다.

## 6. 검증

- **단위 테스트**
  - 저장 파일의 크기·비트 깊이·팔레트 4색·청크 순서가 게임 파일과 같은지
  - 서명 청크가 `recentchatimage.png`와 바이트 단위로 같은지
  - 파일 이름 규칙과 이름 겹침 처리
  - 서명이 없을 때 저장 버튼이 꺼지는지
  - 받은 그림은 서명 원본으로 고를 수 없는지
  - 채우기, 되돌리기, 칸 색 바꾸기
- **렌더**: 그림대화 탭(빈 캔버스 / 그린 상태 / 서명 없음)과 불러오기 창을 사용자에게 확인받는다.
- **게임 확인(사용자)**: 저장한 그림이 `그림 대화 이미지 보기`에 서명 이름으로 나타나고, 보내기까지 되는지 확인한다.
