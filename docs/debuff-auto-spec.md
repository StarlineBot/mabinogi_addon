# 디버프 보스 확인 자동 통합

- 확정 기준: 2026-10-16 사용자 요청. 보스바 없음/불확실 시 기존 1차 감시 유지,
  보스패턴알림 OFF에서도 독립 동작한다.
- 기반: [통합 검토](qa/디버프_보스확인방식_통합검토.md).
- 일반 화면의 자동 상태 + 톱니 버튼으로 펼치는 진단 선택 배치는 제품 렌더로 표시했고,
  사용자가 "현재 배치로 진행"으로 승인했다.
- 기존 숨김/재구성 수정은 별도 QA `19b6d75`에서 실제 제품 경로와 Windows 검증 통과가
  확인됐다. 이번 자동 통합의 검증과 혼동하지 않는다.

## 동작

- 일반 화면의 기본은 자동이다. 아이콘 검색은 기존 한 경로를 그대로 사용한다.
  체력바 모양/퍼센트는 아이콘 종류를 식별하는 대신 보스 존재/부재의 보조 근거로만 쓴다.
- HP 영역 미등록, 최초에 보스 증거가 없음, 캡처 실패, 검은 바, 숫자 판독 불가,
  범위 밖 숫자 및 소스 간 충돌은 부재 확정이 아니다. 기존 아이콘 감지/해제/재표시는
  계속하며, 무기한 직전 적용 상태를 고정한다는 의미가 아니다.
- 디버프 ROI에서 정상 체력바를 확인한 이력이 있으면 그 영역의 확실한 배경을 부재
  근거로 사용할 수 있다. 별도 HP ROI는 유효한 0~100 퍼센트를 확인한 뒤에만 배경을
  부재 근거로 사용한다. 미검증 영역의 배경만으로 보스 부재를 확정하지 않는다.
- 현재 아이콘/체력바/숫자 중 존재 근거가 있거나, 검증한 소스 중 하나라도 불명이면
  전체 미적용 리셋을 하지 않는다. 검증한 근거가 모두 부재인 상태가 기존 1초 유예 동안
  이어질 때만 보스 부재 리셋을 수행한다. 충돌/불명/존재가 나오면 유예를 취소한다.
- 자동 판단 중 엔진/워커/소스를 반복 재생성하거나 모드를 교대로 바꾸지 않는다.
  사용자의 영역/진단 방식/추적 구성 변경에는 기존 재구성 절차를 사용한다.
- 사라짐 경고의 포그라운드 제한, 검출 확인, 재표시 시간과 프라가라흐 식별/숨김 정책은
  유지한다. 보스 이름이나 패턴 지원 목록을 필수 조건으로 삼지 않는다.

## 캡처와 성능

- 보스패턴알림 활성화 여부를 조회해서 디버프를 막지 않는다. 공유하는 것은 HP 영역
  좌표뿐이다. 자동 모드의 디버프 워커는 등록된 영역의 별도 소스를 직접 소유한다.
- 별도 영역이 없으면 주 아이콘 캡처만 사용한다. 보조 캡처 예외가 발생해도 해당 틱의
  주 아이콘 프레임은 계속 처리하며 이후 보조 캡처가 복구될 수 있다.
- 아이콘 검색은 한 틱당 항목별 한 번이며, 부재/충돌 확인은 같은 결과를 재사용한다.
- 자동 모드 보조 캡처는 0.6초 간격이며 캐시 수명도 최대 해당 간격이다. 영역 재구성은
  새 워커로 캐시를 폐기한다. 과거 강제 방식의 캡처 주기는 변경하지 않는다.
- 숫자 판독도 최대 0.6초 간격이다. 현재 ROI의 체력바만으로 존재가 확인되면 추가 숫자
  판독을 생략한다. 새 타이머/스레드를 추가하지 않는다.
- 보조 캡처 예외는 연속 실패 중 한 번만 기록한다. 실제 판단 근거와 호환 이유는
  엔진 `gate_diagnostics`, 자동 상태의 툴팁, 변경 시 DEBUG 로그에 남긴다.
  기존 로그 링버퍼와 파일 회전 보관을 사용하며 별도 무제한 로그를 만들지 않는다.

## 설정과 UI

- `general.debuffAutoGate`가 없거나 유효한 false가 아니면 자동이다. 초기 화면에서
  설정을 자동 저장하거나 기존 영역/순서/숨김/아이콘/과거 모드 값을 덮어쓰지 않는다.
- 기존 `debuffGateMode=off/band/percent`와 `debuffBarGating`은 그대로 읽는다.
  일반 사용은 자동으로 옮기되 과거 값 자체는 보존한다.
- 진단에서 이전 방식을 명시적으로 선택하면 `debuffAutoGate=false`와 해당 과거 방식을
  저장한다. 다시 자동을 선택하면 flag만 true로 바꾸어 과거 방식 기록은 유지한다.
- 자동 모드는 로그인/보스패턴 기능에 의존하지 않는다. 과거 강제 band/percent의 로그인
  제한과 미로그인 시 off 적용은 기존 진단 호환 동작으로 남긴다.
- 톱니 버튼은 진단 행을 펼칠 뿐 설정 저장이나 추적 재시작을 하지 않는다. 실제로
  방식을 변경하거나 좌표가 달라졌을 때만 기존 변경 신호를 보낸다.

- 보스패턴 기능 OFF 상태에서 공유 HP 영역 유무에 따른 실제 시작 코드의 소스 연결을
  검증했다. 캡처/컨트롤러는 대체하되 실제 엔진·설정·시작 코드를 실행했다.
- 체력바 없음, 미검증 배경, 불명/오류/NaN/범위 밖 숫자, 유효한 0%, 소스 충돌,
  부재 유예/재등장, 단일 검색 횟수, 상태 크기 유지, 보조 캡처 실패/0.6초 복구를 검사한다.
- 기존 설정을 한글/공백 경로에 저장해 값 보존과 자동/진단 왕복을 확인했다.
- 실제 게임/Windows 혼합 DPI/장시간 CPU·메모리 실측은 하지 않았다. 정확한 푸시 SHA의
  Windows 회귀·네이티브·exe 성공을 별도로 확인해야 한다. 릴리즈/태그는 진행하지 않는다.
- 최종 전체 격리 회귀 **956 passed, 4 deselected, 3 warnings (187.19초)**.
  제외는 별도 Windows 네이티브 4개, 경고는 기존 QMouseEvent API다.
