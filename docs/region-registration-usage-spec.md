# 영역 등록 기반 사용 및 지정 해제 명세

- 확정일: 2026-10-18
- 상태: 기획 확정. 개발 및 독립 QA 전달용.
- 목적: 영역을 지정했는데 별도 사용 체크 때문에 동작하지 않는 혼란을 없애고, 등록과 해제로 기능 사용을 관리한다.
- 범위: 자동설정 도입 과정에서 추가된 영역 기반 기능 전체의 사용 체크, 첫 사용 안내의 대상 선택, 개별 판독 영역 해제.
- 우선순위: 이 범위에서는 이 문서가 기존 자동설정 및 공통 조작 명세의 사용 체크 공유/보존 정책에 우선한다.
  나머지 기능 동작과 [공통 조작 기준](app-interaction-consistency-review.md)은 유지한다.
- 2026-10-18 후속 확정: 도르카·투아림의 공통 설정과 두 영역을 함께 해제하는 명령은
  [설정 화면 그룹화 및 공통 영역 설정](settings-grouping-common-resource-spec.md)을 따른다.
  개별 조정에서 한쪽만 해제하는 동작과 세부 옵션 보존은 유지한다.

## 1. 기본 원칙

- 영역 등록이 해당 영역을 사용하는 동작의 사용 조건이 된다. 별도 기능 전체 사용 체크나 ON/OFF 버튼을 요구하지 않는다.
- 등록 완료 후 게임 활성 상태, 전체 일시정지, 접근 권한, 세부 표시/알림 옵션 등 기존 조건에 따라 작동한다.
- 영역이 있다는 것과 현재 정상 판독된다는 것은 다르다. 등록만으로 정상 작동/판독 성공을 표시하지 않는다.
- 등록을 유지한 채 잠시 전체 기능을 중단하려면 기존 앱 상단 전체 일시정지/재개를 사용한다.
- 특정 영역을 더 이상 사용하지 않으려면 지정 해제를 한다. 다시 사용하려면 재지정한다.

## 2. 변경 및 보존 범위

### 제거할 항목

- 자동설정 도입으로 추가된 영역 기반 기능 전체의 사용 체크와 그에 해당하는 실행 차단 조건.
- 첫 사용 안내의 대상 체크를 기능의 영구 ON/OFF에 연결하는 동작.
- 같은 역할을 하는 새 기능별 ON/OFF 토글 또는 개별 일시정지 장치.

### 유지할 항목

- 도르카 표시, 투아림 % 표시, 투아림 알림 등 서로 다른 결과의 독립 선택.
- 소리, 아이콘별 표시, 지속시간 표시, 알림 기준, 위치 잠금 등 세부 옵션.
- 원본 판독 영역을 사용하지 않는 기능의 기존 동작과 설정. 파티 모집/계산기/메모 등에 이 규칙을 일괄 적용하지 않는다.
- 커스텀 오버레이의 개별 항목 삭제/프리셋 저장은 기존 독립 명세를 따른다. 지정 해제를 전체 프리셋 삭제로 해석하지 않는다.
- 기존 게임 전면 표시, 클릭 통과, 전체 일시정지, 일반/베타 접근 조건과 판독·알림 정책.

## 3. 첫 사용 안내 및 자동설정

- 체크는 이번 자동설정에 포함할 대상의 선택이다. 체크/해제만으로 기존 기능의 실행 상태나 영역을 바꾸지 않는다.
- 안내는 '설정할 기능을 선택하세요'처럼 설정 대상 선택임이 드러나야 한다.
- 체크하지 않은 기능에도 이미 영역이 있으면 기존 조건에 따라 작동한다.
- 선택된 대상 중 미등록 영역을 기존 방식으로 찾는다. 이미 등록된 영역은 기존 정책대로 건너뛴다.
- 후보 검색 성공만으로 등록하지 않는다. 사용자 승인 후 저장된 영역부터 사용한다.
- 후보 거절/찾기 실패/취소는 기존 영역이나 세부 설정을 지우지 않는다.
- 선택했지만 영역을 등록하지 못한 항목은 '영역 지정 필요' 등으로 표시한다.
  선택하지 않은 항목을 '사용 안 함'으로 표현하지 않는다. 설정 대상 선택과 실제 등록 상태를 구분한다.
- 자동설정의 대상 선택이 기존 표시/알림 세부 옵션을 임의로 켜거나 끄지 않는다.
- 안내 종료/다음 단계 이동은 모든 영역의 등록 성공을 요구하지 않는다.

## 4. 개별 화면과 지정 해제

### 영역 등록

- 직접 지정 완료 또는 자동찾기 후보 승인으로 영역이 저장되면 추가 사용 체크 없이 동작 조건을 갖춘다.
- 지정 취소나 저장 실패 시 기존 영역을 유지하고 새 영역 등록 성공으로 표시하지 않는다.
- 영역이 없으면 '영역 지정 필요'를 안내한다. 영역이 없어도 가능한 표시 예시/세부 설정 편집은 유지한다.

### 지정 해제

- 명령 이름은 '지정 해제'로 한다. 전체 설정 초기화와 구분한다.
- 해당 판독 영역의 보조 명령으로 배치한다. 정확한 폭과 위치는 기존 영역 조작과 함께 렌더로 확인한다.
- 해제 대상과 영향을 안내한 후 확인을 받는다. 취소하면 아무것도 바꾸지 않는다.
- 승인하면 해당 영역 정보를 삭제하고 저장한다. 그 영역이 필요한 판독·표시·알림을 중단한다.
- 배율, 표시 위치, 잠금, 등록 아이콘 목록, 소리 선택, 알림 체크/기준 등 세부 설정은 삭제하거나 초기화하지 않는다.
- 이전 판독값/진행 중 작업의 늦은 결과 때문에 해제한 동작이 다시 표시되거나 알림이 발생하지 않아야 한다.
- 해제 상태는 재실행 후에도 유지하며, 자동으로 옛 영역을 복원하지 않는다.
- 해제 저장에 실패하면 성공으로 표시하지 않는다. 실제 저장 상태와 화면 상태가 어긋난 채 완료 처리하지 않는다.

### 공유 영역

- 하나의 영역을 여러 기능이 공유하면 해제는 해당 공유 영역 전체에 적용된다.
- 확인창에 최신 설정 기준으로 영향을 받는 기능/동작을 명시한다. 특정 탭만 꺼지는 것으로 안내하지 않는다.
- 해당 영역에 의존하는 동작만 중단한다. 다른 영역을 사용하는 독립 동작은 유지한다.
  예를 들어 공유 보스 영역 해제로 보스 관련 경고가 중단되더라도, 별도 자원 영역을 읽는 표시는 유지한다.
- 두 독립 영역 중 하나의 해제는 다른 영역을 삭제하지 않는다. 도르카와 투아림도 같은 기준을 따른다.

## 5. 상태 및 예외 흐름

| 상태/조작 | 기대 동작 |
|---|---|
| 미등록 | 해당 영역 의존 동작은 실행하지 않고 영역 지정이 필요함을 안내한다. |
| 등록 완료 | 별도 기능 전체 사용 체크 없이 기존 실행 조건에 따라 판독·표시·알림을 수행한다. |
| 등록됐지만 현재 판독 불가 | 기존 실패 정책을 유지한다. 영역을 자동 삭제하거나 실제 0으로 취급하지 않는다. |
| 전체 일시정지 | 등록 영역/세부 설정을 보존하고 기존 일시정지 범위를 따른다. 등록 중에도 자동 재개하지 않는다. |
| 전체 재개 | 영역이 남은 동작만 기존 조건에 따라 재개한다. 해제된 영역은 되살리지 않는다. |
| 지정 해제 승인 | 해당 영역 의존 동작을 중단하고 세부 설정은 유지한다. |
| 재지정 | 저장된 세부 설정을 다시 사용한다. 표시/알림 옵션이 꺼져 있었다면 임의로 켜지 않는다. |
| 빠른 지정/해제 반복 | 마지막으로 완료된 사용자 조작을 반영하고 이전 작업 결과로 되돌리지 않는다. |
| 게임 종료/가림/포커스 변경 | 기존 생명주기 정책을 유지하며 일시적 판독 불가를 지정 해제로 간주하지 않는다. |

영역이 없으면 알림 옵션이 체크되어 있어도 그 영역에 의존하는 알림은 발생하지 않는다.
영역 유무를 확인하는 것과 판독 실패 처리의 기존 정책을 혼동하지 않는다.

## 6. 기존 설정 처리

- 기존 사용자의 별도 전환 안내/선택창은 추가하지 않는다.
- 제거 대상인 기능 전체 사용 값이 OFF였다는 이유만으로 등록 영역의 동작을 계속 차단하지 않는다.
  영역이 있으면 이 명세와 기존 세부 옵션/접근 조건에 따라 동작한다.
- 기존 영역 및 세부 설정을 일괄 삭제하거나 재등록시키지 않는다.
- 유지 대상인 표시/알림/소리 옵션의 OFF까지 해제하거나 ON으로 바꾸지 않는다.

## 7. Acceptance Criteria

| ID | 검증 기준 |
|---|---|
| REG-01 | 적용 대상 화면에서 별도 기능 전체 사용 체크/토글 없이 영역을 등록하면, 전체 일시정지 해제 및 기존 실행 조건 충족 시 해당 동작이 시작된다. |
| REG-02 | 첫 사용 안내에서 대상을 체크하거나 해제하는 것만으로 기존 영역/세부 옵션/실행 상태가 변경되지 않는다. |
| REG-03 | 자동찾기 후보를 승인하지 않으면 기존 영역이 바뀌지 않는다. 승인 후에는 추가 사용 체크 없이 저장된 영역을 사용한다. |
| REG-04 | 지정 해제 확인을 취소하면 영역과 동작이 유지된다. 승인하면 해당 영역을 삭제하고 관련 판독·표시·알림을 중단한다. |
| REG-05 | 알림 옵션이 체크된 채 지정 해제해도 이전 판독값이나 늦은 작업 결과로 추가 알림/표시가 발생하지 않는다. |
| REG-06 | 해제 후 재실행해도 영역이 미등록 상태이며, 재지정하면 기존 위치/배율/아이콘/알림 기준을 유지한 채 동작한다. |
| REG-07 | 공유 영역 해제 확인에 영향받는 동작이 표시되며 승인 후 해당 동작은 모두 중단된다. 별도 영역을 사용하는 동작은 계속 유지된다. |
| REG-08 | 도르카 또는 투아림 영역 하나만 해제해도 다른 영역과 독립 동작은 유지된다. 표시/알림 세부 옵션은 해제 전 값이 보존된다. |
| REG-09 | 전체 일시정지 중 등록하더라도 임의 재개하지 않는다. 전체 재개 시 해제된 영역을 복원하지 않는다. |
| REG-10 | 제거 대상의 기존 전체 사용 값이 OFF이고 영역이 있는 설정에서도, 별도 전환창이나 숨은 사용 차단 없이 새 동작 기준을 따른다. 유지 대상인 세부 OFF 옵션은 보존된다. |
| REG-11 | 등록/해제 저장 실패를 성공으로 표시하지 않는다. 취소/실패 또는 일시적 판독 실패가 기존 영역을 임의 삭제하지 않는다. |
| REG-12 | 첫 사용 안내/투어/개별 화면 문구가 설정 대상 선택과 등록 상태를 구분하며, 제거한 사용 체크를 누르도록 안내하지 않는다. |

## 8. 개발 및 QA 인계

- 앱 구현은 이 문서 작성에 포함하지 않는다. 구현 시 최신 화면의 제거 대상 전체 사용 체크와 유지할 세부 옵션을 구분해 대조한다.
- 기존 안내/자동설정/개별 실행 조건/백업 복원에 남은 전체 사용 값 연결도 함께 점검한다.
- '지정 해제'와 공유 영역 확인창을 포함한 화면은 렌더하여 사용자에게 배치를 확인받는다.
- 화면/DPI/전체 일시정지/게임 전환/동시 작업 및 저장 실패 검증은 개발과 독립 QA에서 수행한다.
  이 문서의 기획 확정은 구현 또는 실행 검증 완료를 뜻하지 않는다.
