# Windows 시험 후보 0.5.2 준비

- 준비일: 2026-10-19. 원격 main의 독립 QA 자료까지 받은 상태에서 준비했다.
- 소스/공개 릴리즈 저장소 양쪽에 v0.5.2 태그가 없음을 확인했다. 버전 예약이나 태그 생성은 아니다.
- 기존 v0.5.1 이하 노트를 바이트 단위로 보존하고, 새 사용자 기능/설정 변경이 없다는 v0.5.2 노트를 추가했다.
- 계산기 출시 안내 검사는 실제 출시 버전 0.5.1의 신규/업데이트와 0.5.2로의 업데이트를 검사하도록 수정했다.
  최신 첫 실행에는 과거 출시 안내를 반복하지 않는 반대 조건도 추가했다. 원래 문구 assertion은 유지했다.
- 노트/표시/후보/Unicode 관련 검사: 90 passed (10.97초). 로컬 preflight 0.5.2도 통과했다.
- 앱의 개발용 version.py는 변경하지 않았다. Windows 후보 빌드가 명시한 0.5.2를 주입한다.
- Windows 테스트/네이티브/실제 exe 빌드와 산출물 보관은 아직 실행하지 않았다.
- 태그, Release, 공개 업데이트 정보, 공지는 생성/변경하지 않았다.

사용자가 Windows 검증만 시험할 때:

```bash
gh workflow run windows.yml --ref main -f version=0.5.2
```

위 명령은 검증/후보 보관만 수행한다. 공개 배포 승인은 아니며 release.yml은 실행하지 않는다.
실행 시점에 태그가 새로 사용되었다면 다른 미사용 버전/노트를 준비해야 한다.
