## 사용자 아이디어

앱에서 현재 민트로 표시되는 강조색을 사용자가 원하는 색으로 바꿀 수 있도록 한다. 민트를 바꿀 수 없는 고정색으로 유지하자는 의미가 아니며 변경 전 초기 색상이 민트라는 뜻이다.

## 다음 논의의 출발점

- 색상 선택기로 원하는 강조색을 선택하고, 적용 대상인 민트색 요소에 일관되게 반영하는 방향.
- 배경·일반 글자와 오류·경고의 의미색을 바꾸는 전체 테마 편집과는 구분.
- 선택한 강조색과 버튼 글자 등의 가독성 확보, 기본 민트로 복원하는 방식 검토.
- Discord 로그인 혜택으로 제공하는 방안 검토. 로그인 필수 여부와 로그인 해제·오프라인 시 동작은 아직 확정하지 않음.
- 정확한 적용 요소, 저장 범위, 미리보기·적용 동작과 검증 기준은 후속 기획에서 확정.

이 문서는 아이디어를 잊지 않도록 남긴 기록이다. 위 검토 방향을 확정된 동작이나 이번 배포 약속으로 취급하지 않는다.
