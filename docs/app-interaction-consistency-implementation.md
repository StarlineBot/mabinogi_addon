# 조작 일관성 및 커스텀 자동 저장 개발 기록

- 기준: [확정 명세](app-interaction-consistency-review.md). 실제 Qt 목업 5종을 확인한 뒤
  사용자가 `진행`으로 승인한 배치를 구현했다. 개발 검증이며 독립 QA 판정은 아니다.
- 기존 2단 가로 탭, 창 크기, 버프/디버프 좌우 편집, 저장된 영역/위치/배율/사용 체크를 유지한다.

## 화면과 기존 기능

- 도르카·투아림: 판독 영역 → 원본 미리보기/현재 값 → 표시·배치 → 알림 → 접힌 진단 순서.
  세 사용 체크와 접근 조건은 독립이다. 투아림 알림은 일반 기능으로 유지한다.
  도르카 원본 미리보기는 실제 판독에 쓴 같은 프레임으로 갱신하며 별도 캡처를 추가하지 않는다.
  투아림의 최근 확정값과 순간 관측값의 구분, 불확실/100% 안전 보류를 유지한다.
- 체력바: 같은 순서에 원본/표시 미리보기를 구분한다. 표시 예시는 실제 StatBarOverlay의
  그리기를 재사용하는 자식 위젯이며 독립 HWND/드래그/클릭 통과/흔들림을 실행하지 않는다.
  새 캡처 타이머 없이 기존 판독값을 받는다. 미관측은 `--%`로 표시하며 0%로 표현하지 않는다.
  실제 출력 바의 독립 표시와 보스전 저값 경고/흔들림/소리는 기존대로다.
  보스 영역 등록 상태는 최초 로드와 기존 변경 신호에서 갱신하며 새 파일 polling을 추가하지 않는다.
- 버프/디버프: 왼쪽 상단의 영역 명령과 잠금/배율을 정리하고 좌우 항목 편집을 유지한다.
  보스 경고/목록 잠금은 각각 실제 상태를 나타내는 토글로 구분한다. 단축바의 12그룹/빈 슬롯,
  원본 첫 칸과 출력 배율의 의미는 바꾸지 않는다. 메모는 판독 영역이 아닌 표시 위치/너비 지정이다.
- 파티 모집/구슬 계산/설정에는 판독 UI나 별도 저장 버튼을 억지로 추가하지 않는다.
  파티의 서버/알림/제외 구분, 구슬 로컬 즉시 계산, 설정 가져오기/초기화 확인과 재시작 경로는 유지한다.
- 분배 계산은 명시 계산/Enter만 조회한다. 결과 이후 입력이 달라지면 이전 결과로 표시하며
  요청 ID로 역순 응답이 최신 계산을 덮어쓰지 못하게 한다. 환전 조회 실패는 조회 중과 구분한다.
- 첫 사용 안내/투어가 참조하는 기존 컨트롤과 개별 이동 키를 유지한다. 투아림 진입은 통합 탭의
  알림 기준으로 이동하며 체력바 경로는 독립이다. 투어로 사용 설정이 바뀌지 않는 기존 검사를 유지한다.

## 커스텀 저장과 실패 복구

- 적용 중 이름, 프리셋 목록 선택, 시작 자동 불러오기 콤보는 별도 상태다. 선택만으로 저장 대상은 바뀌지 않는다.
- 추가/삭제/이동/배율/잠금의 완료 신호를 300ms 단일 재시작 타이머로 묶는다. 캡처 프레임마다 저장하지 않는다.
  전환/삭제/정상 종료 전에 대기를 flush한다. 숨김/일시정지는 구성 삭제로 처리하지 않는다.
- 현재 구성과 명시적 적용 프리셋을 하나의 설정 교체로 저장한다. 다른 이름으로 저장도 원본의 최신 구성과
  새 대상을 함께 저장한 뒤에만 편집 대상을 변경한다. 이름 입력/덮어쓰기 취소 시 대상을 유지한다.
- 프리셋을 로드하는 clear/add 중간 신호는 저장에서 제외한다. 로드/저장 실패 시 이전 화면 구성과 대상을
  복구한다. 빈 구성도 정상 저장/불러오기 대상이다. 시작 자동 불러오기 정책은 기존대로 명시 지정만 따른다.
- 저장 실패는 인라인 상태/재시도로 알린다. 편집 내용과 마지막 정상 파일을 유지하며 자동 무한 재시도하지 않는다.
  메인 창은 다른 저장/워커 종료보다 먼저 확인하고 실패하면 종료를 취소해 커스텀 탭을 보여준다.
- 삭제 전에 예약 저장을 정리하고 적용 대상 삭제 시 연결을 해제한다. 이후 편집으로 삭제 프리셋이 재생성되지 않는다.
  기존 데이터에 활성 대상이 없으면 이름/선택/내용 비교로 추정하지 않는다.
- 설정 writer는 본 파일을 백업으로 먼저 이동하지 않고 복사본을 교체한다. 최종 replace가 실패해도
  정상 본 파일이 남으며, 임시 JSON의 flush/fsync와 원자적 교체 및 백업 복구는 유지한다.
