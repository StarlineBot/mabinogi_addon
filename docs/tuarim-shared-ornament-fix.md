# 투아림 자동찾기 축소 후보 누락 수정

- 날짜: 2026-10-17 (Asia/Seoul).
- 근거: `docs/qa/투아림_자동찾기_축소후보누락_QA_20261017.md` (P2 TUARIM-COARSE-QA-01).
- 수정 전 원본 QA 재현 **1 failed, 9 passed (5.27초)**를 직접 확인했다.
  전체 원본만 실패하고 같은 UI의 주변 영역 및 1픽셀 이동 입력은 성공했다.
- QA 원본 보고서/재현/이미지/임계값은 변경하지 않았다.

## 원인과 수정

전체 화면을 0.5배 축소한 상위 배경 3개가 정밀 확인에서 모두 탈락한 뒤,
그 아래에 있던 참 장식을 다시 확인하지 않았다. 원본 참 위치는 0.9884로 합격 기준을 넘었다.

- 도르카의 장식 탐색을 `detect/resource_anchor.py`로 분리해 투아림과 공유한다.
  장식의 원점/배율과 후보를 반환하며 숫자 리더·설정·기능 ON/OFF는 참조하지 않는다.
- 기존 투아림 전체 구조 후보를 유지하면서 공용 원형 장식 후보도 확인한다.
  공용 탐색의 축소 후보가 없으면 원본 해상도 대체 탐색을 사용한다. 같은 위치의 표본 중복은
  합치며 다른 실제 위치가 여러 개면 임의 선택하지 않는다.
- 도르카는 공용 장식에서 `(8,17,28,23)`의 숫자를 읽는다. 기존 0~15 참조/확정 기준과
  미판독/재탐색/종료 정책은 그대로다.
- 투아림은 원점/배율에서 `(34,45,42,16)`을 계산한다. 오른쪽 버튼 구조를 원본 BGR로
  별도 검증하고 화면 밖으로 잘린 % 영역은 거절한다. 이미 다른 장식 표본으로 확인한 원형을
  예전 원형 표본만으로 다시 거절하지 않는다. 후보 기록에 원형/오른쪽 구조 점수를 구분한다.
- 공용 합격 기준 0.97, 지원 배율, 단축바 탐색은 변경하지 않았다. 상위 후보 제한을 무작정
  확대하거나 전역 임계값을 낮추지 않았다.
- 도르카 숫자 가림/참조 누락/기능 OFF와 무관하게 투아림 위치를 찾는다. 투아림 리더도
  위치 확인의 필수 조건이 아니다. 한 자리·두 자리 판독 및 100%의 안전 보류 계약은 유지한다.
- 투아림 상시 추종/주기 재탐색은 추가하지 않았다. 기존 승인/취소 흐름과 알림 설정·발화 이력도 유지한다.

## 진단 호환

- 새 투아림 ZIP에는 원래 `anchor`, `mask` 및 `circle_anchor`, `circle_mask`,
  `circle_anchor_alt`를 저장한다. 도르카 숫자 참조를 투아림 ZIP에 요구하지 않는다.
- 과거의 두 자산만 있는 ZIP도 저장된 전체 장식에서 원형을 만들 수 있다.
  ZIP 재실행은 설치된 공용 모델/도르카 숫자 자료가 없어도 저장된 PNG만 사용한다.
- 모델/원본 입력 픽셀 불변성을 검사한다. 기존 ZIP의 2개 자산 검사도 새 5개 구성을 정확하게
  검증하도록 갱신했다. 파일 검사를 삭제하거나 단순 포함 여부로 약화하지 않았다.
