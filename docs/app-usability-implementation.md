# 사용 준비 화면 개발 기록

- 기준: `docs/app-usability-spec.md`, 2026-10-15 개발 세션의 사용자 렌더 피드백.
- 개발 검증이며 독립 QA, Windows 실게임·DPI·장시간 검증 완료가 아니다.
- 새 기능의 main 푸시는 검증 후 사용자 확인을 받는다. 릴리즈·태그는 실행하지 않는다.

## 반영 범위

- 상위 탭은 기존 네 개를 유지한다. 스택으로 사용 준비 화면을 열고, 설정의 '자동설정 다시 열기'로 재진입한다. 화면을 열기만 해서는 탐색·기능 사용 여부·전체 일시정지를 변경하지 않는다.
- 게임창 등록 우선 배치, 제목 아래 순서 안내, 네 항목 높이의 세로 기능 목록, 목록 아래 전체 너비 자동설정 버튼. 설정 필요/등록된 설정/사용 안 함도 각각 독립 스크롤 박스다.
- 미등록 필수 설정이 있으면 준비 화면, 모두 등록되었거나 `general.skipSetup`이 true이면 기존 트래커 > 버프로 시작한다. 현재 화면에 보스가 없는 것을 미등록으로 취급하지 않는다.
- `general.setupOrder`에 체크 순서를 기록한다. 기존 설정에 순서가 없으면 기존 기능 순서로 해석한다. 등록된 항목은 건너뛰고, 체크를 해제하면 실행 대상에서 제외한다.
- 버프·디버프·커스텀 오버레이에 기능 전체 사용 체크를 추가했다. 기존 사용자에게는 기본 true이며 개별 아이콘·알림·프리셋·잠금과 별개다. 다른 기능은 기존 사용 체크를 재사용하고 양방향으로 동기화한다.
- 자동설정은 Discord 로그인 및 게임창 등록 후 실행한다. 등록된 게임창을 캡처하지 못하면 데스크톱 전체로 대체하지 않고 중단한다. 개별 탭의 기존 캡처 폴백 정책은 바꾸지 않는다.
- 검출만 한 개의 데몬 워커에서 실행한다. 캡처·Qt·설정 저장은 UI 스레드에서 수행한다. 취소·종료 후 늦은 결과는 버리고, 종료 중 숨긴 창을 다시 표시하지 않는다.
- 내부 후보 패널 없이 기존 화면 위 확인 방식을 사용한다. 버프는 목록 위 경계 조절, 나머지는 민트 점선과 승인/거절 창이다. 승인 뒤 목록을 갱신하고 다음 체크 항목으로 진행한다.
- 보스바와 디버프 영역을 별도 승인한다. 한쪽 승인으로 이미 등록된 다른 쪽을 덮어쓰지 않는다. 디버프 % 확인 또는 체력바 저값 경고의 공유 보스바 의존성은 미등록 대상에 포함한다.
- 단축바는 기존 1168x89 논리 격자와 그룹별 셀 복제를 유지한다. 미지원 크기는 등록하지 않는다. 메모·커스텀 오버레이는 자동찾기 대상에서 제외하고 개별 설정으로 연결한다.
- 자동찾기의 실제 원본·결과·승인 정보는 기존 실행별 진단 ZIP에 보존한다. 캡처 실패/미발견/거절/저장 실패를 구분하며 실패 안내 후 다음 항목 또는 전체 중단으로 이어진다.
- 투어 완료와 설정 완료를 구분하고 일반 사용자가 사용할 수 없는 베타 자동설정을 필수 단계로 안내하지 않는다. 기본 버프 추가는 선택임을 명시한다.
- 직접 지정·지정 영역 보기·아이콘 설정·보스 확인 방식 등의 문구를 실제 동작에 맞게 정리한다. 설정 전체 재배치와 등록 영역 자동 검증은 추가하지 않는다.

## 검증

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python scripts/render_setup_page.py
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q tests/test_setup.py
```

렌더는 `/tmp/setup-preview`에 생성하며 사용자 설정과 네트워크를 변경하지 않는다.
추가 테스트는 한글 경로의 실제 JSON 저장, 기존 탭과 잘못된 사용 값 해석의 일치,
순서·재실행 건너뛰기·공유 영역 의존성,
승인/거절·권한 오류·캡처 실패·미지원 격자·중단·종료 후 결과 폐기, 실제 확인 창과
버프 위 경계 선택, 원본 PNG 픽셀과 실행별 진단 ZIP 재실행, 상위 탭 수·기능 체크 동기화를 포함한다.

전체 회귀와 기존 독립 재현 스크립트: **755 passed, 6 warnings in 137.34s**.
이후 기존 탭의 enabled 값 해석과 일치시키는 보완을 반영하고, 새 기능·앱 노트·기존
자동찾기 관련 집합을 다시 실행해 **90 passed, 3 warnings in 18.17s**를 확인했다.
새 사용 준비 테스트는 총 39개다. 각 집합은 서로 겹치므로 중간 전체 741개 결과나
최종 전체 결과와 합산하지 않는다. 경고는 기존 mss/Qt API 사용 중단 안내다.

Windows의 게임창 선택, 포커스/z-order, 혼합 DPI·다중 모니터, Explorer/절전 복귀와
장시간 자원 사용은 이 Linux 환경에서 검증하지 않았다. 기존 좌표 변환/선택기의
혼합 DPI 제약이 해결되었다고 주장하지 않는다. 시작 화면·캡처·스레드 경로가 바뀌므로
독립 QA와 Windows 사전 CI/실게임 확인 후 배포 판단이 필요하다.
