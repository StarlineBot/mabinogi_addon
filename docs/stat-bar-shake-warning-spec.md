# 체력바 저값 경고: 흔들림 시각 효과 명세

- 상태: 동작 기획 확정. 사용자가 제안한 동작 전체에 동의했다. 움직임의 세부 수치는 시안으로 확인한다.
- 작성일: 2026-10-15
- 대상: 편의기능의 체력바 오버레이에 표시되는 HP/MP/STA.
- 목적: 소리만으로 구분하기 어려운 저값 경고의 대상을 주변 시야에서 알아차리고 빠르게 찾게 한다.
- 이 문서는 개발·독립 QA 전달용이다. 앱 구현이나 Windows 실동작 검증 완료를 뜻하지 않는다.

## 1. 사용자 관점의 동작

- 경고 조건을 만족한 바만 기준 위치 주변에서 작게 좌우로 흔들린다.
- 짧은 흔들림 후 잠시 정지하는 동작을 반복한다. 끊임없이 빠르게 떨리는 효과가 아니다.
- 낮은 상태가 유지되는 동안 이 반복을 계속하고, 기준 위로 회복하면 원래 위치에서 멈춘다.
- 여러 바가 동시에 낮으면 해당 바들이 각각 경고한다. 정상인 바까지 함께 흔들지 않는다.
- 점멸, 밝기 깜빡임, 색상 교대, 확대·축소를 이 효과에 추가하지 않는다. 기존 바 색과 채움 비율을 유지한다.
- 소리를 꺼도 흔들림으로 경고 대상을 확인할 수 있다.

## 2. 기존 기능과의 관계

- 기존 바별 HP/MP/STA 경고 사용 체크와 임계 비율을 이용한다.
- 기존 '소리 알림'은 소리만 제어한다. 끄더라도 바별 경고가 켜져 있으면 시각 경고는 동작한다.
- 기존 보스전 조건, 체력바 기능 사용/베타 접근 조건, 표시 토글, 전체 일시정지 및 활성 상태에 따른
  오버레이 표시 정책을 유지한다. 평소 사냥에서도 새롭게 경고하도록 범위를 확대하지 않는다.
- 기존 소리의 발동·회복 후 재무장 정책은 변경하지 않는다. 시각 효과의 반복이 소리 재생을
  반복 호출하는 이유가 되어서는 안 된다.
- 게임의 원본 바, 영역 지정 위치 및 판독 알고리즘을 움직이거나 변경하지 않는다.
- 흔들림 크기·속도 등 새로운 사용자 조절 옵션은 이번 기획의 요구사항이 아니다.

## 3. 경고 활성화 조건

다음 조건을 모두 만족해야 해당 바의 시각 경고를 시작한다.

1. 체력바 기능을 사용할 수 있고 사용 중이며 전체 일시정지 상태가 아니다.
2. 기존 정책에 따라 해당 바 오버레이가 표시되는 상태이다. 표시를 끈 바를 경고 때문에 강제로 띄우지 않는다.
3. 해당 바의 저값 경고가 켜져 있다.
4. 기존 보스 존재 판정이 보스전 상태라고 판단한다.
5. 게임 원본 영역에서 HP/MP/STA 세 바가 모두 정상적으로 판독된다.
6. 해당 바의 판독 비율이 설정값 이하인 상태가 약 0.4초 연속 유지된다. 기존 저값 경고의 판정 지연을 따른다.

경계는 '설정값 이하'이다. 예를 들어 30% 설정에서는 30%도 저값에 포함되고, 30%보다
높아지면 회복이다. 다른 히스테리시스나 추가 임계값을 임의로 넣지 않는다.

## 4. 상태 및 상태 전환

각 바는 독립적으로 다음 상태를 갖는다.

| 상태 | 동작 | 다음 상태 |
|---|---|---|
| 경고 대상 아님 | 흔들림 없음, 기준 위치 | 활성화 조건을 충족하면 저값 확인 대기 |
| 저값 확인 대기 | 판정 지연 동안 정지 | 약 0.4초 연속 저값이면 흔들림 시작. 회복/판정 불가이면 해제 |
| 흔들리는 구간 | 작은 좌우 움직임 | 짧은 움직임을 끝내면 경고 휴지 구간 |
| 경고 휴지 구간 | 기준 위치에서 잠깐 정지. 경고 자체는 유지 | 여전히 조건을 만족하면 다음 흔들림. 회복/조건 해제이면 경고 해제 |

- 유효한 저값 프레임이 계속 들어온다고 매번 애니메이션을 처음부터 시작하지 않는다.
- 경고 휴지 구간을 정상 회복으로 취급하거나 새 경고 진입으로 세지 않는다.
- 회복을 다음 유효 판독에서 확인하면 흔들림/휴지 구간에 관계없이 기준 위치로 돌아가 멈춘다.
- 바 하나의 회복이 다른 저값 바의 시각 경고를 해제하지 않는다.
- 새로 낮아졌을 때는 연속 저값 확인부터 다시 시작한다. 소리의 재발동 여부는 기존 정책을 따른다.

## 5. 중단 및 예외 상황

| 조건 | 기대 동작 |
|---|---|
| 해당 바의 경고 체크 해제 | 해당 바 시각 경고를 해제하고 기준 위치로 복귀 |
| 해당 바 표시 끄기 | 기존 표시 정책대로 숨김. 보이지 않는 바의 애니메이션을 계속 갱신하지 않음 |
| 소리 알림 끄기 | 기존 소리 동작만 꺼짐. 유효한 저값 바의 시각 경고는 유지 |
| 보스바 미감지/보스전 종료 | 시각 경고 해제. 이후 보스전에서 새 유효 판독으로 다시 판단 |
| 세 바 중 일부 판독 실패/캡처 실패 | 이전 저값만으로 흔들림을 계속하지 않고 시각 경고 해제. 판독 불가를 0%로 간주하지 않음 |
| 게임/앱 활성 상태 변경으로 오버레이 숨김 | 숨기고 시각 경고 갱신 중단. 다시 표시될 때 새 유효 판독으로 판단 |
| 전체 일시정지/기능 끄기/로그아웃 | 기존 정책대로 숨기고 시각 경고 해제 |
| Windows 잠금/절전 | 보이지 않거나 판독할 수 없는 상태에서 효과를 계속 진행/누적하지 않음 |
| 복귀/재실행/원본 영역 재지정 | 이전 흔들림의 중간 위치나 위상을 복원하지 않음. 기준 위치와 새 판독에서 다시 판단 |
| 앱 종료 | 효과 관련 갱신·타이머·작업을 정리. 별도 창이나 작업을 남기지 않음 |

- 조건 해제 후 다시 시작할 때는 저값 확인 지연을 다시 적용한다. 놓친 흔들림을 몰아서 재생하지 않는다.
- 판독 실패 시 기존 바 수치 표시를 어떻게 유지하는지는 기존 정책을 따른다. 이 기획 때문에
  정상 수치를 임의로 0으로 바꾸거나 캡처 실패 안내 방식을 새로 변경하지 않는다.
- 임계값·경고 체크 변경은 현재의 유효 판독으로 재평가한다. 경고가 더 이상 성립하지 않으면 멈춘다.
- 빠른 저값/회복 반복에도 효과 인스턴스나 갱신 작업이 중첩되지 않아야 한다.

## 6. 위치·잠금·조작 보존

- 사용자가 지정한 위치는 기준 위치이다. 흔들림은 일시적인 표시 효과이며 저장 좌표가 아니다.
- 흔들리는 도중 다른 설정을 저장해도 흔들린 순간 좌표가 저장 위치를 덮어쓰지 않는다.
- 위치 고정 상태에서도 효과는 가능하지만 클릭 통과와 비활성 표시를 유지한다. 효과 때문에 게임의
  클릭을 가로채거나 포커스를 가져오지 않는다.
- 위치 잠금을 해제한 경우에도 기존 드래그/격자 맞춤을 유지한다. 사용자가 옮긴 위치를
  새 기준 위치로 삼으며, 시각 효과 때문에 드래그 위치가 누적 이동하거나 점프하지 않는다.
- 배율·수치 정렬을 변경해도 기존 설정이 적용되며, 흔들림으로 채움 비율이나 글자 정렬 의미가 바뀌지 않는다.
- 화면 가장자리에서 흔들리는 부분이 오버레이 경계에 잘려 사라지지 않도록 표시 여백을 검토한다.
- 인접한 바의 식별을 방해할 만큼 크게 움직이지 않는다. 사용자가 임의로 겹쳐 배치한 바를
  자동 재배치하거나 충돌 회피시키는 기능은 추가하지 않는다.

## 7. 시각 효과 검토 기준

확정된 형태는 '작은 좌우 흔들림 → 기준 위치에서 잠깐 정지 → 반복'이다.
다음 수치는 아직 임의로 고정하지 않고 작은 시안 2~3개를 실제 배율로 비교해 선택한다.

- 최대 좌우 이동 폭.
- 한 번 흔드는 동안의 왕복 횟수와 소요 시간.
- 다음 흔들림 전 정지 시간.
- 배율과 DPI에 따른 움직임 크기 및 필요한 여백.

시안은 정지 스크린샷만이 아니라 움직임을 판단할 수 있는 짧은 영상이나 실행 가능한
미리보기로 확인한다. 정상 바, 저값 바 1개, 동시 저값 바 2~3개, 작은/큰 배율과 화면
가장자리 배치를 포함한다. 숫자를 읽을 수 있고 지속 경고가 지나치게 산만하지 않은지 사용자 피드백을 받는다.

## 8. 성능 및 구현 범위

- 기존 판독 결과를 이용한다. 시각 효과만을 위해 게임 캡처나 판독 빈도를 높이지 않는다.
- 보이는 경고 바만 필요한 표시 갱신을 한다. 정상·숨김·중단 상태에서 애니메이션 때문에
  지속적인 고빈도 그리기를 하지 않는다.
- 여러 바가 동시에 경고하더라도 효과 갱신이 기존 판독·소리 알림을 지연시키지 않아야 한다.
- 특정 애니메이션 라이브러리, Windows API, 스레드 또는 클래스 구조를 기획상 강제하지 않는다.
- 이번 범위는 오버레이 시각 경고 추가이다. 소리 반복 원인 조사, 음원 분리, 보스전 외
  경고 확대, 추가 설정 화면 및 기존 자동찾기 개선을 함께 구현하지 않는다.

## 9. Acceptance Criteria

| ID | 검증 가능한 성공 기준 |
|---|---|
| SB-01 | 보스전·정상 세 바 판독 조건에서 HP 경고를 30%로 켜고 HP 30% 이하가 약 0.4초 지속되면 HP만 흔들린다. 정상 MP/STA는 정지한다. |
| SB-02 | MP/STA도 각각 자신의 경고 체크·임계값으로 동작하며, 동시 저값 바가 여럿이면 해당 바들이 각각 시각 경고를 유지한다. |
| SB-03 | 저값 상태를 유지하면 작은 좌우 흔들림과 기준 위치에서의 정지가 반복된다. 연속 판독마다 애니메이션이 재시작되어 정지하거나 빨라지지 않는다. |
| SB-04 | 경고 기준이 30%인 바가 30%보다 높은 유효 값으로 회복하면 다음 판독 반영 시 흔들림을 멈추고 기준 위치로 복귀한다. 다른 저값 바의 효과는 유지한다. |
| SB-05 | 소리 알림을 꺼도 경고 체크가 켜진 저값 바는 흔들린다. 시각 효과의 반복으로 기존 소리의 발동 횟수나 재무장 정책이 바뀌지 않는다. |
| SB-06 | 약 0.4초보다 짧은 저값은 시각 경고를 시작하지 않는다. 세 바 판독 실패/캡처 실패/보스전 조건 해제에서는 이전 저값으로 흔들림을 지속하지 않는다. |
| SB-07 | 경고·표시·기능 끄기, 일시정지, 로그아웃 및 기존 활성 상태에 따른 숨김 후에는 해당 효과의 지속 갱신이 없다. 재개 시 새 판독과 저값 확인 지연을 따른다. |
| SB-08 | 효과 중 고정·설정 저장·앱 재실행을 거쳐도 기준 위치가 흔들림 좌표로 바뀌지 않는다. 효과 중 위치 편집은 사용자가 놓은 새 기준 위치로 저장된다. |
| SB-09 | 고정한 바가 흔들리는 동안에도 게임 클릭이 통과하고 포커스를 가져오지 않는다. 잠금 해제 시 기존 드래그와 격자 맞춤이 유지된다. |
| SB-10 | 바의 색·밝기를 점멸시키지 않고 기존 색과 채움 비율을 유지한다. 선택한 시안의 배율/DPI 조건에서 숫자를 읽을 수 있고 움직이는 바가 오버레이 경계에 잘리지 않는다. |
| SB-11 | 저값·회복·숨김·설정 변경을 반복해도 효과·타이머·작업이 누적되지 않으며, 효과만으로 게임 캡처 횟수가 증가하지 않는다. |
| SB-12 | 잠금·절전 후 복귀나 앱 재실행 시 이전 애니메이션의 순간 위치를 복원하거나 누적 흔들림을 재생하지 않고, 종료 후 효과 관련 작업이 남지 않는다. |

## 10. 개발 세션 전달

- 본 문서를 기능 동작과 QA 성공 기준으로 사용한다.
- 현행 판독/경고 조건은 `src/mabinogi_addon/ui/stat_bars_tab.py`, 독립 바 표시는
  `src/mabinogi_addon/ui/stat_overlay.py`에서 확인할 수 있다. 현행 구조의 위치 안내이지 구현 방식의 강제는 아니다.
- 먼저 7절의 작은 움직임 시안을 보여주고 사용자와 시각 수치를 정한다. 임의로 강한 흔들림을 완성형으로 확정하지 않는다.
- 실제 Windows의 클릭 통과·포커스·DPI·숨김/복귀는 별도 검증하며, 소스 검토나 렌더만으로 통과를 주장하지 않는다.
