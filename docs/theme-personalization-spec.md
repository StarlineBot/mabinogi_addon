## 1. 목표

게임 유저가 **"내 색"**으로 앱을 꾸밀 수 있게 한다.
- 배경과 강조색 두 가지를 **밝기까지 자유롭게** 고를 수 있다.
- 어떤 색을 골라도 글자, 안내, 상태 표시가 읽혀야 한다.
- 로그인 여부와 관계없이 모두 쓸 수 있다. 백로그에 있던 Discord 혜택안은 폐기한다.

## 2. 진입: 설정 › 테마

- 기존 `시스템 / 라이트 / 다크` 동그라미 뒤에 4번째 **`개인화`**를 추가한다.
  - 모양: 무지개 원뿔 그라데이션 동그라미. 크기와 선택 테두리는 다른 동그라미와 같다.
- `개인화`를 선택했을 때만 아래 **개인화 패널**이 열린다.
- 다른 테마를 고르면 패널은 닫히고 그 테마가 적용된다. 이때 개인화 값은 지우지 않고 보존한다. 다시 `개인화`를 고르면 그대로 복원된다.
- `시스템 / 라이트 / 다크`의 동작과 모양은 지금과 **완전히 같아야** 한다. 회귀가 없어야 한다.

## 3. 개인화 패널 (위에서 아래 순서)

| 줄 | 구성 |
|---|---|
| `배경` | 프리셋 동그라미 6개, 세로 구분선, `직접 고르기`(+) |
| `강조색` | 프리셋 동그라미 6개, 세로 구분선, `직접 고르기`(+) |
| `내용 칸` | `자동 / 어둡게 / 밝게` 세 칸 선택(기본 `자동`). 옆에 회색 안내 `자동: 배경이 밝으면 밝게, 어두우면 어둡게` |
| 안내 + 버튼 | 회색 안내 두 줄 `읽기 어려운 조합이면 글자·강조색 밝기를 조금 조정해요.` / `상태 색(초록 정상·주황 주의·빨강 위험)은 바뀌지 않아요.`. 오른쪽에 `기본으로 되돌리기` |

**프리셋 값**

| 배경 | 값 | 강조색 | 값 |
|---|---|---|---|
| 그레이 | `#202020` | 민트 | `#00C9A2` |
| 남색 | `#141A26` | 하늘 | `#38BDF8` |
| 자주밤 | `#1E1620` | 파랑 | `#5B8DEF` |
| 진한 핑크 | `#C2185B` | 보라 | `#A78BFA` |
| 하늘 | `#A5D8FF` | 분홍 | `#F472B6` |
| 크림 | `#F5EFE3` | 살구 | `#F59E7B` |

- 선택된 동그라미에는 ✓와 강조색 테두리를 표시한다.
- 직접 고른 색을 쓰는 중이면 `직접 고르기` 동그라미가 그 색으로 칠해지고 ✓가 붙는다.
- 프리셋 동그라미는 한 번 누르면 바로 적용되고 저장된다.
- `기본으로 되돌리기`는 배경 그레이 `#202020`, 강조 민트 `#00C9A2`, 내용 칸 `자동`으로 되돌린다. 결과는 다크 테마와 같은 모습이다.

## 4. 직접 고르기 창

- `+`를 누르면 작은 창이 열린다. 배경용과 강조색용은 같은 창이고 제목만 다르다(`배경 직접 고르기` / `강조색 직접 고르기`).
- 구성(위에서 아래):
  1. 네모판: 가로는 진하기, 세로는 밝기.
  2. 색조 무지개 막대.
  3. `색 코드` 입력(`#RRGGBB`)과 현재 색 견본.
  4. `RGB` 입력: `R`, `G`, `B` 숫자 칸 각각 0~255. 화살표와 휠로 1씩 조정한다.
  5. 회색 안내 `색 코드와 RGB는 서로 같이 바뀌어요.` / `밝기까지 자유롭게 고르고, 즉시 미리 적용돼요.`
  6. `취소` / `적용` 버튼.
- **네모판, 막대, 색 코드, RGB 네 가지는 서로 연동**된다.
  - 내부에서는 색 하나를 기준으로 들고, 한 곳을 바꾸면 나머지 칸을 다시 채운다.
  - 서로 다시 갱신하는 무한 반복이 생기지 않게 막는다.
  - 잘못된 색 코드를 입력하면 직전 값을 유지한다.
- **밝기와 진하기에 제한이 없다.** 앱이 고른 값을 막거나 바꾸지 않는다. 가독성은 5절의 계산이 맡는다.
- 고르는 동안 앱 전체에 **미리 적용**한다. `취소`(또는 창 닫기)는 창을 열기 전 값으로 되돌리고, `적용`은 저장한다.

## 5. 색 계산: 틀은 내 색, 내용 칸은 읽기용

화면을 두 층으로 나눈다.

| 층 | 범위 | 색 |
|---|---|---|
| **틀** | 머리줄(`홈` 버튼·`전투 보조: 켜짐`), 1단 탭 줄, 홈 화면 배경 | 고른 배경색 **그대로**. 홈 배경은 위에서 아래로 살짝 어두워지는 그라데이션 |
| **내용 칸** | 2단 탭 줄부터 아래 페이지 전체, 홈의 카드 | 고른 배경색을 섞은 읽기용 바탕(아래 규칙) |

**내용 칸 톤**
- `자동`: 고른 배경 위에서 흰 글자(`#F2F2F2`)와 검은 글자(`#111111`) 중 **대비가 큰 쪽**을 본다. 흰 글자가 더 잘 읽히면 어두운 톤, 아니면 밝은 톤이다.
- `어둡게` / `밝게`: 사용자가 정한 톤을 그대로 쓴다.
- 어두운 톤 바탕은 `배경 20% + #161616 80%` 섞음, 밝은 톤 바탕은 `배경 18% + #FFFFFF 82%` 섞음이다.
  - 예: `#FF8FB1`이면 `#FFEBF1`(연한 핑크), `#5B3FA0`이면 `#241E32`이다.
  - 입력칸, 버튼, 테두리, 구분선은 이 바탕에서 밝기를 단계적으로 옮겨 만든다.
- 글자와 이름 색 세트는 **내용 칸 톤**을 따른다.
  - 어두운 톤이면 `palette`의 다크 값, 밝은 톤이면 라이트 값을 쓴다.
  - 기존 다크·라이트 처리 경로에 바탕 색만 덮어쓰는 구조다.

**대비 기준과 자동 조정**
- 대비는 WCAG 상대 휘도 대비로 잰다. 본문 글자는 **4.5:1**, 보조 글자·상태색·강조색·탭 글자는 **3:1** 이상이어야 한다.
- 미달이면 그 색의 **색조와 채도는 두고 밝기만** 가장 가까운 값으로 옮긴다. 주황은 주황, 빨강은 빨강으로 남는다.
- **틀 위 글자**:
  - 머리줄 글자와 선택된 1단 탭 외 글자는 흰색과 검은색 중 대비가 큰 쪽을 쓴다.
  - 선택 안 된 탭의 회색과 `전투 보조: 켜짐`의 상태색은 틀색 기준으로 위 조정을 거친다.
- **강조색**:
  - 고른 값을 그대로 쓰되, 틀과 내용 칸 둘 다에서 3:1 미만이면 밝기만 조정한다.
  - 예: 밝은 하늘 배경에서 민트는 진한 청록으로 바뀐다.
  - `on-accent`(잠금 버튼 글자 등)는 `#062F28`과 `#FFFFFF` 중 대비가 큰 쪽이다.
  - `accent-soft`(2단 탭 선택 글자)와 2단 밑줄은 강조색에서 계산한다. 1단 선택색보다 한 단계 약하면서 내용 칸 대비 3:1 이상이어야 한다(14절 1항 위계 유지).
- **상태색**(`ok`, `warn`, `danger`): 값은 고정이고 의미도 바뀌지 않는다. 내용 칸이 정해진 톤 범위라 보통 조정이 없다. 극단적인 경우에만 밝기를 최소로 조정한다.
- 조정이 일어나면 직접 고르기 창 안내 아래에 회색으로 `읽기 쉽게 조금 조정했어요`를 표시한다.

**구현 형태**
- 위 계산은 Qt와 무관한 **순수 함수** 하나로 둔다.
  - 입력: 배경, 강조, 내용 칸 설정.
  - 출력: 틀색, 틀 글자색, 내용 칸 바탕과 단계 색, 이름 색 8가지의 실제 값, 조정 여부.
- `palette.color()`는 개인화 중일 때 이 결과를 돌려준다.

## 6. 적용·저장·범위

- **즉시 적용**: 프리셋 선택, 직접 고르기 미리보기, 적용, 되돌리기 모두 재시작 없이 앱 전체(홈 포함)에 바로 반영한다.
  - 0.29.0의 "테마를 바꾸면 탭 색만 즉시, 그 밖의 이름 색은 다음 실행부터" 동작은 개인화와 맞지 않는다. 따라서 **이름 색을 쓰는 화면 전체를 다시 칠하는 경로**를 만든다.
  - 그러면 기존 테마 전환도 즉시 반영되며, 이는 개선으로 본다.
- **저장**: config에 `theme: "custom"`과 개인화 값(배경, 강조, 내용 칸)을 둔다. 키 이름은 개발이 정하고 status에 기록한다.
  - 다른 테마로 바꿔도 개인화 값은 남긴다.
  - 잘못된 저장값은 기본값(3절 되돌리기 값)으로 읽는다.
- **홈**: 개인화 중에는 홈도 5절 규칙(배경 = 틀, 카드 = 내용 칸)을 따른다. 다른 테마에서는 지금처럼 남색 홈 디자인을 그대로 쓴다.
- **바뀌지 않는 것**:
  - 게임 위 오버레이(버프 시간, 보스 경고, FPS 등 게임 화면 가독성용)
  - 메모 글씨 강조색
  - 브랜드 `#3A0729`
  - 트레이 아이콘 점 색(상태 의미)

## 7. 버린 안 (다시 꺼내지 않도록 이유 기록)

- **밝기 고정, 색조와 진하기만 선택** (`rejected_fixed_lightness.png`): 가독성은 보장되지만 사용자가 "반쪽짜리 기능"으로 보고 쓰지 않을 가능성이 크다(사용자 판단).
- **배경 자유, 모든 글자색 보정** (`rejected_all_corrected.png`): 중간 밝기 배경에서 주황·빨강·초록이 모두 어두운 갈색 계열로 비슷해져 상태 구분이 어렵다. 빨강 배경에서는 위험색이 분홍이 된다.
- **내용 칸 항상 어둡게**: 밝은 색을 고르면 글 읽는 곳이 어두워 앱 전체 톤이 어둡게 보인다(사용자 피드백). 그래서 내용 칸이 배경 톤을 따르게 하고 `자동 / 어둡게 / 밝게` 선택지를 두었다.

## 8. 검증

- **계산 테스트**(맥에서 실행 가능):
  - 프리셋 6×6 × 내용 칸 3가지 전부와 무작위 배경·강조 수천 쌍에 대해 5절 대비 기준 이상인지 확인한다.
  - 상태색의 색조가 유지되는지 확인한다.
  - 다크·라이트·시스템 테마의 결과가 0.29.0 값과 같은지 확인한다.
- **렌더 확인**(사용자 전달):
  - 화면: 설정 패널(개인화 선택), 직접 고르기 창, 홈, 버프, 보스 패턴, 설정.
  - 조합:
    - 남색 + 하늘
    - 진한 핑크 + 민트(`자동`·`밝게` 각각)
    - 하늘 + 민트(자동 조정 확인)
    - 크림 + 보라
    - 중간 회색 `#808080` + 민트
  - 다크·라이트 테마에서 지금과 같은 모습인지도 함께 확인한다.
- **Windows 실화면**: 테마 전환과 미리보기 즉시 반영, 재실행 후 유지.
- 릴리즈 노트 `## v0.30.0`에 개인화 한 줄을 사용자 톤으로 추가한다(개발 커밋에서).
