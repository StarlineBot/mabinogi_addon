## UI

- [~] **버튼 스타일 (민트 토글/인셋) — 보류(현재 불필요)**
  - **원래 목적**: 테마 붙이기 전 Windows 기본 버튼의 **그라데이션**이 모노톤 앱과 안 맞아
    "버튼도 통일하자"였음.
  - **결론(2026-10)**: 테마(`setColorScheme`) 적용 후 라이트/다크 둘 다 버튼에 그라데이션이
    없어 **원래 문제가 해결됨** → 재디자인 이득 없음. 게다가 커스텀 '떠 있는 선'을 전면
    적용하면 스핀박스·콤보·체크박스 등 **네이티브 컨트롤과 톤 충돌** 위험 + 커스텀 페인트
    유지비. → **하지 않기로.**
  - **혹시 재발 시 폴백**(어떤 윈도우 환경에서 버튼 그라데이션이 보이면): 커스텀 말고
    **`app.setStyle("Fusion")` 한 줄**로 앱 전체 버튼 평평화(싸고 안전).
  - 디자인 검토 산출물(참고용 보존): `docs/button-spec.md` + 세션 목업들.
  - 토글 상태는 지금 `#00B894 checked`로 충분히 동작 중.

- [ ] **계산기 통합** — 분배 / 구슬 분배 / 환전비율 계산기 3개를 한 탭으로 묶기(검토).
- [ ] **3단 탭 구성** 검토(보류).
