# 백로그 / 할 일

세션이 길어지면 대화가 압축돼 맥락이 날아가므로, 아직 안 한 작업을 여기에 적어 둔다.
(완료되면 체크 + 간단한 결과, 혹은 줄 삭제.)

## UI

- [ ] **버튼 스타일 (민트 토글) — 특정 버튼에만 한정** — 테마 설정과 함께 나온 논의.
  - 모양: 선택 전 = 어두운 채움 + **민트 외곽선** + 은은한 글로우 / 선택 후 = **민트 채움**
    + 어두운 외곽선·글자 + 강한 글로우.
  - **⚠️ 당시 결론**: 이 민트 외곽선을 **'모든 버튼'에 넣으면 중요도(위계)가 가려져 비추천.**
    → 토글/선택 상태, 또는 주요 액션 등 **특정 버튼에만** 적용한다(전역 기본 버튼 스타일 ❌).
  - 현재: 체크형 버튼(위치 잠금 등)이 탭마다 `QPushButton:checked { background:#00B894 }`로
    **흩어져** 있음(buff/debuff/boss 탭 등). → `ui/widgets.py`에 **공용 토글 버튼 헬퍼**를
    만들어 (그 '특정 버튼들'만) 일괄 교체 + **테마(다크/라이트) 연동**.
  - 주의: Qt QSS는 box-shadow 미지원 → 글로우는 테두리 트릭 또는 `QGraphicsDropShadowEffect`.
  - 작업 전 **렌더(선택 전/후, 다크·라이트)로 피드백** 받고 적용.

- [ ] **계산기 통합** — 분배 / 구슬 분배 / 환전비율 계산기 3개를 한 탭으로 묶기(검토).
- [ ] **3단 탭 구성** 검토(보류).

## 기능

- [ ] **요리 (편의기능 탭)** — '편의기능'에 요리 관련 기능 추가(세부 스펙 미정).
- [ ] **체력바 경고 알림** — HP/MP/스태미나가 임계(예: ≤30%) 이하로 떨어지면 소리/표시 경고.
- [ ] **체력바 숫자 OCR** — 채움 비율뿐 아니라 '현재/최대' 수치까지 읽어 표시(`stat_overlay` 주석의 '추후 수치').

## 조건부 / 관찰

- [ ] **방해카드 per-아이콘 임계** — 특정 아이콘 오탐이 재발하면 그 아이콘만 높은 임계로.
      (3차 보스 바 %판독 게이팅으로 상당 부분 해소됨 — 재발 시에만.)
