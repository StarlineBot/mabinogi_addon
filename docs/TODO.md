세션이 길어지면 대화가 압축돼 맥락이 날아가므로, 아직 안 한 작업을 여기에 적어 둔다.
(완료되면 체크 + 간단한 결과, 혹은 줄 삭제.)

## UI

- [~] **버튼 스타일 (민트 토글/인셋) — 보류(현재 불필요)**
  - **원래 목적**: 테마 붙이기 전 Windows 기본 버튼의 **그라데이션**이 모노톤 앱과 안 맞아
    "버튼도 통일하자"였음.
  - **결론(2026-10)**: 테마(`setColorScheme`) 적용 후 라이트/다크 둘 다 버튼에 그라데이션이
    없어 **원래 문제가 해결됨** → 재디자인 이득 없음. 게다가 커스텀 '떠 있는 선'을 전면
    적용하면 스핀박스·콤보·체크박스 등 **네이티브 컨트롤과 톤 충돌** 위험 + 커스텀 페인트
    유지비. → **하지 않기로.**
  - **혹시 재발 시 폴백**(어떤 윈도우 환경에서 버튼 그라데이션이 보이면): 커스텀 말고
    **`app.setStyle("Fusion")` 한 줄**로 앱 전체 버튼 평평화(싸고 안전).
  - 디자인 검토 산출물(참고용 보존): `docs/button-spec.md` + 세션 목업들.
  - 토글 상태는 지금 `#00B894 checked`로 충분히 동작 중.

- [ ] **계산기 통합** — 분배 / 구슬 분배 / 환전비율 계산기 3개를 한 탭으로 묶기(검토).
- [ ] **3단 탭 구성** 검토(보류).

## 기능

- [ ] **요리 (편의기능 탭)** — '편의기능'에 요리 관련 기능 추가(세부 스펙 미정).
- [x] **체력바 경고 알림** — 생/마/스 각각 on/off + 각각 임계%(직접 설정, 기본 30%), ≤일 때
      1회 경고, 소리 체크. (커밋 `2a68872`, v0.4.58)
- [ ] **체력경고 소리 종류 결정** — 현재 `체력바 경고.mp3` 없으면 시스템 비프로 동작 중.
      추천: **짧은 3음 비프(생=낮게/마=중간/스=높게)를 코드로 생성해 넣기**(TTS 아님).
      비프 vs 효과음 vs TTS 중 택1 → 정하면 구현.
- [x] **버프 사라짐 경고 지연** — 점검 결과 판정(0~0.4초)은 빠르고 확정 대기(3초)가 지연
      원인. 결론: 시간/일반 버프는 3초 견고 유지(어차피 1·2차 경고 후 손실이라 빠를 필요
      없음), **즉시종료형(마나실드)만 0.5초로 빠르게**(`_FAST_GONE_IDS`). (v0.4.58)
- [ ] **2차(막차) 목소리 mp3 생성/푸시** — 코드·대사(gen_tts)는 들어감(v0.4.58). 인터넷 되는
      PC에서 `uv run --with edge-tts python scripts/gen_tts.py` 실행 → 세 팩에 `OOO 연장2.mp3`
      5개씩 생성 → `git add`·커밋·푸시. (없어도 1차 소리로 폴백, 무회귀.) 급박도는 gen_tts
      맨 위 `URGENT_*` 상수로 조절.
- [ ] **체력바 숫자 OCR** — 채움 비율뿐 아니라 '현재/최대' 수치까지 읽어 표시(`stat_overlay` 주석의 '추후 수치').
