# 기능별 안정성과 오프라인 검증 점검

검증일: 2026-10-15. 기준 소스: `cd90f52b841ae7f8358fc5c9f0358c3b5e45816a`.
독립 QA이며 제품 구현/기존 테스트를 수정하지 않았다. 커밋 이력은 조회하지 않았다.
판독기, 트래커, UI, 진단 수집의 주요 14개 파일을 원격 Git blob과 대조했다.

## 결론

정상 사용에서 안정적으로 보였다는 사용자 관측과 모순되지 않지만, 다른 기능까지
예외 상황에 안전하다고 단정할 수는 없다. 이번에는 **게임 실행 없이 체력바의
확정 결함 2건**을 추가 재현했다. 버프와 투아림의 기존 실패 재현은 계속 통과했다.
보스 패턴에는 작은 상승 오독이 반복 알림으로 연결될 수 있는 조건부 위험이 있다.

라이브에서 모든 버그를 처음 발견해야 하는 구조는 필수가 아니다. 이번 체력바 문제,
이전 디버프 경계 문제와 버프 연장 알림 경계는 원본/통제 입력으로 오프라인 재현할 수 있다.
다만 현 자료가 포괄하지 않는 화면 조건과 연속 상태 변화는 수집 범위를 넓혀야 한다.

## 같은 이미지 판독이어도 차이가 나는 이유

자동찾기는 실행 중 판독과 별개다. 자동찾기는 등록할 위치를 찾고, 실행 중에는 저장된
영역의 내용을 각 기능의 판독기와 상태 머신이 읽는다. 같은 OpenCV 매칭 함수를 사용해도
검색 범위, 아이콘 크기, 채널, 시간 보정과 오류 방어가 같다는 뜻이 아니다.

| 기능 | 실제 입력/판독 | 안정성을 돕는 요소 | 남는 경계 조건 |
|---|---|---|---|
| 버프 | 아이콘 열 검색 + 옆의 남은 시간 판독 | 앵커, 내부 시계, 두 번 확인하는 시간 보정, 아이콘 미검출 시 시간 확인, 표시 지터 완화 | 앵커/시간 동시 오독, 목록 이동, 연속 누락, 사용자 아이콘/배율 |
| 디버프 | 영역 전체에서 작은 아이콘 존재 검색 | 감지/해제 이력 임계, 0.3초 감지 확인, 재표시 유예 | 시간 정보로 생존을 보강하지 않음, 비슷한 물리/마법 아이콘, 작은 크기와 가림, 배경 후보 |
| 투아림 | 숫자 자리의 정규화 상관/레퍼런스 뱅크, % 기호 정렬 | 자리별 신뢰도, 새 판독 확인, 주기별 발화와 낮은 값 지속에 의한 재무장 | 오독이 여러 번 이어짐, 실제 리셋 구간 누락, 미검증 UI 배율 |
| 보스 패턴 | 이름 템플릿 + HP 숫자 | 이름 식별 게이트, HP 2~3회 확인, 급락 방어, 구간별 1회 발화 | 지속적인 소폭 상승 오독, 짧은 재식별/페이즈 전환 |
| 체력바 | HSV 색 띠와 밝기 경계의 채움 비율 | 숫자 글씨 제외, 만충 스냅, 알림의 3개 바/보스 게이트와 0.4초 확인 | 띠 일부 미검출 시 이름 매핑, 실패 뒤 오래된 대기 시각 |

투아림의 실행 중 판독은 아이콘 찾기가 아니다. `detect/tuarim_reader.py`는 숫자와
% 기호를 기준으로 판독하며, `ui/tuarim_tab.py`는 표시용 이전 확정값과 새 관측을 분리한다.
디버프는 아직 16px 템플릿 전제를 가진다. 이번 수정은 입력 영역 전체 축소를 없앤 것이며
모든 게임 UI 배율에서 아이콘 크기를 자동 정규화한다고 보장하지 않는다.

## 미검증과 배포 판단

현재 Linux/offscreen 실행이다. Windows 실제 음성/게임 포커스·후킹·GPU·FPS,
모든 UI 배율/멀티모니터, 장시간 자원 누수와 다른 테스터의 모든 환경은 새로 실측하지 않았다.

이번에 발견한 두 체력바 결함 때문에 네 기능 전체를 안정화 완료로 선언하지 않는다.
