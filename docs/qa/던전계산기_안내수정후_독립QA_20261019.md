## 확인 범위와 결과

정확한 소스 트리를 비교했다. 앞선 QA 공유본 `b9c6439` 대비 변경은 공개 노트, 노트 회귀 테스트, 개발 검증 문서의 세 파일뿐이다. 계산기·조회·종료 등 기능 코드는 변하지 않았다. 커밋 이력/메시지는 조회하지 않았다.

- 미공개 `v0.4.91` 노트에 편의기능 진입 위치, 통행증 비용·누적 순이익, 균열의 편린 시세 계산을 설명하는 한국어 문장 추가를 확인했다.
- `v0.4.90` 이하 공개 노트 내용은 그대로다.
- 기존 독립 재현을 그대로 실행해 최초 실행과 0.4.90 이후 업데이트에서 설명이 선택됨을 확인했다. 새 일반 회귀는 위치·순이익·균열 안내까지 검사하며 skip/기존 assertion 약화는 없다.

```bash
PYTHONPATH=src:. QT_QPA_PLATFORM=offscreen python -m pytest \
  tests/test_dungeon_release_note.py tests/test_release_notes.py \
  tests/test_release_notes_trigger.py scripts/qa_dungeon_release_note_20261019.py \
```

## 재사용과 제한

- 기능 소스가 동일하므로 선행 기능/회귀 90개와 독립 검증 5개 통과 및 화면 확인 결과를 재사용한다. 이번에 기능 95개 전체를 다시 실행하지 않았고 실행 수로 합산하지 않는다.
- Windows 네이티브·exe·실게임·실제 Nexon API·혼합 DPI·장시간 실행은 이번에 실행하지 않았다. 이전 제약을 유지하며 Linux 통과를 Windows 통과로 대신하지 않는다.
- 일반 푸시에 Windows 수동 실행을 추가 요구하지 않는다. 실제 태그 릴리즈의 전체 일반 회귀·Windows 네이티브·exe 필수 게이트는 유지한다.
- 확인 시 원격 최신 태그는 `v0.4.90`, 다음 번호와 노트 맨 위는 `v0.4.91`이다. QA 문서 공유와 원격 확인 후 해당 릴리즈 명령을 제공한다. 태그/릴리즈 실행은 사용자가 직접 한다.
- QA에서 제품·공개 노트·기존 테스트를 수정하지 않았으며 이 완료 기록만 공유한다.
