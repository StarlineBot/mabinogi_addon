### Improvement / P3: 기존 영문 기본 이름을 보존한 설정의 표시 이름 갱신

- 사용자 요청: 기본 목록을 한글로 바꿨지만 기존 초기 영문 이름이 계속 보이므로,
  다음 배포에서 해당 이름만 한 번 갱신한다. 전체 설정 초기화나 모든 이름 강제 덮어쓰기가 아니다.
- 근거/위치: `src/mabinogi_addon/catalog.py:39`에 기본 14개의 한글 이름이 있지만,
  `ui/buff_tab.py:426`의 _display_name은 저장된 비어 있지 않은 name을 우선한다.
  `config.py:412`도 이전 name을 그대로 읽는다. 저장 name이 영문 ID인 경우 새 한글 기본값이
  가려지는 경로는 소스로 확인했다. 사용자 설정 원본을 직접 확보·실행한 결과는 아니다.
- 이 항목은 새 이관 요구이며 구현/테스트 완료로 표시하지 않는다. 사용자 사용법이나
  업데이트 누락을 원인으로 단정하지 않고 앱의 기존 설정 호환 처리로 해결한다.

### 확정 범위 및 보존 조건

1. 기존 기본 버프 14개 중 **저장 name이 해당 버프의 영문 ID와 정확히 같은 항목만** 이관한다.
   예: `overture_of_the_battlefield` → `전장의 서곡`.
   대상 ID와 한글 이름은 카탈로그의 DEFAULT_BUFF_NAMES를 기준으로 한다.
2. 비어 있는 name은 이미 카탈로그 한글 기본값을 따르므로 불필요하게 저장 값을 채우지 않는다.
   이미 한글인 이름, ID와 다른 사용자 지정 이름(영문 포함), 사용자 추가 버프는 변경하지 않는다.
   현재 저장 형식만으로는 사용자가 의도적으로 ID와 똑같이 지은 이름과 옛 기본 이름을
   구별할 수 없다. 이 정확 일치값은 이번 요청에서 이전 기본 이름으로 취급한다.
3. 기준 버프 premium_battle도 대상이며, 편집 불가 UI 때문에 영문 이름이 남지 않아야 한다.
   일반 목록과 기준 버프 패널 등 기존 표시 경로가 같은 결과를 사용하게 한다.
4. name 이외에는 보존한다. 버프 ID·목록 순서·숨김/표시·시간 표시·알림 기준/소리/2차 알림,
   사용자 아이콘·추가 버프·삭제/숨긴 항목 및 모든 판독 영역·오버레이 위치/잠금 설정을 유지한다.
   삭제했던 기본 항목을 다시 만들거나 파일을 지우거나 설정 전체를 초기값으로 재생성하지 않는다.
   저장 문서의 다른 섹션과 알 수 없는 기존 필드도 이관 때문에 유실하지 않는다.
5. **설정 파일 기준 최초 1회** 실행하고 성공 후 완료 표식을 남긴다. 매 버전/매 시작마다
   이름을 덮어쓰지 않는다. 완료 뒤 사용자가 다시 이름을 바꾸면 재실행해도 그 값을 보존한다.
   기존 설정 저장 경로를 사용해 이름 변경과 완료 표식을 함께 안전하게 저장한다.
   쓰기 실패에 완료 표식만 남기거나 정상 원본을 훼손하지 않으며 이후 정상 저장 시 재시도 가능해야 한다.
6. 첫 실행부터 한글 이름을 보여주도록 버프 UI가 기존 설정을 읽기 전에 이관한다.
   새 설치/설정 없음도 정상 시작하고, 손상·읽기/쓰기 실패는 기존 복구 원칙대로 처리한다.
