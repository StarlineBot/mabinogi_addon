## Confirmed Bug 2: 경고 위치 편집 표시를 다음 틱에서 숨긴다

- 심각도: **P2**, 정상 위치 조정 조작 불가/중단.
- 조건: 제작자가 설정에서 헤일로 경고 위치 잠금을 해제한다. 대상 보스가 없거나
  게임 대신 앱이 활성화된 상태라 다음 타이머 캡처가 None인 일반적인 설정 상황이다.
- 사용자 영향: 샘플이 잠깐 보인 뒤 사라져 안정적으로 드래그해 위치를 지정할 수 없다.
  잠금 버튼/오버레이는 해제 상태 그대로여서 표시와 조작 상태도 어긋난다.
- 원인: `_toggle_warning_lock()`는 기존 오버레이의 해제 샘플을 표시하지만,
  `_tick()` → `_monitor(None)` → 보스 대기/불확실 분기가 잠금 해제 여부를 보지 않고 hide한다.
  기존 PatternWarningOverlay의 편집 샘플 유지 계약과 충돌한다.
- 코드: `src/mabinogi_addon/ui/halo_capture_section.py:153`, `:187`, `:197`, `:379`.
  편집 계약: `src/mabinogi_addon/ui/pattern_overlay.py:3`, `:102`.
- 재현: 헤일로 탭에서 잠금 버튼을 클릭해 `locked=False`, `isVisible=True`를 먼저 확인한다.
  캡처 None 경계에서 실제 `_tick()`을 한 번 실행하고 가시성을 다시 확인한다.
- 실행 결과: `locked=False`는 유지되지만 `isVisible=False`가 되어 assertion이 실패한다.
  실제품 타이머 간격은 500ms다. 테스트는 기다리는 대신 해당 콜백을 직접 실행한다.
- 재현 코드: `scripts/qa_halo_presentation_20261019.py:27`.
