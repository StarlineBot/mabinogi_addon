# 단계별 자동설정을 기본 시작 화면으로 변경

- 사용자 추가 지시: 2026-10-15.
- 확인 소스: `aad006aa9cfac8bd1f208f697a7635954516e2ea`.
- 제보: 첫 시작 화면에 단계별 안내가 아니라 기존 한 화면 자동설정이 표시됐다.
- 새 요구: 단계별 자동설정을 먼저 표시하고 기존 한 화면과 그 진입 버튼은 노출하지 않는다.
  기존 화면의 구현을 폐기하거나 공유 자동찾기를 제거하라는 요구는 아니다.
- QA 세션에서는 제품 구현을 수정하지 않고 개발 세션에 적용 기준을 전달한다.

## 현재 소스에서 확인한 동작

1. MainWindow 생성 마지막에 `needs_start_screen()`이 true이면 `_open_setup()`을 호출한다.
   이 메서드는 기존 한 화면인 `setup_page`를 표시한다.
2. 실제 창이 표시된 뒤 `_on_first_shown()` → `_maybe_run_tour()`가 단계별 안내 진입을 판단한다.
3. `tourShown`, `firstUseGuideShown`, `skipSetup` 중 하나가 true이면 그 판단에서 반환한다.
   따라서 기존 투어를 본 정상 사용자도 skipSetup=false인 채 기존 한 화면에 머물 수 있다.
4. 단계별 안내 진입에는 별도로 기존 Discord 로그인 조건도 적용된다.
5. 설정에는 `자동설정 다시 열기`(기존 한 화면)와 `첫 사용 안내 다시 보기 (베타)`가 모두 노출돼 있다.

관련 위치:

- `src/mabinogi_addon/ui/main_window.py:410` 시작 화면 선택, `:414` 기존 화면 열기.
- `src/mabinogi_addon/ui/main_window.py`의 `_maybe_run_tour`, `_open_guide`, `_on_first_shown`.
- `src/mabinogi_addon/setup_state.py`의 `needs_start_screen`.
- `src/mabinogi_addon/ui/settings_tab.py:840` 기존 한 화면 버튼, `:844` 단계별 버튼.

위 내용은 실제 소스의 결정적인 실행 경로 분석이다. 이 요청에서 Windows 앱을 새로 실행한 것은 아니다.
사용 기록/로그인 상태는 프로그램의 분기 조건이지 사용자 과실이나 설정 삭제를 요구할 근거가 아니다.

## 개발 적용 기준

- 기존 로그인 사용자용 베타 조건 안에서 기본 준비 화면은 단계별 안내의 1단계로 한다.
  첫 설치 여부, 영역 등록 완료 여부, 과거 투어/안내 시청 기록 때문에 기존 한 화면으로 보내지 않는다.
- 사용자가 명시한 `skipSetup=true`는 존중한다. 이 값을 자동 해제하거나 설정/기록을 삭제하지 않는다.
  그 경우 기존 앱 화면으로 시작하며 단계별 안내는 설정에서 다시 열 수 있다.
- 기존 한 화면은 시작 화면/대체 화면/설정 버튼에서 노출하지 않는다.
  사용자의 표현처럼 내부 구현을 남겨도 되며, 범위를 벗어난 삭제/리팩터링은 요구하지 않는다.
- 설정의 자동설정 진입은 단계별 화면으로 통일한다. 기존 한 화면으로 가는 버튼은 숨기거나
  단계별 진입으로 정리하고, 같은 목적의 버튼을 중복 노출하지 않는다.
- 별도의 하이라이트 앱 둘러보기는 유지할 수 있다. 그 투어의 다시 열기 강조 대상과 설명도
  실제 남아 있는 단계별 진입 버튼으로 맞춘다. 숨긴 기존 버튼을 계속 강조하면 안 된다.
- 이미 등록된 게임창/영역/사용 체크/알림/배치/잠금은 그대로 읽고, 미등록 항목만 찾는다.
  기존 사용자가 안내를 테스트하려고 사용자 설정이나 시청 기록을 지울 필요가 없어야 한다.
- 업데이트 노트가 먼저 표시되는 순서는 유지하되, 노트 종료 후 기존 한 화면을 거치지 않고
  의도한 단계별 화면으로 연결한다. 트레이 시작은 기존처럼 창을 강제로 띄우지 않는다.
- 이 요청만으로 기존 로그인 제한을 해제하거나 앱 전체에 로그인을 강제하지 않는다.
  미로그인 동선에서도 기존 한 화면으로 우회 노출하지 않고 기존 앱 사용은 유지한다.

이 추가 지시는 기존 `docs/auto-setup-v2-spec.md` 7/10절의 한 화면 노출 유지 및
과거 투어 시청자 자동 안내 제외 정책을 변경한다. 개발 시 해당 기획과 기존 회귀 기대값도
함께 갱신한다. 앞선 QA 통과는 당시 명세에 대한 것으로 새 요구가 이미 구현됐다는 뜻은 아니다.

## 후속 QA 조건

- 로그인 + skipSetup=false에서 신규/기존 설정, 영역 등록 완료/미완료,
  tourShown/firstUseGuideShown 각각의 조합 모두 단계별 1단계로 진입한다.
- skipSetup=true에서는 앱 화면으로 시작하고 단계별 다시 열기는 가능하다.
- 미로그인/로그아웃/재로그인에서 베타 권한을 우회하거나 기존 한 화면을 노출하지 않는다.
- 기존 한 화면 진입 버튼이 없고 단계별 진입이 중복되지 않으며 앱 둘러보기의 강조 대상이 유효하다.
- 단계를 열고 이동하는 것만으로 기존 좌표/사용 체크/skipSetup을 덮어쓰지 않는다.
- 노트 종료, 트레이 시작/복원, 안내 중 종료/재실행에서도 동일 정책과 기존 종료 정리를 유지한다.
- 변경한 정확한 SHA의 자동 Windows 테스트/필요한 exe 빌드와 독립 QA를 확인한 뒤 배포를 판단한다.

현재 제품은 아직 이 새 동선을 구현하지 않았다. 이 문서 푸시를 제품 수정 완료나 새 릴리즈 승인으로 보지 않는다.
