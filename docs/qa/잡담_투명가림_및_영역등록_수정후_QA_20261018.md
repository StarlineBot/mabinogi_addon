## 원래 잡담 재현

- 원본 `scripts/qa_dialogue_transparent_occlusion.py`를 변경하지 않고 실행했다.
  이전 실패인 투명 창 노출/얼굴 클릭/자동 표시 세 조건은 이제 통과한다.
- 전체 원본+관련 검사 실행은 **1 failed, 83 passed, 2 deselected (11.67초)**였다.
  남은 실패는 '투명 창이 있을 때는 안 보이고 제거해야만 보임'이라는 과거 현상 관측이다.
  수정 후에는 제거 전부터 정상 표시되어 `assert not bubble.isVisible()`가 실패한다.
  이 과거 현상 관측을 새 제품 회귀로 분류하거나 기대값을 바꿔 통과시키지 않았다.
- 실제 코드 `system/dialogue_visibility.py:92` 이후는 WS_EX_LAYERED이고 알파 조회에서
  LWA_ALPHA/alpha=0이 확인되는 중첩 창만 제외한다. 알파 1/128/255, 비레이어드, 색상 키,
  조회 실패/픽셀별 투명 불확실 조건은 계속 보수적으로 차단하는 검사도 통과했다.
- 입력 통과/레이어드 플래그만으로 불투명 창을 무시하지 않는다. 포커스 변경/화면 캡처를 추가하지 않았다.

## 영역 등록과 생명주기

- 기준은 `docs/region-registration-usage-spec.md`다. 영역 등록을 실행 조건으로 사용하는
  버프/디버프/보스/체력바/단축바에서 이전 전체 enabled=False 때문에 차단하지 않는다.
  도르카 표시/투아림 표시/투아림 알림의 독립 선택 및 기존 접근/일시정지는 유지한다.
- 확인 취소/쓰기 권한 오류는 기존 영역과 메모리를 유지하고, 성공 뒤에만 메모리 상태를 지운다.
  공유 보스 영역의 소비자 안내/갱신, 저장 도중 변경된 영역 보존, 한 원자 쓰기의 보스/디버프
  동시 등록, 해제 후 같은 보스 재등록, 단축바의 이전 셀 제거 관련 검사가 통과했다.
- 지역/전역 세대와 현재 편집 가능 상태로 해제 후 늦은 선택/승인을 거절한다.
  실제 QThread가 큐에 넣은 이전 네 신호를 stop 뒤 폐기하고 새 실행의 네 콜백은 UI 스레드에서
  실행하는 검사도 통과했다. 기존 QThread 누수 가드는 유지했다.
- 새 독립 검사에서 도르카 13/투아림 95 표시 및 90/95 알림 후 각 영역을 하나씩 해제했다.
  대상 box만 None이 되고 다른 영역/수치/세부 옵션이 보존되며 추가 알림과 타이머 추가가 없었다.
- 기본 및 20px 글꼴 Qt 렌더 검사가 통과했다. 생성된 도르카·버프 큰 글꼴 PNG를 직접 확인해
  해제 명령과 주변 버튼/문구의 겹침 및 잘림이 없는 것을 확인했다. Windows DPI 검증을 대신하지 않는다.

## 클릭 진단 및 남은 개선

- 새 독립 검사에서 Windows 노출 거절 클릭이 INFO 사유 범주/유효 대사 수를 한 번 기록하고,
  이후 자동 틱 100회에서는 해당 로그가 늘지 않았다. 유효 대사 0개도 로그로 구분했다.
- **Improvement / P3:** `ui/creator_dialogue.py`의 첫 `_eligible()`와 대사 선택 실패는
  기록하지만, 문장 배치 또는 표시 직전 두 번째 `_eligible()` 실패 분기는 여전히 조용히
  반환한다. Windows 진단도 현재 범주까지만 남고 차단 HWND/알파를 특정하지 않는다.
  실제 PC에서 계속 무반응이면 로그만으로 모든 원인을 확정할 수 없다. 이것을 표시 기능의
  재현 실패나 배포 차단 결함으로 부풀리지 않으며 후속 진단 개선 대상으로 남긴다.
- 당시 사용자 PC의 차단 창/실제 대사 수/최초 거절 사유는 미확인이다. 이번 알파 0 모델 통과가
  실제 라이브 원인 확정이나 모든 종류의 투명 오버레이 지원을 의미하지 않는다.

## 배포 및 미검증

- 원격 최신 태그는 v0.4.85, 다음 번호는 **v0.4.86**이다. 현재 노트 상단도 일치한다.
  v0.4.85 이하 내용은 원격 태그와 비교해 보존 여부를 확인한다. QA에서 태그/Release를 만들지 않는다.
- Linux Qt offscreen 및 명시적 Windows API/캡처/게임 상태 대체 결과다. 실제 Windows
  알파 합성/가림/혼합 DPI/게임 입력·포커스/장시간 CPU·메모리·핸들/exe는 미검증이다.
- 무료 한도 정책에 따라 수동 Windows 실행을 일괄 요청하지 않는다. 실제 게임의 잡담 클릭과
  영역 해제/재시작은 라이브 확인 범위이며, 태그 게시에는 전체 회귀/네이티브/exe 성공이 필수다.
