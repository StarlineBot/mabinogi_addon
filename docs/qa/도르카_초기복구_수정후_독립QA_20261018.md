## 미검증 및 릴리즈

- Linux Qt offscreen과 기존 원본 입력을 사용했다. 시계/게임 활성/캡처/창 식별은 명시적으로
  대체했다. 실제 Windows 첫 시작/게임 캡처/혼합 DPI/포커스/장시간 부하/exe는 미검증이다.
- 당시 첫 실패 원인은 여전히 미확정이다. 이번 결과는 그 원인을 확정하거나 모든 초기
  판독 실패를 해결했다는 뜻이 아니다. 실제 게임 첫 시작에서 숫자와 앱 표시의 회복을 확인한다.
- UI가 저장 위치와 다른 곳에 있거나 워커가 계속 실행 중이면 기존 전체 탐색을 기다린다.
  이 제한을 새로운 전 화면 2초 복구 보장으로 설명하지 않는다.
- 무료 한도 정책에 따라 일반 푸시의 Windows 실행을 새로 요청하지 않았다.
  태그 릴리즈는 기존 전체 회귀/네이티브/exe 성공 게이트를 통과해야 게시할 수 있다.
- 원격 `v0.4.85`가 이미 존재하므로 다음 번호는 `v0.4.86`이다. 이번 도르카 노트를
  v0.4.86으로 분리하고 v0.4.85 이하 전체 본문은 해당 원격 태그와 바이트 단위로 보존한다.
  태그 생성/푸시/Release 게시는 사용자가 직접 진행한다.
