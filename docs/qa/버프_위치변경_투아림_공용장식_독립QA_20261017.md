## 버프: 옮긴 뒤 자동 찾기 재실행

자동 찾기는 화면에서 영역을 찾아 사용자가 승인하여 등록하는 동작이다.
이번 요구는 등록 후 창을 계속 따라다니라는 요구가 아니다.

소스 `ui/buff_tab.py:340`의 재실행은 새 전체 캡처에 `perform_autofind("buff", ...)`를 적용한다.
이전 등록 영역으로 탐색 범위를 제한하지 않는다. `detect/status_panel.py:44`는 화면 전체에서
프리미엄 배틀 멤버십 아이콘을 반해상도 BGR로 찾고, 원해상도에서 위치/크기를 정밀 확인한다.
반환값은 사용자에게 위 경계 확인을 받는 기존 흐름이며 승인 후에만 새 설정을 저장한다.

독립 도구: `docs/qa/assets/buff_position_20261017/position_probe.py`.

- 실물 원본 7개: 2556x1436, 2560x1440, 3830x2138, 3840x2160.
- 각 원본을 nearest 정수 이동하여 8개 위치로 재입력한다: 화면 중앙의 4개 1픽셀 위상,
  좌/우 중단, 좌/우 하단. 아이콘의 원본 픽셀이 보존됐는지 먼저 검사한다.
- 각 입력에 실제 `run_detector("buff", ...)`를 호출한다. 성공 여부뿐 아니라 앵커 x/y/size의
  정확한 일치, 정밀 점수 >=0.85, 화면 안 영역, 앵커 전체 포함, 아이콘 열의 위치를 검증한다.

- 최근 두 화면도 실제 원본 그대로 각각 `(16,849,16)`, `(16,945,16)`을 검출했다.
