분리한다. 대체의 `get`은 위반 기록과 assertion을 남긴다. 실제 네트워크 검사는 해당 생성만
명시적으로 원복하고 제품 `start`를 호출한다. HTTP 응답/취소/캐시 바이트/타이머 종료와
DeferredDelete 이후 관리자·reply의 실제 파괴를 확인한다. 기존 응답 오류 및 QThread 누수 assertion은 유지됐다.
Windows와 태그 CI 모두 회귀/네이티브 실패를 무시하지 않고 `-vv -ra`로 테스트 ID를 남긴다.

```bash
PYTHONPATH=src:. QT_QPA_PLATFORM=offscreen python -m pytest tests/test_test_boundaries.py tests/test_dialogue_network_lifecycle.py tests/test_windows_ci.py tests/test_creator_dialogue.py -q --tb=short
```
