## Confirmed Bug

### [P3] 새 던전 입장 계산기가 앱 업데이트 노트에 안내되지 않음

- 발생 조건: 현재 소스를 노트와 일치하는 `v0.4.91`로 배포하고 최초 실행하거나 `v0.4.90`에서 업데이트한다.
- 사용자 영향: 계산기 탭 자체는 사용할 수 있지만, 업데이트 안내에 새 기능이 나타나지 않아 추가 사실과 위치를 알기 어렵다. 계산 오류나 크래시는 아니다.
- 기술적 원인: `MainWindow`는 새 계산기를 추가했으나, 번들 노트의 `v0.4.91` 본문은 기존 설정 화면/잡담 변경 설명 그대로다. `notes_since()`가 실제로 보여줄 본문에도 던전 입장 계산기 설명이 없다. 기존 노트 파서 테스트는 형식/범위 선택만 검사하므로 이 내용 누락은 잡지 못한다.
- 요구사항 근거: `CLAUDE.md`의 릴리즈 노트 규칙은 새 기능 등 사용자에게 보이는 변경을 해당 버전 공개 노트에 한국어로 추가하도록 요구한다. 코드 스타일 제안이 아니다.
- 관련 위치:
  - `src/mabinogi_addon/ui/main_window.py:329`: 신규 계산기 생성/탭 등록.
  - `src/mabinogi_addon/assets/release_notes.md:1`: 현재 배포 예정 버전 안내.
  - `src/mabinogi_addon/ui/release_notes.py:61`: 최초 실행/업데이트에서 실제 노트 선택.
- 재현: 아래 별도 재현을 실행하면 최초 실행/0.4.90 이후 업데이트 두 조건 모두 실패한다.

```bash

  scripts/qa_dungeon_release_note_20261019.py -q --tb=short --show-capture=no
```

- 검증 결과: **2 failed / 0.14초**. 같은 안내 누락을 두 진입 조건에서 재현한 것이며 별개 결함 2건이 아니다. 일반 테스트 자동 수집에는 넣지 않았다.
- 개발 전달: 배포 예정 최신 노트에 기능 추가 한 줄을 넣으면 된다. 예: “편의기능에 던전 입장 계산기를 추가했습니다. 차수별 입장 비용과 누적 순이익을 확인하고, 믿음의 균열은 편린 시세로 입장 비용을 계산할 수 있습니다.” 과거 공개 노트는 변경하지 않는다. 확인 시점 최신 원격 태그는 v0.4.90이므로 v0.4.91 항목에 추가할 수 있다. 실제 수정 시점 원격 태그는 다시 확인해야 한다.

- 실제 `_request()` → Python 워커 → 기존 경매 페이지 처리 → Qt 타이머 수신 경로를 실행했다. 첫 페이지를 Event로 보류하고 탭 전환/중복 요청을 구성한 뒤 두 페이지의 묶음 총액과 개당가를 다르게 주입했다. 개당 최저가 10,000과 11차 누적 비용 560,000 적용 및 이전 던전 표 불변을 확인했다.

- 실제 MainWindow 내 4개 던전 화면을 12/20px에서 렌더했다. 페이지/표 가로 스크롤 없음, 모든 금액 텍스트 폭, 탭 전환 시 설정 및 타이머 개수 불변을 검증했다. 큰 글꼴의 통행증/균열 화면을 직접 열어 배치를 확인했다.
- 독립 종료 검사의 초안은 MainWindow 종료 자체가 저장하는 창 위치/오버레이 상태까지 불변이라고 잘못 가정했다. 기존 정상 종료 저장 경로를 확인하고 계산기 조작 중의 불변 검사와 종료 후 워커 검사를 분리했다. 제품 결함으로 집계하지 않았다.

소스 차이에 대한 `git diff --check`도 통과했다. 일반 회귀와 독립 검증 합계는 95개 통과이며, 안내 누락 재현 2개 실패는 별도다.

## 영향 및 제한

- 이번 제품 변경은 새 계산 모듈/탭과 MainWindow의 탭 등록·종료 호출이다. 기존 판독기·안정화·알림·오버레이 설정 코드는 변하지 않았다.
- 미조작 상태에서 API 조회는 시작하지 않고 새 수신 타이머도 동작하지 않음을 확인했다. 실제 게임 CPU/메모리/Windows 핸들 수치나 장시간 증가를 측정한 결과는 아니다.
- 실제 Nexon API 응답/권한·네트워크 지연, Windows 네이티브/exe, 혼합 DPI·다중모니터·실게임은 미검증이다. 유료 Windows 수동 실행은 요청/실행하지 않았다.
- 조회 취소는 진행 중 네트워크 I/O를 강제 종료하지 않는다. 외부 응답 읽기 중의 지연은 실제 Windows/API 검증 범위로 남는다.
- 계산기 자체에 배포 차단 기능 장애는 확인하지 못했다. 다만 저장소 완료 기준상 확인된 공개 안내 누락은 개발 세션에 전달하고, 반영 확인 전 이번 추가 개발분에 대한 릴리즈 명령은 보류한다. 노트만 수정되면 같은 제품 소스의 본 기능 검증을 재사용할 수 있다.
- QA는 제품/공개 노트/기존 테스트를 임의 수정하지 않았다. 보고서와 독립 검증·재현 자료만 공유한다.
