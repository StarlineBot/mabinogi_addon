## 소스 검토

- `src/mabinogi_addon/system/dialogue_visibility.py`의 `_region_overlap()`은
  CreateRectRgn/GetWindowRgn 후 NULLREGION(명시적으로 빈 영역)을 정보 없음과 구분한다.
  SIMPLE/COMPLEX 영역은 RectInRegion으로 얼굴/말풍선 두 사각형과 교차하는지 확인한다.
- region 좌표는 DWM 확장 경계가 아닌 GetWindowRect의 원점을 사용한다. 중심 한 점이
  아니라 사각형 전체를 검사하여 모서리 한 픽셀이나 두 번째 대상만 가려진 경우도 거부한다.
- 임시 GDI 영역은 finally에서 DeleteObject로 해제한다. 조회 실패/unknown/실제 겹침은
  보수적으로 거부하며, 기존 완전 투명 전역 알파 0/잠금/최소화/화면 밖 경계를 유지한다.
- 수동 진단의 `_blocker_identity()`는 제한 정보 권한으로 연 프로세스 핸들을 finally에서
  닫는다. 핸들을 유지한 채 HWND/PID를 다시 확인하고 바뀌면 소유자 결과를 채택하지 않는다.
  basename만 기록하고 전체 경로/창 제목/예외 메시지는 넣지 않는다.
- `ui/creator_dialogue.py`는 수동 클릭 거부에만 소유자 진단을 요청한다. 자동 tick에는
  프로세스 조회/거부 로그를 추가하지 않았다. 새 캡처/입력/포커스 이동/폴링 타이머도 없다.
