## 공통 자원 설정

- `ui/resource_tab.py`의 공통 승인 전 비교와 공통 해제가 기존 `setup_state.section()`
  경계로 비-dict 섹션을 정규화한다. 공통 해제의 변경 대상도 dict로 만들어 null의
  `setdefault()` 실패를 없앴다. 정상 섹션은 영역 키 외 옵션을 보존한다.
- 기존 `scripts/qa_common_resource_null_section_20261018.py`의 6개 조건 모두 통과했다.
  이전 실패 4개는 도르카/투아림 각각 null에서 승인 및 공통 해제다. 정상 대조군 2개도 통과했다.
  기존 재현 스크립트와 기대값은 수정되지 않았다.
- 키 없음/null/목록/문자열/숫자에서 한쪽 등록 및 반대쪽 설정 보존, 공통 해제도 통과했다.
- 취소/쓰기 실패/후보 없음/동시 변경/로그아웃/해제/중복 요청/종료 중 결과 도착 등
  기존 공통 설정 경계와 실제 원본의 두 모델/부분 성공/진단 ZIP 재생도 확인했다.

## 잡담 판정 및 진단

- `system/dialogue_visibility.py`는 창 경계와 대상 영역의 겹침을 먼저 확인하고
  겹칠 때만 cloak을 조회한다. 따라서 얼굴/말풍선과 무관한 창의 cloak HRESULT 실패나
  예외가 전체 표시를 거부하던 조건이 제거됐다. 실제 겹치는 창의 불확실한 cloak은 계속 거부한다.
- 완전 투명으로 확인된 전역 알파 0만 제외하고, 불투명/부분 알파/색상 키/알파 조회 불가는
  보수적으로 처리한다. 잠금/최소화/화면 밖/모달/투어의 억제 정책을 우회하지 않았다.
- 입력 데스크톱 API 실패는 단계/API 이름/오류 번호로 구분되고, 획득한 데스크톱 핸들은
  조회 성공/실패 모두 finally에서 닫힌다. API 실패를 다른 기능으로 전파하지 않는다.
- `ui/creator_dialogue.py`는 수동 거절 로그에 호출별 진단을 붙인다. 자동 경로의 매초
  거절 로그는 추가되지 않았다. 창 제목이나 예외 메시지를 진단에 포함하지 않는다.
- 독립 추가 검사 `docs/qa/assets/resource_dialogue_fix_20261018/probe.py`에서:
  - 무관한 창의 cloak 실패/예외 각각에 실제 Qt 얼굴 클릭과 자동 tick 모두 말풍선 표시.
  - 같은 창을 겹치게 바꾸면 안전하게 표시 중단, 수동 클릭 로그에 실패 단계/차단 HWND 기록.
  - 차단 창이 사라지면 재시작 없이 다시 클릭해 표시, QTimer 개수 유지.
  - 실제 desktop_unlocked 함수에 OpenInputDesktop/GetUserObjectInformationW 실패를
    각각 주입해 실제 클릭의 API 이름/오류 번호 로그 및 핸들 정리 확인.
    오류 해제 후 같은 앱에서 클릭 복구, 요청 전후 검사마다 획득한 핸들 해제 확인.
- 위 항목의 Windows 경계는 명시적 대체 입력이다. 실제 Windows 합성/사용자 PC 재현과 구분한다.

## 배포 및 잔여 범위

- 실제 Windows 잡담 표시, 혼합 DPI/멀티모니터, 게임 Alt+Tab, 장시간 리소스 및 exe 실행은
  미검증이다. 실제 사용자 로그의 무반응 원인은 이전 통합 문구만으로 더 세분할 수 없다.
- 이번 버전에서 동일 증상이 계속되면 한 번의 수동 클릭 직후 보강된 로그로 실제 단계를
  확인할 수 있다. 제보를 사용자 사용 오류로 돌리거나 같은 구형 로그를 반복 요청하지 않는다.
- 위험 기반 베타 정책에 따라 별도 수동 Windows 사전 실행은 요청/시작하지 않는다.
  태그 릴리즈의 전체 회귀/네이티브/exe 게이트 성공 전에는 게시 성공이 아니다.
- 확인 시 원격 최신 태그는 v0.4.88, 다음 v0.4.89는 미사용이고 공개 노트 최상단과 일치했다.
  v0.4.88 이하 공개 노트는 원격 v0.4.88과 그대로 일치했다. 노트 버전 수정은 필요하지 않았다.
- QA 공유는 이 보고서와 추가 독립 검사만 포함한다. 제품 구현/자산/기존 테스트/사용자 설정과
  원시 로그는 수정하거나 커밋하지 않는다. 태그/실제 배포는 사용자가 직접 한다.
