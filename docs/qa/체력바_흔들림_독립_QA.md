## 판정

검증 가능한 범위에서 Confirmed Bug, Highly Likely Bug 또는 배포 차단 문제를 발견하지 못했다.
흔들림은 창 좌표가 아닌 그리기 좌표를 이동하며, 기존 소리 무장과 별도 시각 확인 상태를 사용한다.
아래 실행 결과와 Windows 최종 결과를 구분해 기록한다. 실게임 안정성 전체를 보증하는 판정은 아니다.

## 독립 실행

독립 검사는 `docs/qa/assets/stat_shake_20261016/probes.py`에 보관한다.
실제 Qt 위젯·타이머·기존 PNG 판독·임시 설정 파일을 사용하고 캡처·오디오·활성 창 경계만 대체했다.
`ExternalBoundaries`로 의도하지 않은 외부 호출이 없음을 확인했다.

```sh
PYTHONPATH=src:. QT_QPA_PLATFORM=offscreen python -m pytest docs/qa/assets/stat_shake_20261016/probes.py tests/test_stat_bars_stability.py -q --tb=short
```

실제 결과 **26 passed (5.76초)**. 신규 독립 검사 8건과 기존 안정성 회귀 18건이다.

- 실제 100ms 주기의 테스트용 판독 타이머와 제품의 단발 애니메이션 타이머를 2.85초 실행했다.
  저값 확인 후 첫 움직임과 1.8초 주기 뒤 두 번째 움직임을 확인했다. 제품 판독 주기를
  변경한 것이 아니며 이벤트 루프 부하를 제어하기 위한 독립 시험 입력 주기다.
- 그동안 캡처는 명시적으로 수행한 탭 틱 수와 같고 소리는 1회였다. 흔들림 타이머 자체의
  추가 캡처·추가 소리 호출이 없다. 실제 창 geometry와 기준 위치는 고정이었다.
- 일시정지 뒤 애니메이션 타이머가 멈추고 150ms의 실제 대기 중 효과 update가 늘지 않았다.
- 캡처 실패·비활성·로그아웃·보스 조건 해제·불완전 판독을 각각 주입하면 효과가 중단된다.
  복귀는 새 0.4초 저값 확인부터 진행하며 이미 울린 소리를 재무장하지 않는다.
- 캡처가 더 오지 않는 상태에서 마지막 유효 판독으로부터 0.65초를 넘기면 효과가 해제된다.
  임계값 재평가만으로 오래된 값을 재사용해 효과를 시작하지 않는다.
- 실제 저HP 원본을 1,201회 판독하고 정지/복귀를 60회 반복했다. 매 틱 외의 추가 캡처가 없고,
  동일 오버레이 3개와 각 1개 효과 타이머가 유지됐다. 소리는 1회, 저장 영역과 음수 기준 위치도 보존됐다.
  이는 반복 상태 검증이며 수시간 OS 자원 누수 측정은 아니다.

## 관련 회귀와 렌더

다음 검사군은 중복 항목이 있으므로 서로 다른 테스트 개수로 합산하지 않는다.

| 실행 범위 | 실제 결과 |
| --- | --- |
| `test_stat_shake.py`, `test_stat_bars.py`, `test_main_shutdown.py` | 41 passed (4.02초) |
| 독립 검사와 기존 저HP·판독 공백 회귀 | 26 passed (5.76초) |
| `QT_SCALE_FACTOR=1.5`: 흔들림·저HP 회귀 | 50 passed (3.42초) |
| 준비 화면·자동 디버프·공개 노트 회귀 | 177 passed (32.10초) |

- 기존 검사에서 동시 저값/개별 회복, 경계값/짧은 저값, 무음, 설정 변경, 실제 타이머 중단,
  배율 50/100/150/300%, RGBA 픽셀 보존·여백, 잠금/드래그/격자/저장 기준 위치를 실행 확인했다.
- 창의 저장 기준은 `base_position`/`move_base`로 통일되어 그림 이동이 저장 좌표를 바꾸지 않는다.
  호출자 검색에서 체력바의 위치 저장 경로를 함께 확인했다.
- 주 판독은 기존 200ms이고 효과는 보이는 경고 바에만 단발 타이머를 사용한다. 휴지 중에는
  프레임 주기 갱신 대신 다음 주기 또는 유효 판독 만료 시각을 예약한다. 캡처·스레드는 추가하지 않았다.
- 버프/디버프/투아림 판독 코드, 공유 캡처, 공용 포커스·클릭 통과 헬퍼와 전체 일시정지 정책은
  변경하지 않았다. 체력바 쪽 정지와 종료에서 새 효과 타이머를 해제하는 경로를 확인했다.
- `scripts/render_stat_shake_preview.py --output /tmp/qa-stat-shake-preview` 정상 종료.
  실제 바 렌더 PNG를 확인했고 숫자·색·채움에 확인한 범위의 잘림은 없다. 정지 PNG는
  움직임의 증거로 사용하지 않았으며 움직임은 위 실제 Qt 타이머 검사로 확인했다.

## 배포 판단

제한된 베타 배포 기준에서 릴리즈 명령 제공 가능하다. 원격 최신 태그 `v0.4.75`와

재사용하며 새 제품 변경 없이 수동 검증을 반복 요구하지 않는다. 실제 태그·배포는 사용자가 한다.

## 환경 제약

Linux offscreen과 제어된 캡처·활성 상태에서 수행했다. 실제 Windows 게임 중 흔들림의 시인성,
기존 오버레이와 원본 판독 영역이 겹치는 배치, 클릭 통과/포커스, Windows 잠금·절전·모니터 변경과
혼합 DPI, 장시간 CPU/GPU·핸들·GDI·메모리 사용은 직접 측정하지 않았다.
150% Qt 배율과 반복 검사는 이러한 Windows 실측을 대신하지 않는다.
기존 창 스타일은 유지했지만 실제 게임에서의 클릭 통과를 새로 통과했다고 주장하지 않는다.
YoloMouse 동시 사용과 마우스 하이라이트는 이번 제품 변경 범위가 아니다.
