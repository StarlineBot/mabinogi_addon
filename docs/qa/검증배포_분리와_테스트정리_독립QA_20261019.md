## 테스트 정리 검증

- 세 이관 모듈의 모든 최상위 함수/클래스를 원래 SHA의 AST와 직접 비교했다.
  함수 인자·장식자·fixture·assertion·반복 횟수 등 함수 내용이 동일했다.
- 대응: `scripts/qa_tuarim_low_range_display.py` → `test_support/regressions/tuarim_low_range.py`,
  `scripts/qa_dorcha_restart_after_move.py` → `test_support/regressions/dorcha_restart.py`,
  `scripts/qa_custom_autosave_import_reset.py` → `test_support/regressions/custom_replacement.py`.
- 원래 QA 경로는 호환 진입점이고 일반 게이트는 tests/만 수집한다.
- conftest의 외부 장치/네트워크·사용자 설정 격리와 QThread 누수 assertion은 유지됐다.
- 자동 저장의 대기 변경은 완료 조건과 1초 제한이며 저장 횟수/최종 값 검증은 유지됐다.
- `--regression-group`은 개발용 선택 도구이며 전체 Windows 게이트에 적용되지 않는다.
- 수집: resources 546, combat 413, navigation 235, capture 193, configuration 52,
  dialogue 107, calculator 18, delivery 132, core 204, windows 7. 합계 1907.
  native 10개 중 3개는 dialogue 그룹에 있으므로 windows 그룹 7개와 혼동하지 않는다.
- 기존 사례를 화면별 정상 검사 하나로 줄이지 않았다. 배포 경계 검사 추가로 총 사례 수는 늘었다.
  따라서 이번 변경으로 전체 테스트 시간이 크게 단축됐다고 주장할 근거는 없다.
  실제 Windows 전체 검사 최적화는 별도 측정이 필요하며 게시에서의 중복 실행 제거와 구분한다.

## 실행 명령

저장소 루트에서 환경에 맞는 Python을 사용한다.

```bash
env PYTHONPATH=src:. QT_QPA_PLATFORM=offscreen python -m pytest tests/test_release_candidate.py tests/test_windows_ci.py tests/test_test_inventory.py tests/test_qt_wait.py tests/test_unicode_io_contract.py tests/test_custom_autosave.py tests/test_custom_config_replacement.py tests/test_dorcha_restart.py tests/test_dorcha_self_capture.py tests/test_tuarim_low_range_display.py tests/test_release_050_regressions.py -q --tb=short --show-capture=no
env PYTHONPATH=src:. QT_QPA_PLATFORM=offscreen python -m pytest docs/qa/assets/validation_promotion_20261019/probe.py -q --tb=short --show-capture=no
python -m pytest --collect-only -q --test-inventory=/tmp/qa-promotion-inventory.json
```

독립 probe는 실제 임시 Git 저장소/로컬 bare 원격/태그를 생성해 gate와 fingerprint를 실행한다.
외부 GitHub API 응답과 Windows PE 버전 읽기만 대체하며 실제 외부 게시를 하지 않는다.
이관 전 AST 확인에는 위 원래 SHA의 Git 객체가 필요하다. 소스 미러처럼 .git이 없는 환경에서는
`QA_GIT_ROOT`를 해당 객체가 있는 실제 checkout으로 지정한다. 이번 실행값은 `/workspace/mabinogi_addon`.

  후보를 이미 검증했다면 이 코드가 추가된 입력으로 재검증해야 한다.
