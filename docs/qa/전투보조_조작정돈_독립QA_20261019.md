- 분류: 테스트/배포 검증 결함. 실제 앱의 영역 해제가 실패한다는 결론이 아니다.
- 발생 조건: 초기 영역이 없는 MainWindow를 만든 뒤 `runtime` fixture가 도르카 `_region`과 `_cfg['box']`만 직접 대입한다. 이 상태에서 자동찾기 중 `clear_region_btn.click`을 예약한다.
- 사용자 영향: 게임 중 장애는 확인하지 못했다. 다만 현재 릴리즈 전체 테스트에 해당 테스트가 포함되므로 테스트 단계에서 실패해 exe 빌드/배포가 차단될 것으로 예상된다. Windows CI를 실행해서 확인한 결과는 아니다.

  - 독립 재현도 실패: 해제 버튼 비활성 확인 후 예약 클릭이 무시되고 도르카/투아림 두 후보가 등록됨.

## 제약 및 재검증 조건

- Windows 네이티브, exe, 게임 Alt+Tab/전체화면/실제 DPI·다중모니터/장시간 리소스는 이번 환경에서 실행하지 않았다. Linux 통과를 Windows 통과로 대신하지 않는다.
- 판독기·안정화·알림·캡처 구현 변경은 이번 소스 차이에 없다. 이번 QA가 실제 게임의 모든 인식 정확도를 보증하지 않는다.
- 제작자 잡담 가림 판정은 앞선 별도 QA 범위다. 이번 화면 변경으로 사용자의 실제 PC에서 잡담 문제가 해결됐다고 판단하지 않는다.
- 제품/기존 테스트/워크플로는 QA에서 수정하지 않았다. 보고서, 독립 검증, 실패 재현 및 생성된 예시 이미지만 공유한다.
- 후속 개발은 테스트 준비 오류를 고친 뒤 해당 파일의 새 프로세스 사례까지 통과하는지 확인해야 한다. 실패 assertion을 삭제하거나 skip하지 않는다. 이후 변경 영향에 맞춰 위 회귀를 재검증한다.
- 일반 푸시에 Windows 실행을 일괄 요구하지 않는다. 현재 실패는 로컬에서 재현되므로 유료 Actions 재실행보다 소스의 테스트 준비 수정이 먼저다.
