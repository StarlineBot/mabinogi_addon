- 확정일: 2026-10-21
- 상태: 사용자 기획 확정. 개발 세션과 독립 QA 세션에 전달하는 최종 명세.

## 1. 목적과 범위

첫 사용 안내부터 개별 화면의 설명과 도움말까지 실제 기능명·조작·동작에 맞춰 읽기 쉬운 구어체로 통일한다. 보스 패턴 알림과 도르카·투아림에 도움말을 추가하고, 전투 보조 일시정지의 범위를 일관되게 맞추며, 일반 기능의 개별 자동찾기를 로그인 없이 제공한다.

- 포함: 첫 사용 안내, 자동설정 결과, 앱 둘러보기, 기능 설명 14종, 도움말 9종, 관련 설정 안내·툴팁, 전투 보조 일시정지, 개별 자동찾기 일반 공개.
- 유지: 현재 탭 구성과 화면 배치, 기능별 조작 방식, 영역·배치·표시·알림 설정, 프리셋 자동 저장, 후보 확인·승인·취소, 공개 범위를 바꾸지 않는 기능의 접근 정책.
- 제외: 강조색 변경과 추가 Discord 로그인 혜택, 새 자동찾기 검출기 개발, 헤일로 기능 자체의 비로그인 공개, 수집·진단·알파의 추가 공개.
- 이 명세의 자동찾기 공개와 일시정지 범위는 이전 문서의 상충하는 제한·예외 설명보다 우선한다. 그 밖의 기존 기능 요구사항은 유지한다.

## 2. 문구 원칙

- 설명 문장은 존댓말 구어체인 `~해요`, `~보여줘요`, `~알려줘요`, `~할 수 있어요`를 쓴다. 안내는 `~해 주세요`, `~확인해 주세요`를 쓴다.
- 제목·버튼·짧은 상태는 문장으로 늘리지 않는다. 예: `직접 지정`, `위치 잠금`, `등록됨`, `찾는 중…`, `저장 실패`.
- 본문을 `할당`, `게이팅`, `렌더`, `앵커`, `12뭉`, `미러` 같은 구현 용어로 설명하지 않는다. 실제 기능명인 커스텀 오버레이는 유지한다.
- `아직 걸지 않은 디버프`보다 `아직 걸리지 않은 디버프`를 사용해 특정 사용자가 직접 걸어야 한다는 의미를 피한다.
- `체력`을 자원명으로 쓰는 곳은 `생명력`으로 맞춘다. 기능명 `체력바`와 보스의 `체력`은 유지한다.
- `표시`와 `알림`, `판독 미리보기`와 `표시 미리보기`, `등록됨`과 `현재 판독됨`은 서로 다른 의미다. 말투를 맞추면서 이 차이를 없애지 않는다.
- `자동설정`은 첫 사용 안내의 일괄 설정, `자동 찾기`는 기능별 탐색을 뜻한다. 두 단어를 임의로 교환하지 않는다.
- 이동을 막고 클릭을 통과시키는 기능은 `위치 잠금`으로 설명한다. 게임 UI의 고정 즐겨찾기는 별도 개념이므로 고정 표현을 유지한다.
- 경매장 데이터 요청은 `시세 조회`, 다시 요청하는 동작은 `새로고침`으로 맞춘다. 실제 아이콘은 변경하지 않는다.
- 경로는 실제 화면의 이름으로 쓴다. `설정 > 게임창 등록`, `전투 보조 > 도르카·투아림`처럼 표기한다.
- 상단 요약은 핵심 역할 1~2문장이다. 준비 방법은 영역 조작 근처, 긴 조건과 예외는 도움말에 둔다. 중요한 제약을 도움말로만 옮기지는 않는다.
- 설명에 베타·로그인 요구 문구를 다시 반복하지 않는다. Discord 구간의 기존 베타 선사용 안내는 유지한다. 개별 자동찾기는 7.2절에 따라 일반 공개하고, 그 외 수집·진단·알파 등 기존 접근 제한은 유지한다. 숨겨진 기능을 설명만으로 일반 공개처럼 약속하지 않는다.
- 아이콘의 유무나 모양을 설명의 유일한 기준으로 삼지 않는다. 실제 버튼 이름으로 안내한다.

## 3. 첫 사용 안내

### 3.1 단계 이름

공통 화면 제목은 `첫 사용 안내`를 유지한다.

| 단계 | 화면의 단계 제목 | 하단 흐름 표시 |
|---|---|---|
| 1 | 게임창 등록 | 게임창 등록 |
| 2 | 전투 보조 설정 | 전투 보조 |
| 3 | 전투 보조 추가 설정 | 추가 설정 |
| 4 | 앱 둘러보기 | 앱 둘러보기 |

기존 선택 항목과 단계 구분은 유지한다. 세 번째 단계의 도르카·투아림·체력바·단축바도 실제로는 전투 보조 안에 있으므로 편의기능 단계라고 부르지 않는다. 단계 이름을 실제 기능 묶음에 맞추며 탭이나 기능을 재배치하지 않는다.

### 3.2 단계별 본문

게임창 등록, 처음 진입:

> 처음 오셨군요. 필요한 기능만 골라 함께 설정해 봐요.
> 게임창을 등록하면 앱이 마비노기 창을 찾을 수 있어요.
> 게임이 실행 중이지 않다면 나중에 등록해도 돼요.

게임창 등록, 다시 열었을 때:

> 등록한 영역을 확인하고, 추가로 설정할 기능을 골라봐요.
> 게임창을 바꿔야 한다면 여기서 다시 등록할 수 있어요.

버튼 가까이의 짧은 안내:

> ‘게임창 등록 시작’을 누른 뒤 3초 안에 마비노기 창을 선택해 주세요.

전투 보조 설정:

> 이번 자동설정에 포함할 전투 보조 기능을 골라주세요.
> 선택하지 않아도 이미 등록한 영역과 세부 설정은 그대로 유지해요.

전투 보조 추가 설정:

> 도르카·투아림·체력바·단축바도 함께 설정할 수 있어요.
> 이 기능들도 ‘전투 보조’ 탭에 있어요. 필요한 것만 고르거나 이 단계를 넘어가도 돼요.

보스 체력바 준비 안내:

> 보스 체력바를 찾으려면 연습 모드에 들어가 체력바가 보이는 상태에서 자동설정을 눌러주세요.
> 지금 준비하기 어렵다면 다른 기능부터 설정하고 나중에 다시 시도해도 돼요.

이 준비 안내의 기존 노출 조건은 유지한다. 관련 미등록 항목을 찾을 때만 보이고 이미 등록된 영역까지 다시 찾게 하지 않는다.

### 3.3 선택 문구

현재 `선택 문구 - 기능명` 형식은 유지한다. 선택이 실제 기능의 사용 여부를 바꾸는 것처럼 안내하지 않는다.

| 항목 | 선택 문구 | 뒤에 붙일 기능명 |
|---|---|---|
| 버프 | 버프가 끝나기 전에 알림을 받고 싶어요 | 버프 트래커 |
| 디버프 | 보스에게 아직 걸리지 않은 디버프를 확인하고 싶어요 | 디버프 트래커 |
| 보스 | 보스 패턴이 다가오면 알림을 받고 싶어요 | 보스 패턴 알림 |
| 헤일로 | 믿음의 균열에서 헤일로가 나오기 전에 알림을 받고 싶어요 | 1분 헤일로 알림 |
| 투아림 | 투아림이 설정한 비율에 도달하면 알림을 받고 싶어요 | 투아림 알림 |
| 도르카 | 도르카 수치를 보기 편한 위치에 표시하고 싶어요 | 도르카 |
| 체력바 | 생명력·마나·스태미나를 보기 편한 위치에 표시하고 싶어요 | 체력바 |
| 단축바 | 단축바를 보기 편한 위치에 표시하고 싶어요 | 단축바 |

도르카와 투아림은 독립적인 설정 대상이지만 `전투 보조 > 도르카·투아림`에서 함께 관리한다. 투아림 % 표시의 알파 권한을 바꾸거나 첫 안내 선택 항목으로 추가하지 않는다.

### 3.4 결과와 복귀 문구

- 그룹 제목 `설정 필요`, `등록된 설정`, `이번 설정에서 제외`는 유지한다.
- 영역 있음은 `등록됨`으로 표시한다. 사용자 확인이나 판독 성공을 뜻하는 `정상`, `사용 준비 완료`로 바꾸지 않는다.
- 선택하지 않은 미등록 항목은 `영역 지정 필요 · 이번 설정에서 제외`를 유지할 수 있다. 선택하지 않은 기존 등록 항목은 미등록으로 바꾸지 않는다.
- 후보 확인: `표시한 영역이 설명에 맞는지 확인해 주세요. 이 영역으로 등록할까요?`
- 후보 버튼 `이 영역으로 등록`, `등록하지 않기`는 유지한다.
- 직접 설정 후 돌아오는 버튼: `첫 사용 안내로 돌아가기`.
- 미선택: `이번에 자동설정할 기능을 골라주세요.`
- 게임창 미등록: `게임창을 먼저 등록한 뒤 자동설정을 눌러주세요.`
- 미등록 대상 없음: `선택한 기능의 영역은 이미 등록되어 있어요. 다시 지정하려면 해당 기능 화면을 열어주세요.` 이 문구는 실제로 모두 등록된 경우에만 사용한다. 자동설정 미지원·권한 제외·유효 대상 없음은 해당 원인으로 안내한다.
- 취소·실패에서는 기존 영역 유지, 저장 실패, 캡처 실패를 구분한다. `원인이 정확히 이렇다`고 단정할 수 없는 실패를 확정 원인으로 바꾸지 않는다.
- 게임창 등록 후 결과: `게임창을 등록했어요. 이번에 자동설정할 기능을 골라주세요.`
- 게임창 등록 실패: `게임창을 등록하지 못했어요. 마비노기 창을 선택한 뒤 다시 시도해 주세요.`

- 분배 계산기의 `판매가는 만 단위` 및 입력 예시는 제거하지 않는다. 상단을 짧게 만든다면 판매가 입력란 가까이에 둔다.
- 보스 체력바·버프 기준 버프·경험치 바 제외·원본 첫 칸 등 실제 영역 지정 조건은 조작 근처에 유지한다. 상단 문장을 간결하게 만들기 위해 필수 조건까지 삭제하지 않는다.
- 믿음의 균열 선택 시 자동 조회와 10분 캐시·새로고침, 다른 던전의 고정 비용 계산 차이를 유지한다. 이전의 수동 조회 전용 설명으로 되돌리지 않는다.
- 일반 사용자에게 보이지 않는 투아림 % 표시를 상단 요약에서 약속하지 않는다.
- 소리·표시 등 선택 옵션의 자세한 조건은 해당 옵션과 도움말에서 설명한다. 현재 꺼진 옵션이 켜져 있다고 상태 문구를 만들지 않는다.

## 5. 도움말 구성과 본문

도움말은 버프·디버프·체력바·커스텀 오버레이·단축바·메모·파티 모집·보스 패턴 알림·도르카·투아림의 9종으로 구성한다. 보스 패턴 알림과 도르카·투아림에 `?` 버튼을 추가하고 나머지 화면에는 일괄 신설하지 않는다. 도르카·투아림은 통합 화면의 도움말로 제공한다.

도움말의 공통 순서는 `어떤 기능인가요?` → `설정하는 방법` → `알아두세요`다. 아래 본문을 사용하며 실제 버튼명은 인용 표시해 유지한다.

### 5.1 버프 트래커

**어떤 기능인가요?**

등록한 버프의 남은 시간을 게임 화면에 보여줘요. 버프별로 종료 알림과 사라짐 경고를 설정할 수 있어요.

**설정하는 방법**

1. 게임의 상태목록창을 열고 ‘직접 지정’을 눌러 버프 아이콘과 남은 시간이 보이는 영역을 지정해 주세요.
2. 기준 버프가 영역 안에 보이도록 하고, 상태목록창 상단의 고정 즐겨찾기 영역은 빼 주세요. 고정 목록은 버프가 사라져도 아이콘이 남아 있어 잘못 감지할 수 있어요.
3. ‘추가’로 추적할 버프를 등록해 주세요. ‘상태창에서 가져오기’나 ‘파일 선택’으로 찾을 아이콘을 지정할 수 있어요.
4. 버프별 표시·지속시간·종료 알림을 설정해 주세요. 소리가 등록된 버프는 소리와 2차 알림을 설정할 수 있어요.
5. 오버레이 위치를 옮긴 뒤 ‘위치 잠금’을 눌러주세요. 잠그면 클릭이 게임으로 통과해요.

**알아두세요**

- 기준 버프는 다른 버프의 위치를 찾는 기준이에요. 기준 버프 자체에는 일반 버프의 표시·알림 설정을 하지 않아요.
- 남은 시간이 1분 미만이면 시간 숫자가 빨간색으로 바뀌어요. 실제 종료 알림 시점은 버프별 설정을 따라요.
- 찾을 아이콘이 완전히 같은 버프는 구분하기 어려워요. 급소관통과 물리공격력증가처럼 같은 아이콘을 쓰는 경우를 함께 확인해 주세요.
- 오버레이 아이콘을 따로 선택하지 않으면 찾을 아이콘을 사용해요.
- 게임창은 ‘설정 > 게임창 등록’에서 등록할 수 있어요.

### 5.2 디버프 트래커

**어떤 기능인가요?**

보스 체력바 위의 디버프 줄을 읽어, 등록한 디버프 중 아직 걸리지 않은 것만 보여줘요. 게임에 키 입력이나 클릭을 보내지는 않아요.

**설정하는 방법**

1. ‘직접 지정’으로 디버프 아이콘 줄이 들어오도록 지정해 주세요. 직접 지정·보기·해제는 디버프 영역에만 적용돼요.
2. ‘자동 찾기’를 사용하면 디버프 줄과 공유 보스 체력바를 함께 등록할 수 있어요. 찾은 영역을 확인한 뒤 등록해 주세요.
3. ‘추가’로 확인할 디버프를 등록하고 ‘영역에서 가져오기’나 ‘파일 선택’으로 찾을 아이콘을 지정해 주세요.
4. 오버레이를 원하는 위치에 옮긴 뒤 ‘위치 잠금’을 눌러주세요.

**알아두세요**

- 기본 보스 확인 방식은 자동이에요. 보스 체력바가 없거나 판독이 불확실하면 아이콘 감시를 이어갈 수 있어요.
- 공유 보스 체력바는 보스 패턴 알림에서도 사용해요. 공유 영역을 바꾸거나 해제하면 관련 기능에도 반영돼요.
- ‘사라짐 경고’를 켜면 보스에게 걸렸던 디버프가 떨어졌을 때 알려줘요. 경고에 필요한 보스 체력바 인식 상태를 함께 확인해 주세요.
- 영역을 넓히는 것만으로 보스가 없을 때 모든 오탐이 사라지는 것은 아니에요.

### 5.3 체력바

**어떤 기능인가요?**

게임의 생명력·마나·스태미나 비율을 읽어 새 바 형태로 보여줘요. 원본 화면을 그대로 복제하는 기능과는 달라요.

**설정하는 방법**

1. ‘직접 지정’을 누르면 박스가 마우스를 따라와요. 생명력·마나·스태미나 세 바에 맞추고 클릭해 주세요. 필요하면 마우스 휠로 박스 크기를 조절할 수 있어요.
2. 아래의 경험치 바는 영역에서 빼 주세요. 영역을 지정한 뒤 ‘판독 미리보기’에서 원본과 현재 값을 확인해 주세요.
3. 표시할 바와 배율·수치 정렬을 선택하고, 실제 오버레이를 원하는 위치로 옮겨주세요.
4. 각 바의 ‘위치 잠금’을 누르거나 ‘전체 잠금’으로 한 번에 잠글 수 있어요.

**알아두세요**

- ‘낮은 수치 알림’은 보스전에서 설정한 기준 이하가 됐을 때 해당 바를 흔들어 알려줘요. 소리는 따로 켜고 끌 수 있어요.
- 보스전 확인에는 공유 보스 체력바를 사용해요. 보스 체력바 등록 상태도 확인해 주세요.
- 원본을 읽지 못하는 동안은 실제 오버레이를 숨겨요. 이전 수치를 정상 값처럼 계속 표시하지 않아요.

체력바의 직접 지정은 박스를 맞춰 클릭하는 방식으로 안내한다. 다른 기능과 같게 보이도록 드래그 방식으로 잘못 설명하지 않는다.

### 5.4 커스텀 오버레이

**어떤 기능인가요?**

게임 화면에서 고른 부분을 다른 위치에 복제해 보여줘요. 특정 스킬의 재사용 대기시간이나 미니맵처럼 자주 보는 부분을 가까이 둘 수 있어요.

**설정하는 방법**

1. ‘복제할 영역 추가’를 눌러 원본 화면에서 복제할 부분을 드래그해 주세요.
2. 만들어진 오버레이를 드래그해 원하는 위치로 옮겨주세요. 잠금이 해제된 오버레이 위에서 마우스 휠로 배율을 바꾸고, 더블클릭하면 원래 배율로 돌아가요.
3. 목록의 위치 잠금이나 선택·전체 잠금 버튼으로 배치를 잠글 수 있어요. 잠그면 클릭이 게임으로 통과해요.

**프리셋을 사용할 때**

- 현재 구성의 변경은 자동 저장해요. 다른 구성을 만들면서 원본도 남기려면 먼저 ‘다른 이름으로 저장...’을 눌러주세요.
- 프리셋을 선택하는 것과 적용하는 것은 달라요. 다른 프리셋을 사용하려면 선택한 뒤 ‘불러오기’를 눌러주세요.
- 시작할 때 불러올 프리셋은 ‘프리셋 관리 > 시작 시 자동 불러오기’에서 따로 골라주세요.
- 선택 삭제와 전체 삭제의 대상은 현재 오버레이예요. ‘선택 프리셋 삭제’와 구분해 주세요.

### 5.5 단축바

**어떤 기능인가요?**

게임의 원본 단축바를 4칸씩 12개 묶음으로 나눠 원하는 위치에 보여줘요. 복제한 단축바는 게임 화면을 보여주는 용도이며, 스킬 입력을 대신 보내지는 않아요.

**설정하는 방법**

1. 원본 단축바를 보이게 해 주세요. ‘직접 지정’은 맨 왼쪽 위 첫 칸에 박스를 맞춰 클릭하면 돼요.
2. ‘기본 배치’에서 ‘중앙 하단(기본)’, ‘중앙 2단’, ‘블록 분리’ 중 하나를 고를 수 있어요.
3. 각 묶음을 드래그해 원하는 위치로 옮긴 뒤 ‘전체 잠금’을 눌러주세요. 다시 옮기려면 ‘전체 잠금 해제’를 눌러주세요.
4. 빈칸을 숨기려면 잠금을 해제한 실제 오버레이에서 해당 칸을 마우스 오른쪽 버튼으로 눌러주세요.

**알아두세요**

- ‘표시 배율’로 복제한 단축바의 크기를 조절해요. 원본 단축바의 크기는 바꾸지 않아요.
- 커스텀 오버레이의 저장 프리셋과 단축바의 기본 배치는 서로 다른 기능이에요.

도움말 제목은 `단축바 사용법`으로 한다. 첫 칸 미등록 안내는 `원본 첫 칸 미지정 — 맨 왼쪽 위 첫 칸에 맞춰 클릭해 주세요.`로 맞춘다. 잠긴 상태에서 우클릭하거나 단축바 자체의 휠 조절을 지원한다고 새로 약속하지 않는다.

### 5.6 메모

**어떤 기능인가요?**

작성한 메모를 게임 화면 위에 보여줘요. 던전 패턴 표나 준비물 목록을 적어둘 수 있어요.

**설정하는 방법**

1. ‘직접 지정’으로 메모를 표시할 위치와 너비를 잡아주세요. 높이는 내용과 화면의 남은 공간에 맞춰 조절해요.
2. ‘메모 내용’에서 글을 작성해 주세요. 내용은 자동 저장해요. 게임에 띄운 메모에서는 직접 입력하지 않아요.
3. 도구 버튼으로 제목·굵게·목록·표·구분선·코드를 넣을 수 있어요. ‘표시 미리보기’를 누르면 작성 결과를 확인할 수 있어요.
4. 잠금을 해제한 메모의 테두리를 드래그해 위치를 옮겨주세요. ‘위치 잠금’을 누르면 클릭이 게임으로 통과해요.

**알아두세요**

- 잠긴 메모는 게임창이 활성 상태일 때 보여요. 잠금을 해제하면 앱을 보면서 위치를 조정할 수도 있어요.
- 화면보다 긴 내용이 항상 전부 보이는 것은 아니에요. 글자 크기·너비·위치나 내용을 조정해 주세요.
- ‘지정 해제’는 표시 영역만 지워요. 작성한 내용과 글자 크기·잠금 설정은 유지해요.

마크다운의 기존 표·목록·강조 예시는 유지한다. 눈 아이콘이 있어야 미리볼 수 있다는 설명과 잠금이 시각적 가림까지 없앤다는 표현은 사용하지 않는다.

### 5.7 파티 모집

**어떤 기능인가요?**

선택한 서버의 파티 모집 현황을 모아서 보여줘요. 등록한 키워드가 제목에 포함되면 화면 알림으로 알려줘요.

**사용하는 방법**

1. ‘서버’에서 모집을 확인할 서버를 골라주세요. 현황과 키워드 알림에 같은 서버를 사용해요.
2. ‘키워드 알림’에 원하는 단어를 입력하고 ‘등록’을 눌러주세요.
3. 알림 소리는 종 모양 버튼으로 켜고 끌 수 있어요. 소리를 꺼도 화면 알림은 별개예요.
4. 제외할 파티장은 현황에서 이름을 누르거나 ‘파티장 제외’에 이름을 등록해 주세요. 해당 파티장의 모집은 현황과 알림에서 제외해요.

**알아두세요**

- 화면 알림은 ‘설정 > 일반 > 알림 > 토스트 알림 위치’에서 고른 위치에 나타나요. 기본 위치는 우측 하단이에요.
- 트레이에 있어도 알림을 받을 수 있어요. 알림을 누르면 앱의 파티 모집 화면을 열어요.
- 파티 알림 소리는 기본 소리를 사용해요. ‘알림 목소리’ 팩을 바꾸는 기능과는 별개예요.

토스트라는 용어는 설정의 실제 항목명에서 유지하고, 일반 설명에서는 먼저 화면 알림이라고 설명한다.

### 5.8 보스 패턴 알림

도움말 제목은 `보스 패턴 알림 사용법`으로 한다. `전투 보조 > 보스 패턴 알림 > 체력별패턴` 화면의 기능 제목 줄에 기존 도움말과 같은 `?` 버튼을 둔다. 별도 하위 탭인 1분 헤일로의 사용법과 섞지 않는다.

**어떤 기능인가요?**

보스 이름과 남은 체력 비율을 읽어, 패턴 기준에 가까워지면 화면과 소리로 알려줘요. 지원하는 보스와 패턴 기준은 화면 아래에서 확인할 수 있어요.

**설정하는 방법**

1. 보스 체력바가 보이는 상태로 준비해 주세요. 연습 모드에서도 설정할 수 있어요.
2. ‘직접 지정’으로 보스 이름부터 체력 비율까지 모두 들어오도록 드래그해 주세요. ‘자동 찾기’를 사용하면 보스 체력바와 디버프 영역을 함께 찾고 확인한 뒤 등록할 수 있어요.
3. ‘판독 미리보기’에서 원본 이미지와 ‘식별’, ‘HP’가 실제 게임 화면과 같은지 확인해 주세요. 영역이 등록돼 있어도 현재 보스를 올바르게 읽고 있다는 뜻은 아니에요.
4. ‘알림 미리보기’로 경고가 표시되는 위치와 소리를 확인해 주세요. 경고 위치를 옮기려면 ‘경고 위치 잠금’을 해제한 뒤 화면에 표시된 경고를 옮겨주세요.
5. ‘남은 패턴 목록 표시’를 켜면 앞으로 남은 패턴을 별도로 볼 수 있어요. 목록은 ‘목록 위치 잠금’을 해제한 뒤 따로 옮길 수 있어요. 배치를 마치면 다시 잠가주세요.

**알아두세요**

- 보스 이름이나 체력을 제대로 읽지 못하면 알림이 누락되거나 실제 시점과 다를 수 있어요. 게임 UI 위치나 크기가 바뀌었다면 판독 영역을 다시 확인해 주세요.
- 보스 체력바 영역은 디버프의 보스 확인과 체력바의 보스전 알림에서도 사용해요. 바꾸거나 ‘지정 해제’하면 관련 기능에도 영향을 줄 수 있어요.
- 직접 지정·지정 영역 보기·지정 해제는 보스 체력바를 대상으로 해요. ‘자동 찾기’는 디버프 영역도 함께 등록할 수 있다는 차이가 있어요.
- 경고와 남은 패턴 목록은 위치를 따로 정해요. 위치를 잠그면 클릭이 게임으로 통과해요.
- ‘알림 미리보기’는 경고의 모양·위치·소리를 확인하는 기능이에요. 실제 보스 판독이 성공했는지 확인하는 기능은 아니에요.

보스 체력바 준비 조건과 판독 결과 확인 안내는 도움말에만 넣지 않고 기존 영역 설정 근처에도 남긴다. 지원 보스 이름과 수치는 도움말에 중복 나열하지 않고 화면의 지원 목록을 안내한다. 자동찾기는 7.2절에 따라 일반 공개하고 수집 접근 정책은 유지한다.

### 5.9 도르카·투아림

도움말 제목은 `도르카·투아림 사용법`으로 한다. 통합 화면의 기능 제목 줄에 기존 도움말과 같은 `?` 버튼을 둔다. 숨겨진 이전 투아림 화면을 여는 방식이 아니라 통합 화면에서 직접 볼 수 있어야 한다.

**어떤 기능인가요?**

도르카 수치를 숫자와 15칸 바 형태로 크게 보여주고, 투아림이 설정한 비율에 도달하면 알려줘요. 도르카 표시와 투아림 알림은 필요한 것만 따로 선택할 수 있어요.

**설정하는 방법**

1. 게임에서 보라색 원과 오른쪽 아래의 투아림 숫자·%가 보이도록 준비해 주세요.
2. ‘직접 지정’으로 두 부분이 함께 들어오는 영역을 드래그해 주세요. 선택한 범위 안에서 도르카 숫자와 투아림 % 위치를 함께 찾아요. ‘자동 찾기’를 사용하면 게임 화면에서 함께 찾을 수 있어요.
3. 찾은 영역이 각각 도르카 숫자와 투아림 %에 맞는지 확인한 뒤 등록해 주세요. 한쪽만 찾았다면 찾지 못한 쪽의 기존 영역은 그대로 유지해요.
4. ‘판독 확인’에서 잘라낸 게임 화면과 읽은 수치를 비교해 주세요. 위치를 따로 맞춰야 한다면 ‘개별 영역 조정’을 열어 해당 영역만 다시 지정할 수 있어요.
5. ‘도르카 표시’를 켜고 배율을 조절해 주세요. 위치 잠금을 해제해 실제 오버레이를 원하는 곳으로 옮긴 뒤 다시 잠가주세요.
6. 투아림 알림을 받으려면 ‘투아림 알림 사용’을 켜고 ‘첫 알림’과 ‘추가 알림’의 비율을 정해 주세요. 각 알림의 소리는 따로 켜고 끌 수 있어요.

**알아두세요**

- 함께 찾더라도 두 수치는 서로 다른 영역에서 읽어요. 한쪽이 잘 맞지 않는다고 다른 쪽까지 다시 지정할 필요는 없어요.
- ‘현재 판독’과 ‘최근 확정’은 의미가 달라요. 특히 투아림의 ‘최근 확정’은 이번 화면에서 새로 읽은 값이 아니라 마지막으로 확정한 값일 수 있어요.
- ‘표시 미리보기’는 오버레이의 모양과 크기를 확인하는 곳이에요. 실제 숫자를 올바르게 읽는지는 ‘판독 확인’에서 게임 화면과 비교해 주세요.
- 공통 ‘지정 해제’는 두 판독 영역을 모두 해제해요. 한쪽만 해제하려면 ‘개별 영역 조정’을 사용해 주세요. 영역을 해제해도 표시·알림 선택과 위치·배율·잠금·소리 설정은 유지해요.
- 게임 UI 위치나 크기가 바뀌었다면 등록한 영역도 다시 확인해 주세요.

투아림 % 표시 옵션이 실제로 보이는 사용자에게만 해당 도움말에 `‘투아림 % 표시’로 퍼센트를 함께 표시할 수 있어요. 표시와 알림 사용은 따로 선택해요.`를 추가한다. 일반 사용자에게 없는 옵션을 켜라고 안내하거나 알파 권한을 변경하지 않는다. 공통 지정 조건과 두 영역의 등록 상태는 화면에도 계속 표시한다.

## 6. 화면에 남길 짧은 필수 안내

보스 패턴 알림과 도르카·투아림에 도움말을 추가하더라도 아래 안내는 관련 조작 가까이에 남긴다. 도움말을 열지 않아도 영역 지정의 필수 조건을 알 수 있어야 한다.

- 보스 패턴 알림: `이름과 체력 비율이 보이는 보스 체력바를 지정해 주세요.` / `판독 미리보기의 식별 결과와 HP가 게임 화면과 같은지 확인해 주세요.`
- 헤일로: `게임 상단의 남은 시간이 분·초까지 모두 들어오도록 지정해 주세요.` / `보스 이름을 확인한 뒤 남은 시간을 기준으로 안내해요.` 정확한 대상이 필요한 준비 안내에서는 `레넨의 미이르 : 회한`을 사용하고, 판독 상태와 별개로 항상 해당 보스가 확인됐다고 말하지 않는다.
- 도르카·투아림: `보라색 원과 오른쪽 아래의 투아림 숫자·%가 함께 들어오도록 지정해 주세요.` / `두 영역은 함께 찾고, 필요한 경우 ‘개별 영역 조정’에서 따로 맞출 수 있어요.`
- 투아림 알림: `첫 알림과 추가 알림 기준을 각각 정할 수 있어요. 표시 여부와 알림 사용은 따로 선택해요.` 일반 사용자에게 없는 % 표시 옵션을 켜라고 안내하지 않는다.
- 계산기: 분배 계산은 버튼 실행, 구슬 분배는 입력에 따른 갱신, 시세 계산기는 항목 선택·새로고침을 통한 조회라는 현재 조작 차이를 유지한다. 문구 통일을 이유로 실행 방식을 바꾸지 않는다.

| 위치 | 문구 |
|---|---|

| 편의기능 둘러보기 | 게임 중 번거로웠던 일을 도와주는 편의 도구를 모아뒀어요. 필요한 도구를 골라 사용해 보세요. |

| 격자 설명 | 격자가 작을수록 촘촘하게, 클수록 큰 간격으로 이동해요. 기본 크기는 32px이에요. |

위 표는 설명·버튼 이름 정리다. 기존 첫 사용 안내의 다시 보지 않기, 둘러보기 종료 후 복귀, 개별 알림 소리 설정은 변경하지 않는다. 일시정지는 7.1절, 자동찾기 공개 범위는 7.2절을 따른다.

편의기능 둘러보기는 개별 기능명이나 개수를 나열하지 않는다. 기능이 추가돼도 안내를 고칠 필요가 없도록 기능군의 목적을 설명하고, 각 기능의 구체적인 역할은 해당 화면의 제목과 설명에서 안내한다.

### 7.1 전투 보조 일시정지

목적은 앱을 종료하거나 설정을 지우지 않고 전투 보조의 표시와 알림을 잠시 끄는 것이다. 앱 전체 실행·모든 작업 중단으로 확대하지 않는다. 아래 범위로 동작해야 한다.

**사용자 관점의 범위**

| 구분 | 기대 동작 |
|---|---|
| 중단 대상 | 전투 보조 탭의 버프·디버프, 보스 패턴 경고·남은 패턴 목록·1분 헤일로, 체력바, 도르카·투아림, 커스텀 오버레이, 단축바, 메모의 게임 화면 표시와 관련 소리 알림 |
| 중단 대상 아님 | 파티 모집 조회·알림, 편의기능 계산기, 설정 화면 사용 |
| 설정 보존 | 등록 영역, 개별 표시·알림 선택, 위치, 배율, 잠금, 프리셋, 메모 내용은 그대로 유지 |
| 재개 | 기존 개별 설정과 현재 게임 상태·권한·표시 조건에 맞는 기능만 다시 표시·알림. 원래 꺼 둔 항목까지 켜지 않음 |
| 상태 유지 기간 | 기존처럼 이번 앱 실행에만 적용. 앱을 종료했다 다시 실행하면 일시정지 해제 상태로 시작하되 개별 설정은 유지 |

전투 보조 탭에 속한 메모·커스텀 오버레이·단축바도 포함한다. 숨겨진 알파·베타 기능의 접근 권한은 변경하지 않으며 접근 가능한 기능에만 같은 중단 원칙을 적용한다.

**상태와 경계 조건**

- 일시정지는 개별 기능의 사용 체크나 영역 해제가 아닌 공통 임시 상태다. 기능마다 추가 클릭을 요구하는 사용 체크를 신설하지 않는다.
- 중단하면 이미 떠 있는 대상 오버레이와 경고·흔들림을 숨기고, 재생 중인 전투 알림 소리도 멈춘다. 중단 중 새 전투 알림 소리를 시작하지 않는다.
- 위치 잠금 해제 상태나 앱이 활성 상태라는 이유로 대상 오버레이가 다시 나타나면 안 된다. 설정 변경·게임 전환·영역 재등록 후에도 재개 전까지 중단 상태를 유지한다.
- 재개는 현재 유효한 판독·게임 상태를 기준으로 한다. 과거 표시를 그대로 복원하거나 중단 중 지난 알림을 모아서 재생하지 않는다. 헤일로의 실제 전투 시간도 일시정지한 시간만큼 뒤로 밀지 않는다.
- 표시·알림을 막기 위한 캡처·판독·타이머 처리 방식은 개발에서 정한다. 모든 내부 작업을 멈추거나 재개 시 모든 추적기를 재시작해야 한다는 요구사항은 아니다.
- 상단과 트레이는 같은 공통 상태를 제어하고 어느 쪽을 눌러도 표시가 일치해야 한다. 빠르게 반복해도 중복 표시·중복 소리나 정지 상태의 뒤늦은 재표시가 없어야 한다.

**공통 문구**

| 위치 | 문구 |
|---|---|
| 정상 동작 상태 | 전투 보조: 켜짐 |
| 일시정지 상태 | 전투 보조: 일시정지 |
| 동작 중 버튼·트레이 명령 | 전투 보조 일시정지 |
| 일시정지 중 버튼·트레이 명령 | 전투 보조 재개 |
| 일시정지 툴팁 | 전투 보조의 오버레이와 소리 알림을 잠시 멈춰요. 파티 모집 알림은 계속 받을 수 있어요. |
| 재개 툴팁 | 기존 설정에 따라 전투 보조의 표시와 알림을 다시 켜요. |
| 일시정지 토스트 | 전투 보조의 오버레이와 소리 알림을 잠시 껐어요. |
| 재개 토스트 | 전투 보조를 재개했어요. 기존 설정에 따라 표시와 알림이 동작해요. |

현재 상단의 재생·일시정지 아이콘 형태는 유지하고 명령은 툴팁으로 안내한다. 버튼을 새로 여러 개 만들거나 전체 기능 목록을 토스트에 나열하지 않는다. 트레이의 `메모·투아림 소리 알림은 유지`라는 이전 설명은 제거한다.

**Acceptance Criteria**

- 대상 오버레이가 표시되고 전투 알림 소리가 재생되는 상태에서 일시정지하면 대상 표시와 소리가 멈추고, 파티 모집 알림과 계산기는 계속 사용할 수 있다.
- 중단 상태에서 보스·투아림 알림 조건에 도달해도 화면 경고·목록·소리가 나타나지 않는다. 위치 잠금 해제 상태의 대상 오버레이도 숨겨진다.
- 중단 중 개별 표시 설정이나 등록 영역을 바꾸더라도 전투 보조는 자동 재개되지 않는다. 재개하면 변경한 설정과 현재 판독에 맞게 동작한다.
- 재개할 때 원래 꺼 둔 표시·알림은 꺼진 상태이고, 중단 중 지나간 알림이 몰아서 재생되거나 헤일로 시간이 중단 시간만큼 지연되지 않는다.
- 상단·트레이의 상태와 명령이 일치한다. 앱을 다시 실행하면 공통 일시정지는 해제되며 기존 영역·배치·내용·개별 설정은 보존된다.

### 7.2 개별 자동찾기 일반 공개

첫 사용 안내의 일괄 자동설정처럼 아래 일반 기능의 개별 `자동 찾기`도 Discord 로그인 없이 사용할 수 있게 한다. 대상 화면에 같은 공개 정책을 적용한다.

**공개 범위와 유지 조건**

- 대상 화면은 버프, 디버프, 보스 패턴 알림의 체력별패턴, 체력바, 도르카·투아림, 단축바다. 통합 화면에서 사용하는 도르카·투아림 공동 탐색도 포함한다.
- 일괄 자동설정은 이미 일반 공개한 정책을 유지한다. 일괄 자동설정과 개별 자동찾기의 이름과 실행 범위는 구분한다.
- 로그인 때문에 버튼을 숨기거나 비활성화하지 않는다. 버튼이 활성화되어 있지만 눌렀을 때 로그인 검사로 아무 반응 없이 끝나는 상태도 없어야 한다.
- 실제 탐색 시작, 비동기 탐색 완료, 후보 미리보기, 사용자 승인, 영역 저장까지 비로그인 상태로 이용할 수 있어야 한다. 로그인·로그아웃만을 이유로 일반 공개 탐색을 취소하거나 후보 승인을 막지 않는다.
- 게임창 등록·실행 상태, 캡처 가능 여부, 대상 UI 노출, 탐색 중 중복 실행 방지 등 기존 실행 조건은 유지한다. 일반 공개가 무조건 탐색 성공을 보장한다는 뜻은 아니다.
- 기존 후보 확인 후 승인·취소, 부분 성공, 기존 영역 보존, 저장 실패 안내는 유지한다. 일반 공개를 이유로 찾은 영역을 바로 저장하는 방식으로 바꾸지 않는다.
- 투아림 % 오버레이의 제작자 전용 알파, 수집·진단 도구, 별도 제한 기능은 공개하지 않는다. 자동찾기와 같은 로그인 검사를 공유하더라도 모든 접근 검사를 한꺼번에 해제하지 않는다.
- 현재 자동찾기가 없는 화면에 새 탐색 기능을 추가하는 요구는 아니다. 1분 헤일로의 시간 영역 자동찾기는 현재 소스에 이미 존재하며, 헤일로 기능 자체는 로그인 사용자용 베타다. 헤일로를 사용할 수 있는 사용자에게 자동찾기만을 위한 추가 권한은 요구하지 않되, 이번 자동찾기 공개가 헤일로 기능 전체의 비로그인 공개를 뜻하지는 않는다.
- 설정의 Discord 구간에는 베타 기능 선사용 목적 안내만 유지한다. 일반 공개한 자동찾기를 로그인 혜택으로 안내하지 않는다.

**Acceptance Criteria**

- 비로그인 상태에서 대상 화면 각각의 `자동 찾기`가 보이며, 기존 실행 조건이 갖춰지면 실제 탐색과 후보 확인을 진행할 수 있다.
- 비로그인 상태로 후보를 승인하면 해당 영역이 저장되고 관련 화면에 반영된다. 취소·탐색 실패·저장 실패에서는 기존 영역을 보존하고 기존 결과 안내를 제공한다.
- 디버프/보스 공동 탐색과 도르카·투아림 공동 탐색의 등록 대상·부분 성공·확인 절차가 기존과 동일하다.
- 로그아웃하거나 앱을 비로그인 상태로 다시 실행해도 개별 자동찾기를 계속 사용할 수 있고 기존 영역·표시·알림·배치 설정이 유지된다.
- 일반 공개 이후에도 수집·진단·알파 기능의 기존 접근 제한은 유지된다. 첫 사용 안내의 일괄 자동설정과 직접 지정·보기·해제도 기존처럼 사용할 수 있다.

이 절은 [기능 공개 정책](feature-release-stage-review.md)과 [일괄 자동설정 공개 명세](app-usability-polish-20261020-spec.md)의 개별 자동찾기 제한 유지 규칙보다 우선한다. 다른 기능의 공개 단계는 변경하지 않는다.

### 7.3 자동찾기 공개 후 남는 제한 기능

7.2절의 자동찾기 공개 후에도 다음 접근 제한을 유지한다.

| 구분 | 기능 | 접근 범위 |
|---|---|---|
| 실사용 베타 | 믿음의 균열 1분 헤일로의 시간 판독·카운트다운·경고 | 일반 Discord 로그인 사용자 |
| 테스트·진단 | 디버프 보스 확인 방식을 체력바 모양/체력 %로 강제 지정하는 기존 진단 방식 | 일반 Discord 로그인 사용자. 기본 자동 방식은 로그인 불필요 |
| 테스트·진단 | 보스 HP바 수집, 투아림 숫자 템플릿 수집, 체력바 판독 수집·스냅샷 | 일반 Discord 로그인 사용자 |
| 테스트·진단 | 설정의 진단 스냅샷 저장 | 일반 Discord 로그인 사용자 |
| 제작자 전용 알파 | 도르카 오버레이의 투아림 % 표시 | 제작자만 허용 |
| 제작자 전용 수집 | 헤일로 시간 자료 수집·관련 스냅샷 도구 | 제작자만 허용 |

헤일로 시간 판독·카운트다운·경고는 일반 로그인 베타이며 시간 자료 수집만 제작자 전용이다. 투아림 % 오버레이는 제작자 전용 알파로 유지한다.

설정의 Discord 내보내기 등 계정이 실제 전송 대상 식별에 필요한 기능은 테스트용 베타와 구분한다. 로그인 필요라는 이유만으로 모두 베타 기능으로 세지 않는다. 아직 구현되지 않은 기획 기능도 현재 남은 베타 목록에 포함하지 않는다.

## 8. 공통 Acceptance Criteria

- 설명·도움말을 교체할 때 실제 버튼명·그룹명·탭 경로를 한 번에 맞춘다. 숨겨진 이전 컨트롤러의 문자열만 고치고 실제 사용자 화면을 빠뜨리지 않는다.
- 도움말마다 실제로 가능한 조작만 남긴다. 드래그 지정, 박스 클릭 지정, 휠 조절 지원을 기능별로 구분한다.
- 조건부 소리·자동 저장·직접 지정과 공동 자동찾기·현재 판독과 최근 확정의 의미는 유지한다. 접근 정책은 7.2절의 자동찾기 일반 공개만 변경하고 나머지 베타·알파·수집 제한은 유지한다.
- 변경 후 첫 사용 안내 세 단계와 앱 둘러보기, 14개 기능 설명, 기존 7종과 추가 2종을 합한 9개 도움말을 같은 기준으로 렌더·대조한다. 길어진 문구가 버튼이나 본문을 가리지 않는지 지원 글꼴·테마·화면 크기에서 확인한다.
- 보스 패턴 알림과 도르카·투아림의 제목 줄에서 `?` 버튼으로 해당 도움말을 열고 닫을 수 있어야 한다. 도움말을 열고 닫아도 영역·표시·알림 설정이 바뀌지 않고, 필수 지정 안내도 기존 화면에 남아 있어야 한다. 보스 도움말은 1분 헤일로 설명으로 잘못 연결되지 않아야 한다.
- 특히 첫 사용 안내에서 기능을 선택하고 해당 탭으로 이동했을 때 같은 기능을 가리키는지 확인한다. 추가 설정을 편의기능 탭으로 잘못 안내하지 않는다.
- 분배 계산기 입력 단위, 보스 준비, 기준 버프, 경험치 바 제외, 프리셋 자동 저장과 적용, 경매 시세 지연 등 필수 안내가 줄어들지 않아야 한다.
- 전투 보조 일시정지는 7.1절의 표시·소리 중단과 설정 보존을 함께 검증한다. 문구만 교체하고 누락된 출력 경로를 그대로 두어 완료로 처리하지 않는다.
- 개별 자동찾기는 7.2절에 따라 비로그인·일반 로그인 상태 모두에서 버튼 노출부터 후보 승인·저장까지 검증한다. 버튼만 열고 실제 탐색이나 완료 처리를 로그인 조건으로 막는 누락이 없어야 한다.

## 9. 개발·QA 전달 기준

## 11. 설정을 마친 영역은 접는다 (2026-10-29 사용자 결정 — 렌더 목업 확인)

### 11.1 공통 원칙
- 처음 한 번 하는 설정(영역 지정·판독 확인·영역 안내)과 평소 쓰는 조작(표시·잠금·알림)을 같은 무게로 깔지 않는다. 최적화 화면처럼 평소 쓰는 것만 보이게 한다.
- **지정 전**: 화면 맨 위 `영역 지정` 상자 — `● 아직 지정 안 됨 — 지정하면 …` (주황) + 버튼(자동 찾기·직접 지정·지정 영역 보기·지정 해제) + 안내 **한 줄** + 판독 확인(미리보기).
- **지정 후**: 한 줄 요약 + 접힌 `영역 다시 지정 ▸`(또는 `영역 다시 지정 · 판독 확인 ▸`). 버튼·안내·판독 확인·영역 관련 세부 조정은 모두 그 안에.
  요약 줄 = 버프·디버프는 기존 상태 줄(상태 아이콘 B안 + `추적 중 — 버프 N개 표시` 등, 게임 비활성·기준 버프 미검출 등도 이 줄에서 바뀜, 별도 상태 줄은 없앰),
  그 밖의 화면은 `✓ 영역 지정됨 · <현재 판독 값>`(예: `생명력 82% · 마나 64% · 스태미나 100%`, `도르카 12/15 · 투아림 87%`, `식별: … · HP 72%`, `판독 시간 14:52 · 보스명`).
- 지정(자동 찾기·직접 지정)을 막 마친 직후에는 그 세션 동안 펼친 채 두어 판독 확인을 볼 수 있게 하고, 다음에 탭을 열 때부터 접는다. 지정 해제하면 다시 `영역 지정` 상자로.
- 긴 회색 설명은 도움말로 옮기고 화면에는 한 줄만. 잠금 버튼은 상태형 하나(`위치 잠금됨` 초록 ↔ `위치 잠금`)로, 잠금 의미 설명 줄은 두지 않는다.
- 진단·수집은 10절대로 맨 아래 접힘. 앞으로 새 화면도 이 원칙을 따른다.

| 보스 패턴(체력별 패턴) | 영역(공통). `패턴 경고`·`남은 패턴 목록` 두 상자를 `화면 표시` 하나로: 1줄 `패턴 경고 [경고 위치 잠금됨] [알림 미리보기]`, 2줄 `[✓] 남은 패턴 목록 표시 [목록 위치 잠금]`. 잠금 설명 줄 삭제. 지원 보스 상자(• 없이)는 진단 바로 위 유지 |

| 체력바 | 영역(공통, 판독 확인은 접힌 안). `표시`: 1줄 `표시할 바 [✓]생명력 [✓]마나 [✓]스태미나 … [위치 잠금됨]`(전체 잠금/해제·바별 잠금 5개 → 하나), 2줄 `표시 배율 · 수치 정렬`, 접힌 `바마다 따로 잠그기 ▸`. **표시 미리보기(바 3개 그림) 삭제**. `낮은 수치 알림 · 보스전`: 체크·% 한 줄 + `소리 알림` + 오른쪽 회색 `보스 체력바가 보일 때만 동작해요`(설명 문단 삭제) |

| 커스텀 오버레이 | `[✓] 커스텀 오버레이 사용`. `프리셋` 상자: 1줄 `[프리셋 선택] [불러오기] … [프리셋 관리]`, 2줄 `현재: <이름> · 바꾸면 자동 저장돼요 … [다른 이름으로 저장…]`(안내 2줄 삭제). `오버레이`: 비었을 때는 표·버튼 대신 점선 안내 `아직 오버레이가 없어요. ‘복제할 영역 추가’로 …`; 있을 때 `[＋ 복제할 영역 추가] … [전체 위치 잠금됨]` + 표 + `선택 삭제`(빨강). 선택/전체 × 잠금/해제/삭제 6버튼 → 2개. **표의 `위치 잠금` 칸을 누르면 그 오버레이만 잠금/해제(신규 동작)**, 안내 한 줄 `표의 위치 잠금 칸을 눌러 하나씩 잠그거나 풀 수 있어요. 잠금을 풀면 마우스 휠로 크기를 바꿀 수 있어요.` |
| 블랙박스 | 1줄 `[블랙박스 사용(중)] ● 상태`(꺼짐 `● 꺼짐 — 켜면 최근 영상을 계속 보관해요` 회색 / 켜짐 `● 보관 중 3:12 / 5분 · 전투 녹화` 초록, 기존 `현재 상태` 상자 흡수). `보관과 저장`: **1줄 `최근 보관 시간 [5분] | 저장 단축키 <키> [변경]`**(사용자 아이디어), 2줄 `[지금 최근 영상 저장] 최근 저장: …`, 안내 한 줄. `녹화 방식`: 라디오 + 고른 방식 설명 한 줄만. `저장 위치`: 경로 + `[변경] [폴더 열기]` 한 줄. 접힌 `저장 내역·복구 ▸`. 맨 아래 회색 한 줄(자원·약 450MB · 게임 화면만 1080p/60FPS · 소리 저장 안 함) |

- 단축바·메모·최적화·FPS·파티 모집·계산기·설정은 이번 대상 아님(이미 단순하거나 다른 원칙으로 정리됨).
- 렌더 기준: 기획 세션 목업(지정 전/후, 블랙박스 꺼짐/켜짐, 커스텀 비어 있음/있음). 구현 후 같은 상태로 다시 렌더해 확인한다.

## 12. 던전을 고르는 계산기는 첫 던전이 선택된 채 열린다 (2026-10-29 사용자 결정)

- 편의기능의 던전 목록이 있는 두 계산기를 같게 맞춘다. 던전 입장 계산기는 이미 첫 던전(크롬바스 심연)이 선택돼 있고,
  **환전비율 계산기는 지금 `던전을 선택하세요` 빈 상태**로 열린다 → 첫 던전(목록 맨 위, 현재 탈라가흐)이 선택된 채로 연다.
- 환전비율 계산기는 던전을 고르면 경매 시세를 조회한다. 기존 원칙("앱 초기화 때 모든 탭이 생성된다는 이유로 가격을 미리 요청하지 않는다",
  [균열 자동 조회 개발 전달 5절](qa/배포시간단축_균열시세자동조회_화면헤더통일_개발전달_20261020.md))을 지키기 위해,
  첫 선택은 **그 탭이 세션에서 처음 화면에 보일 때** 한다(앱 시작·탭 생성 때가 아님). 이후 동작은 사용자가 직접 고른 것과 같다
  (10분 세션 캐시, 중복 요청 1개, 키 없음·오류 안내, 새로고침 유지).
- 사용자가 다른 던전을 고른 뒤에는 그 선택을 존중한다(이번 세션 동안). 선택을 디스크에 저장하지 않는다(기존과 같음).

## 13. 화면 마무리 다듬기 (2026-10-29 사용자 결정, 0.28.1 — 0.28.0 실화면 피드백, 렌더 목업 확인)

1. **잠금 버튼 통일**: 글자는 `위치 잠금됨` / `위치 잠금`만(무엇의 위치인지는 줄 앞 이름이 알려 줌 — `경고 위치 잠금됨`·`목록 위치 잠금됨`·`카운트다운 위치 잠금됨` 폐지).
   한 번에 여러 개를 잠그는 버튼만 `전체 위치 잠금됨` / `전체 위치 잠금`(체력바·단축바·커스텀 오버레이). **잠금 버튼은 같은 종류끼리 같은 폭**(일반 `위치 잠금(됨)` = 보통 굵기 `위치 잠금됨` 글자 + 여백, `전체 위치 잠금(됨)` = 그 글자 + 여백). 굵기 보통, 높이는 일반 버튼과 같게(옆 `알림 미리보기`와 같은 키), 켜짐 초록·테두리 유지. 같은 스타일의 사용 토글(최적화 `추천 설정으로 최적화`·`FPS 표시`·`블랙박스 사용`)도 같은 톤(폭은 글자에 맞춤). (2026-10-30 Windows 실화면 피드백 B안 정정 — 처음의 128px 고정·굵게는 옆 버튼보다 커 보여 폐지.)
   한 상자 안 여러 줄은 줄 앞 이름 칸 폭을 맞춰 잠금 버튼이 같은 세로선에 서게 한다.
2. **보스 패턴 `화면 표시`**: `패턴 경고 [위치 잠금됨] [알림 미리보기]` / `패턴 목록 [위치 잠금] [ ] 표시`(표시 여부 체크를 잠금 뒤로, `남은 패턴 목록 표시` 문구 폐지). 1분 헤일로(`다음 헤일로` / `헤일로 경고`)와 같은 줄 구성. (2026-10-29 사용자 결정 정정: 이름 칸 폭은 **상자마다** 가장 긴 이름에 맞춰 상자 안 잠금 버튼만 같은 세로선 — 화면끼리 버튼 위치를 맞추면 보스 쪽 이름 뒤가 20px로 벌어져, 다른 화면과 같은 이름 뒤 간격(약 8px)을 우선.)
3. **체력바**: 위 잠금 `전체 위치 잠금됨`(세 바 모두 잠기면 됨, 하나라도 풀리면 `전체 위치 잠금`), 접힌 메뉴 이름 `바마다 따로 잠그기` → `생명력·마나·스태미나 따로 잠그기`(펼치면 바별 `위치 잠금됨`).
   `낮은 수치 알림 · 보스전` 상자의 `보스 체력바가 보일 때만 동작해요`는 `소리 알림` 오른쪽 끝에서 **상자 첫 줄**로.
4. **투아림 알림 여백**(도르카·투아림): `첫 알림 / 추가 알림` 줄이 옮겨 온 그룹 상자의 안쪽 기본 여백 때문에 들여쓰기·간격이 다르고 `추가 알림`이 가로 절반 지점에 떨어져 있음 →
   안쪽 여백 0, `추가 알림`을 `첫 알림` 바로 옆(일정 간격)으로, 줄 간격을 다른 상자와 같게(체력바 알림 줄과 같은 방식).
5. **단축바·메모도 11절 접기 적용**(11.2에서 대상 밖으로 뺐던 것을 정정 — 다른 화면과 통일감):
   - 단축바: 지정 전 `영역 지정` 상자 / 지정 후 `✓ 영역 지정됨` + `영역 다시 지정 ▸`. 맨 위 긴 안내 문단은 영역 상자 안 한 줄로.
     `전체 잠금`·`전체 잠금 해제` 두 버튼 → `전체 위치 잠금됨` 하나. 표시 상자: `표시 배율 … [전체 위치 잠금됨]` / `기본 배치 [중앙 하단(기본)] [중앙 2단] [블록 분리]` / 안내 한 줄.
   - 메모: 판독이 아니라 띄울 자리라 지정 후 `✓ 표시 위치 지정됨` + `표시 위치 다시 지정 ▸`. 잠금은 같은 폭 `위치 잠금됨`, 잠금 설명 줄 삭제. 편집기는 그대로.
6. **설정 › 제작자 잡담**: `제작자 잡담 사용` 체크를 **숨기고 잡담은 항상 켬**(사용자: 나오든 말든 신경 쓸 사람이 없음). `잡담 소리 사용` 체크만 남기고 항상 조작 가능하게.
   예전에 끈 사용자(`creatorDialogue=false`)도 켜진 것으로 다룬다. 잡담이 켜지면 창이 864(제작자 캐릭터 줄)인 기존 동작 그대로(화면이 작으면 기존 높이 제한).
7. **홈의 `영역 지정 필요` 기준(사용자 재결정 — 지금 동작 유지, 개발 변경 없음)**: 처음엔 어떤 기능인지 몰라 고르지 않았을 수 있으므로,
   **줄(칸)은 고르지 않은 기능이라도 영역이 없으면 노랑 `영역 지정 필요`로 알려 준다**(0.28.0 그대로). 위쪽 `설정이 필요한 기능` 경고 상자와 상태 카드의 `M개 설정 필요`만
   첫 사용 안내에서 고른 기능(`setupSelection`) 기준(0.28.0 그대로). 메모처럼 고를 수 없는 기능은 칸에서만 노랑. 앞서 정한 A안(회색 `설정 안 함`)은 취소.

8. **조작 모양 규칙(2026-10-30 사용자 결정 A안 — 표시 여부를 버튼으로 바꾸지 않음, 개발 변경 없음)**. 앞으로 새 화면도 이 표를 따른다.

   | 종류 | 모양 | 예 |
   |---|---|---|
   | 위치 잠금(상태가 한눈에 보여야 함) | 같은 폭 상태형 버튼(초록 `…잠금됨` / 회색) | `위치 잠금됨`, `전체 위치 잠금됨` |
   | 켜고 끄는 옵션(표시·소리·사용) | 체크박스 | `표시`, `소리 알림`, `투아림 알림 사용`, `생명력/마나/스태미나` |
   | 홈 화면의 기능 켜기/끄기 | 스위치 | 홈 각 줄 |
   | 바로 실행하는 동작 | 일반 버튼 | `알림 미리보기`, `자동 찾기`, `직접 지정` |

   근거: 표시까지 초록 버튼이면 `표시 중`·`위치 잠금됨`이 나란히 초록이라 글자를 읽어야 구분되고("초록 버튼 = 잠금" 규칙이 깨짐),
   줄 맞춤(이름 → 잠금 → 기타)이 어긋남. 여러 개 중 고르는 옵션은 어차피 체크라 완전한 통일도 안 됨(기획 세션 A/B 렌더 비교).
