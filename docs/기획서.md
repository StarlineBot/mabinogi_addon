# 마비노기 버프·디버프 트래커 기획서

> 2026-10-06 기획 확정분. 변경 시 이 문서를 갱신한다.

## 1. 개요

마비노기(공식 API 없음)의 화면을 실시간으로 분석해서

- **버프**: 상태목록창에서 등록한 버프를 찾아 남은 시간을 읽고, 지정한 위치에 오버레이로 가로 나열한다. 연장이 필요한 시점에 알림을 준다.
- **디버프**: 보스 체력바 위 디버프 줄에서 등록한 디버프를 찾아, **아직 걸리지 않은 디버프만** 오버레이로 보여준다.

화면을 **읽기만** 한다. 키 입력·클릭 자동화, 메모리 읽기는 하지 않는다 (넥슨 보안 모듈 탐지 대상).

## 2. 게임 화면 구조 (스크린샷 분석 결과)

### 2.1 버프 상태목록창 (화면 오른쪽)

- 한 행 = `[아이콘] 이름 ......... 남은시간`. 아이콘·이름은 왼쪽 정렬, 시간은 오른쪽 정렬.
- 목록이 **그룹으로 나뉘고 그룹 사이에 구분선·여백**이 있다 → 행 높이로 균등 분할 불가.
  - 위 그룹: 시간 없음 / 가운데 그룹: 시간 있음 / 아래 그룹: 시간 없음
- 시간 표기: `일 / 시간 / 분 / 초` 한글 단위 혼합. 예) `1분 20초`, `1시간 46분 59초`, `5일 21시간 34분`
- 시간 글자색: 흰색, 임박 시 빨간색.
- **30초 이하에서 아이콘이 점멸 + 반투명**해진다. 그 전에는 아이콘 투명도 없음.
- 창 배경이 반투명 → 뒤 게임 화면이 비친다.
- 맵 이동·스킬 이펙트로 화면이 순간적으로 까매지거나 하얘지는 경우가 잦다.
- **"프리미엄 배틀 멤버십"** 버프는 항상 존재하고 지속시간이 없다 (점멸 안 함) → 앵커로 사용.

### 2.2 보스 디버프 (화면 하단, 보스 체력바 바로 위)

- 작은 아이콘이 가로로 나열되고, 아이콘 아래에 시간 (`4M`, `2M`, `19`, `43` …: 분은 M, 초는 단위 없음).
- 디버프가 걸리고 풀릴 때마다 가로 위치가 바뀐다.
- 보스 체력바 위치는 고정.

## 3. 기능 명세

### 3.1 버프 트래커

| 항목 | 내용 |
|---|---|
| 입력 | 사용자가 지정한 상태목록창 영역 |
| 탐지 | 아이콘 열(x 고정, 세로 띠)에서 등록 아이콘을 템플릿 검색 → 매칭된 y의 오른쪽 시간 영역을 판독 |
| 표시 | 등록 순서대로 **매칭된 버프만** 빈칸 없이 왼쪽부터 가로 나열 |
| 표시 아이콘 | 등록한 표시 아이콘 → 없으면 매칭 아이콘(또는 처음 매칭 시 캡처본) |
| 지속시간 | 버프별 표시 여부 선택. 켜면 아이콘 아래 표기 |
| 알림 | 버프별 사용 여부·기준 초(기본 30초)·점멸·소리 |
| 앵커 | 버프 하나를 앵커로 지정(기본: 프리미엄 배틀 멤버십). 오버레이에는 표시 안 함 |

표시 예) 등록 `A B C D E F G`
- `A B E F` 켜짐 → `[A][B][E][F]`
- `C D G` 켜짐 → `[C][D][G]`

지속시간 표기 (축약):

| 남은 시간 | 표기 |
|---|---|
| 1일 이상 | `5d` |
| 1시간 이상 | `1h46m` |
| 1분 이상 | `3:28` |
| 1분 미만 | `28s` |

지속시간 표시를 끈 버프도 아래 글자 칸은 비워 둬서 아이콘 높이를 맞춘다.

### 3.2 디버프 트래커

| 항목 | 내용 |
|---|---|
| 입력 | 사용자가 지정한 디버프 줄 영역 (가로는 체력바 폭만큼 넉넉히) |
| 탐지 | 영역 안에서 등록 아이콘을 가로 검색 |
| 표시 | 등록 순서대로 **매칭되지 않은 디버프만** 가로 나열. 오버레이는 항상 표시 |
| 앵커 | 없음 (보스가 없으면 "전부 안 걸림"으로 보이는 게 의미상 맞음) |
| 안정화 | 숨김은 즉시, **다시 표시는 1.5~2초 연속 미감지일 때만** |
| 지속시간·알림 | 없음 |

### 3.3 알림 (버프 연장 타이밍)

- 별도의 "버프 연장" 기능이나 수동 TTL 입력은 만들지 않는다. **연장이 필요한 시점에 알림만** 준다.
  - 마비노기에서 "다시 걸기"와 "연장"은 같은 의미(지속시간을 늘림)로 쓰이므로, 알림 문구는 "연장"으로 통일한다.
- 조건: 내부 시계 기준 남은 시간 ≤ 버프별 기준값 → **아이콘 점멸 + 알림음 1회**.
- 남은 시간 증가 감지 = 연장 성공 → 알림 자동 해제.
- 버프 사라짐 = 연장 실패 → 점멸 종료, 표시 제거.
- Windows 토스트 알림은 쓰지 않는다 (게임 중 방해 금지 모드로 묻힘).
- 지속시간 표시를 끈 버프는 알림 설정 불가.
- 확장 여지: 단계별 알림(예: 30초 점멸, 10초 점멸+소리).

#### 알림음 방식 (기본음 / TTS)

전역 설정으로 알림음 방식을 고른다.

- **기본음**: Windows 기본 알림음 1회.
- **TTS**: `"{버프 이름} 연장"`을 음성으로 읽는다. 어느 버프가 임박했는지 화면을 안 봐도 알 수 있다.

TTS는 **생성과 재생을 분리**해 매번 합성하지 않는다 (개인용·배포용 공통으로 유리).
캐싱 덕분에 생성 엔진이 느리거나 온라인이어도 런타임 비용은 없으므로, 품질 좋은 엔진을 쓸 수 있다.

- **엔진·음성은 개발 단계에서 고정 결정**한다. 사용자 UI로 노출하지 않는다(개인용이라 불필요).
  - 후보: Windows 내장 SAPI5(오프라인, 품질 보통) vs Edge-TTS 뉴럴(`ko-KR-SunHiNeural` 등, 품질 높음, 생성 시에만 네트워크).
  - 선택한 엔진·음성은 코드 상수로 둔다. (추후 바꾸고 싶으면 상수만 수정)
- **생성(드물게)**: 설정 저장/앱 시작 시, 알림+TTS가 켜진 버프마다 `"{이름} 연장"` 음성을 **WAV 파일로 캐시**한다.
  - SAPI는 `win32com`의 `SAPI.SpVoice` + `SpFileStream`로 생성(새 의존성 없음). Edge는 edge-tts로 생성.
  - 캐시 키 = `(읽을 문자열, 엔진, 음성)`. 셋 다 그대로면 재생성하지 않고, 하나라도 바뀌면 다시 굽는다(옛 파일은 정리).
  - 캐시 위치: 설정 옆 `tts_cache/` (pathlib).
- **재생(자주)**: 알림 시 캐시 WAV를 `winsound.PlaySound(SND_ASYNC)`로 비동기 재생. SAPI를 호출하지 않아 탐지 스레드(5ms 예산)에 영향 없음.
- **폴백**: 캐시 WAV 없음/생성 실패/한국어 음성 미설치 → 기본음으로 대체.
- 구조: 생성은 `TtsCache`(OS 의존부는 `system/`), 재생은 `Notifier`. 둘 다 맥에서는 스텁(파일 없음·print)으로 동작해 테스트 가능해야 한다.

### 3.4 오버레이

- 항상 위, 배경 투명, **클릭 통과**(`WS_EX_TRANSPARENT | WS_EX_LAYERED`), 포커스 안 뺏음(`WS_EX_NOACTIVATE`).
- 위치 편집 모드에서만 드래그 이동 가능.
- 버프/디버프 각각 **배율 50~300%**. 표시에만 적용, 탐지와 무관.
- 아이콘 확대 방식 기본값: Nearest (작은 아이콘을 선명하게). Bilinear 선택 가능.
- 지속시간 글자는 폰트로 직접 그린다.
- **마비노기가 포그라운드일 때만 표시**. 자기 프로그램 창(설정 창, 편집 모드 오버레이)도 활성으로 간주.

### 3.5 파티모집현황 + 키워드 알림

섯다라인 디스코드 봇의 "인게임 파티모집현황 / 키워드 알림" 기능을 이 앱으로 옮긴 것.
버프/디버프와 달리 **화면 캡처가 아니라 넥슨 공식 오픈 API를 읽는다** → "읽기만 한다" 규칙에 부합하고,
맥에서도 테스트 가능하다(네트워크만 있으면 됨).

#### 데이터 출처

- 넥슨 오픈 API 거뿔(월드 외침) 기록:
  `GET https://open.api.nexon.com/mabinogi/v1/horn-bugle-world/history?server_name=하프`
  헤더 `x-nxopen-api-key: {키}`. 응답 `horn_bugle_world_history[]`: `message`, `character_name`, `date_send`.
- **서버는 하프 고정.**
- **API 키는 비밀**. `.env`의 `NEXON_API_KEY`로 관리하고 git에 커밋하지 않는다(`.env.example`만 커밋).
  배포판에선 설정 탭 입력란 → 로컬 설정(`config.local.json`)에 저장. 키 탐색 순서: `.env` → 로컬 설정.
- 폴링 주기 약 10초(봇과 동일). 백그라운드 스레드에서, UI를 막지 않는다.

#### 파티모집 파싱

- 파티모집 = `message`가 `"{character_name} : #"`로 시작하는 외침.
- 형식: `"{캐릭명} : #[채널N] 내용 [현재/모집명]완?"`
  - `채널N` = 채널 번호, `내용` = 제목(채널·인원·완 제거), `[현재/모집]` = 인원, `완` 또는 현재==모집 → 완료.
- 현황 리스트: **사람당 최신 1건**만, 최신순 상위 N개(기본 5).

#### 파티 탭 (신설)

- 리스트 한 행 = `채널 | 파티장 | 제목 | 인원`. **인원은 오른쪽 정렬.** 완료 파티는 표시(✅) 또는 흐리게.
- 키워드 등록/삭제 UI(1인용이라 목록 하나). 매칭 대상은 **제목(내용)**.

#### 키워드 매칭 → 토스트 알림

- 폴링마다 **최근 5분 이내** 신규 모집에서, 제목에 등록 키워드가 포함되면 알림.
- 중복 억제: **5분 슬라이딩 TTL + 서명(채널 + 숫자·캐릭명 제거한 내용)** → 파티당 1회. (봇의 `partyAlerts` 로직 그대로)
- **토스트**: 직접 그리는 프레임리스 창(네이티브 Windows 토스트 아님 → 위치·지속·최상위를 완전히 제어, 집중지원 모드에 안 묻힘).
  - 위치 **화면 우측 하단**, **항상 최상위**, **3초 후 자동 소멸**.
  - **클릭하면 즉시 닫는다**(dismiss). 할 동작이 없으므로 수동으로 치울 수 있게만 한다.
- 참고: 3.4의 "Windows 토스트 안 씀"은 **전투 중 버프 만료 알림** 맥락이다. 파티 알림은 전투 중이 아니므로 토스트를 쓴다(별개 규칙).
- (옵션, 봇에 있음) 알림 받을 **시간대 설정** — 추후 확장.

## 4. 탐지 설계

### 4.1 파이프라인

```
FrameSource(캡처) → Detector(이미지 → 판정) → Tracker(상태 머신 + 내부 시계) → Overlay / Notifier
```

- `FrameSource` 인터페이스로 캡처를 분리한다.
  - `FileFrameSource`: 스크린샷 폴더 (맥 개발)
  - `VideoFrameSource`: 플레이 영상 (맥 개발)
  - `LiveCaptureSource`: dxcam 영역 캡처 (Windows)
- `WindowWatcher` 인터페이스로 포그라운드 감지를 분리한다.
  - `WindowsWatcher`: `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` 이벤트 방식
  - `AlwaysActive`: 맥 개발용

### 4.2 아이콘 매칭

- `cv2.matchTemplate` + `TM_CCOEFF_NORMED` (밝기·대비의 선형 변화에 강함 → 반투명, 단색 배경 대응).
- 템플릿은 시작 시 한 번만 전처리해서 메모리에 올린다.
- 등록과 탐지가 같은 좌표 규칙으로 아이콘을 자르도록 한다 ("상태창에서 가져오기").

### 4.3 시간 판독

- 범용 OCR(Tesseract/EasyOCR) 사용 안 함.
- 숫자 0~9와 단위(`일`, `시간`, `분`, `초`) 템플릿 매칭. 디버프용 `M`도 필요 시 추가.
- 밝기 기준 이진화 후 매칭 (흰색·빨간색 글자 모두 대응).
- 매칭된 행에서만, 1초 주기로 판독.

### 4.4 프레임 판정 3상태

| 결과 | 조건 | 처리 |
|---|---|---|
| 감지 | 아이콘 매칭 | 활성 유지, 시간 갱신 |
| 미감지 | 정상 프레임인데 아이콘 없음 | 사라짐 후보 카운트 |
| 판정 불가 | 앵커 미검출, 게임 비활성 | 상태 동결, 내부 시계만 진행 |

보조 판정 불가 조건: 영역 밝기 극단값(블랙아웃·화이트 플래시), 여러 버프 동시 소멸.

### 4.5 버프 상태 머신

```
[없음] ──N프레임 연속 감지──▶ [활성] ──남은시간 ≤ 기준──▶ [만료임박: 점멸+소리 1회]
  ▲                              │  ▲                          │
  └── 사라짐 판정 ───────────────┘  └── 시간 증가(연장) ────────┘
```

- **점멸 대응**: 최근 1~1.5초 프레임의 매칭 점수 중 **최고값**으로 판정. 캡처 주기는 점멸 주기보다 충분히 짧게(0.1~0.2초), 에일리어싱 주의.
- **추적 유지**: 이미 추적 중인 버프는 같은 행 시간 글자가 정상적으로 줄어들면 생존으로 본다. 목록이 당겨질 수 있으므로 기억한 y 주변을 재검색, 화면 복귀 후엔 아이콘 열 전체 재검색.
- **내부 시계**: 마지막 정상 판독값 − 경과 시간으로 계속 카운트다운. 알림은 내부 시계 기준이라 화면이 안 보여도 울린다. 판독값이 크게 늘면 연장으로 보고 보정.
- **사라짐 판정**:
  1. 내부 시계 ≤ 0 이고 정상 프레임에서 미감지 → 만료
  2. 내부 시계는 남았는데 정상 프레임에서 2초 이상 연속 미감지, 다른 버프는 보임 → 중간 해제
  - 판정 불가 구간만으로는 사라짐 처리하지 않는다.

### 4.6 앵커

- 앵커 매칭 = 정상 프레임, 실패 = 판정 불가.
- 앵커는 설정에서 변경 가능(`anchor: true`, 하나만).
- 앵커가 30초 이상 안 보이는데 다른 버프는 매칭되면 "앵커 미검출" 경고 (멤버십 만료 대비).

### 4.7 게임 비활성 시

| 항목 | 동작 |
|---|---|
| 화면 탐지 | 정지 (판정 불가) |
| 내부 시계 | 계속 진행 |
| 오버레이 | 숨김 |
| 소리 알림 | 울림 (설정으로 끌 수 있음) |

## 5. 화면 구성

### 5.1 메인 창 (탭: 버프 / 디버프 / 설정)

```
┌─ 마비노기 버프 트래커 ─────────────────────────────────────────────┐
│ [버프] [디버프] [설정]                                 ● 실행 중 ■ │
├────────────────────────────┬───────────────────────────────────────┤
│ [ 버프 영역 지정 ]          │  이름                                 │
│  영역: 1770,400 220×550 ✔  │  [ 마법 대미지 증가          ]        │
│ ┌────────────────────────┐ │  매칭 아이콘                          │
│ │ ⚓ 배틀 멤버십 (앵커)   │ │  [▣]  [ 상태창에서 가져오기 ]         │
│ │ ▣ 마법 대미지 증가     │ │  보여줄 아이콘                        │
│ │ ▣ 골렘의 의지          │ │  [▣]  [ 파일 선택 ] [ 초기화 ]        │
│ │ ⚠ 새 버프 (아이콘 없음) │ │   └ 비워두면 매칭 아이콘 사용        │
│ └────────────────────────┘ │  ☑ 지속시간 표시                      │
│  [+] [-] [▲] [▼]           │  ☑ 종료 알림 [ 30 ]초 전  ☑점멸 ☑소리 │
│                            │  ☐ 앵커로 사용 (항상 있는 버프)        │
└────────────────────────────┴───────────────────────────────────────┘
```

- `+` 맨 끝에 추가 후 선택, `-` 삭제(확인), `▲▼` 순서 이동, 드래그 앤 드롭 지원.
- 기본 순서 = 등록 순서. 순서는 설정 파일 **배열 순서**로 저장 (별도 order 필드 없음).
- 변경 즉시 자동 저장 + 오버레이 반영.
- 디버프 탭: 이름, 매칭 아이콘("영역에서 가져오기"), 보여줄 아이콘만.

### 5.2 영역 지정

- 버튼 → 전체화면 반투명 오버레이 → 드래그 → 좌표 저장. ESC 취소.
- Windows에서는 시작 시 DPI 인식(`SetProcessDpiAwareness(2)`)을 켜서 모든 좌표를 실제 픽셀로 통일.
- 확장: 마비노기 창 기준 상대 좌표로 저장 (창 이동 대응).

### 5.3 설정 탭

```
[일반]
 ☑ Windows 시작 시 자동 실행
 ☑ 실행 시 트레이로 시작
 ☑ 닫기(X) 버튼을 누르면 트레이로 최소화
 ☑ 게임 비활성 중에도 소리 알림
[오버레이]
 버프 배율 [150%]  디버프 배율 [100%]  아이콘 확대 방식 [Nearest]
 [ 오버레이 위치 편집 ]
[게임]
 마비노기 창 식별 [ ... ] [ 자동 찾기 ]
```

- 자동 실행: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에 `"<exe 경로>" --tray`. 실행할 때마다 현재 exe 경로로 갱신.
- 트레이 메뉴: 열기 / 탐지 시작·정지 / 오버레이 위치 편집 / 종료. 더블클릭으로 창 열기.
- **중복 실행 방지**: 이미 실행 중이면 새 프로세스는 종료하고 기존 창을 띄운다 (`QLocalServer` 또는 named mutex).

## 7. 비기능 요구사항 (성능)

| 항목 | 목표 |
|---|---|
| CPU | 평균 1~2% 이하, 게임 비활성 시 거의 0% |
| 메모리 | 80~150MB |
| 탐지 1회 | 5ms 이하 |

- 지정 영역만 캡처.
- 주기: 버프 아이콘 0.2초 / 시간 판독 1초 / 디버프 0.3~0.5초 / 비활성 시 정지.
- `cv2.setNumThreads(1)`, `OMP_NUM_THREADS=1` (작은 이미지에서 멀티스레드는 오히려 CPU 스파이크).
- 탐지는 백그라운드 스레드 1개, 오버레이는 상태가 바뀔 때만 다시 그림. 점멸 타이머는 알림 중일 때만.
- 프로세스 우선순위 BELOW_NORMAL.
- `opencv-python-headless` 사용 (일반판은 PySide6와 Qt 충돌).
- 프레임 이미지는 보관하지 않고 점수만 링버퍼에 보관. 캡처 버퍼 재사용.
- 설정 탭에 숨김 디버그 패널 (처리 시간 ms, fps, CPU %, 메모리).

## 10. 준비할 테스트 데이터 (원본 해상도 PNG, 영상은 git 제외)

1. 상태목록창 스크린샷 여러 장 (버프 구성 다양하게)
2. 30초 이하 점멸 구간 영상 (10~20초)
3. 맵 이동·화면 플래시 순간 영상
4. 보스전 디버프 줄 스크린샷 (많을 때 / 적을 때 / 없을 때)
5. 시간 표기 예시 (`일`, `시간`, `분`, `초`, 빨간 글씨)
6. 게임 해상도, UI 배율 설정값

## 11. 미확인 사항

1. 상태창 투명도 옵션 유무
2. 점멸 시 시간·이름 글자도 같이 점멸하는지, 점멸 주기
3. 빨간 글씨가 몇 초 이하부터인지
4. 디버프 아이콘도 점멸하는지, 같은 디버프가 여러 개 뜰 수 있는지
5. 디버프가 많을 때 체력바 폭을 넘거나 두 줄이 되는지
6. 상태목록창이 넘칠 때 스크롤되는지
7. 같은 아이콘을 쓰는 다른 버프가 있는지
8. 게임 UI 배율 옵션 유무
9. 마비노기 창 제목·프로세스 이름
