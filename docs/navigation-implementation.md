# 전투 보조 2단 탭 구조 개발 검증

## 승인 및 구현 범위

- 기준: `navigation-structure-spec.md`. 사용자가 좌측 탐색 목록 대신 2단 가로 탭 시안을 승인했다.
- 상위 순서: 전투 보조 / 파티 모집 / 편의기능 / 설정.
- 전투 보조는 버프 / 디버프 / 투아림 / 보스 패턴 알림 / 체력바 / 도르카 /
  커스텀 오버레이 / 단축바 / 메모 순서다. 체력바와 커스텀 오버레이 앞에 작은 구분선을 그린다.
- 기존 하위 탭의 글자 크기를 유지하고 좌우 여백만 14px에서 9px로 조정한다.
  본창 폭 790, 본문 가용 폭 및 기존 두 열 편집/큰 글꼴 예외는 바꾸지 않는다.
- 편의기능은 기존 계산기 세 개를 기존 순서로 유지한다. 새 페이지/워커/오버레이를
  만드는 것이 아니라 초기 생성 시 기존 기능 위젯을 새 위치에 한 번 배치한다.
- `_combat_pages`는 기능 키와 실제 스크롤 위젯을 연결한다. 안내의 기능 열기는 숫자
  하위 인덱스를 해석하지 않는다. 알 수 없는 키/종료/재시작 대기 중 요청은 화면을 바꾸지 않는다.
- 탭 이름에서 도르카의 베타 표기만 제거한다. 로그인 및 사용 ON 조건, 원본 영역 등록,
  캡처/판독/알림/게임 창 감지와 저장 형식은 유지한다. 기능 선택만으로 사용 설정을 바꾸지 않는다.

## 투어

- 일곱 단계는 각각 진입 함수를 실행한다. 개별 설정/잠금은 버프를 선택하고 해당 컨트롤까지
  스크롤한다. 전체 일시정지는 버프 화면, 설정은 실제 접근 가능한 다시 보기 버튼을 준비한다.
- 강조 영역은 대상의 현재 보이는 영역과 화면 안으로 제한한다. 화면 밖 전체 위젯을 강조하지 않는다.
- 완료/건너뛰기 후 단계별 안내 출발은 버프, 다시 보기 출발은 진입 전 상위 탭과 기능 선택으로 복귀한다.
- 완료 기록은 `tourShown`만 저장한다. 기능 사용/등록/잠금/전체 정지 값은 바꾸지 않는다.
- 창 숨김/종료는 투어를 닫되 완료 콜백/복귀를 실행하지 않으며 창을 다시 보이지 않는다.
- 기존 로그인 해제 처리와 투어 중 제작자 잡담 제외 정책은 유지한다.

## 함께 확인한 미리보기 결함

실제 Qt 화면을 반복 전환한 렌더에서 도르카 미리보기 뒤에 이전 체력바 설정 픽셀이 남았다.
게임 창용 투명 속성을 자식 미리보기에도 주던 것이 원인이다.
`DorchaOverlay`는 부모가 있으면 일반 배경을 채우고, 부모 없는 실제 게임 오버레이만
투명하게 유지한다. 판독/스케일/칸/클릭 통과 동작은 바꾸지 않는다.

## 검증 명령

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest tests/test_navigation.py tests/test_setup.py tests/test_tracker_layout.py tests/test_creator_dialogue.py -q --tb=short
PYTHONPATH=src:. QT_QPA_PLATFORM=offscreen .venv/bin/python scripts/render_navigation.py
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q -m 'not windows_integration'
```

- 기존 안내/레이아웃 검사 164개 통과. 관련 244개 통과 후 미리보기 배경 검사를 추가했으며,
  신규 탐색 검사 20개도 별도로 통과했다. 중복 실행을 합산한 고유 총계로 표현하지 않는다.
- 신규 검사는 9개 정확한 진입, 탭 복귀, 무효 요청, 현재 화면별 편집 활성, 미로그인 도르카,
  양방향 투어 단계/대상/카드 비겹침, 완료/건너뛰기 복귀, 숨김 정리 및 설정 불변성을 포함한다.
- 15회 전체 기능 순회에서도 자식 타이머/탭 객체 수와 저장 설정이 유지되는지 검사한다.
  이는 실제 Windows 핸들/GDI/게임 장시간 자원 추세 검증이 아니다.
- 실제 제품 렌더는 `/tmp/navigation-implemented/`에 9개 기능, 편의기능, 큰 글꼴,
  투어 7단계를 저장한다. 제품 탭을 교체하는 별도 모형이 아니라 구현된 MainWindow를 사용한다.
  임시 샘플 설정, 네트워크/캡처/오디오 경계를 적용하며 실제 장치나 사용자 설정을 쓰지 않는다.
- 전체 격리 회귀 **1,330 passed, 5 deselected, 3 warnings (327.07초)**.
  5건은 별도 Windows 네이티브 검사이며 경고는 기존 QMouseEvent 사용 경고다.
  이전 이미지/자동찾기/알림/도르카 재탐색/설정/종료 검사와 기존 QThread 누수 검사를 유지했다.
- 푸시 후 정확한 SHA의 Windows 테스트/필수 통합/exe 빌드는 별도로 확인한다.
  Linux Qt 렌더나 이전 SHA의 CI 성공을 새 Windows 실행 결과로 대신하지 않는다.
- 실제 혼합 DPI, Windows 작업 영역 전환과 장시간 실게임 동시 실행은 후속 검증 범위다.

원격 v0.4.81이 있으므로 사용자 변경 노트는 v0.4.82에 작성한다. 태그/릴리즈는 실행하지 않는다.
