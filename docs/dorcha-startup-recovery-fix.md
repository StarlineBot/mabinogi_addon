# 도르카 초기 실패 후 저장 영역 복구

- 날짜: 2026-10-18 (Asia/Seoul).
- 근거: `docs/qa/도르카_게임첫시작_판독지연_QA_20261018.md`.
- 함께 올라온 Windows 무료 한도 정책 QA는 추가 결함 없이 통과했다.
  Windows 워크플로/테스트 경계/누수 검사는 이번 변경에서 수정하지 않는다.

## 확인과 최소 수정

초기 저장 영역 검증과 전체 탐색이 실패하면 tracking_lost 상태에서 작은 영역도
확인하지 않았다. 전체 탐색의 벽시계 비용 20배 대기는 유지되므로 정상 화면이
같은 위치에 돌아와도 수십 초~수분 동안 읽지 않을 수 있었다.

원래 관측 도구를 수정 전에 실행해 **5 passed (4.84초)**로 지연 경로를 확인했다.
이는 정상 동작 합격 테스트가 아니라 주입한 탐색 비용에 따른 미판독 대기를 기록하는
도구다. 사용자 라이브의 첫 실패 원인까지 확정한 것은 아니다. 원본 도구는 수정하지 않았다.

- 추적 상실 중 워커가 없고 게임이 활성일 때 저장 위치를 최대 2초에 한 번 재검증한다.
- 힌트가 현재 등록된 게임 HWND/PID/창 경계 안에 있어야 한다. 힌트 크기는
  16,384픽셀 이하로 제한해 이 복구가 두 번째 전체 화면 탐색이 되지 않게 한다.
- 기존 초기 검증기를 그대로 써 장식과 현재 숫자가 함께 확인돼야 복구한다.
  검증 후 숫자 영역을 다시 캡처해 현재 숫자를 읽고, 캡처 중 대상이 바뀌면 거절한다.
- 숫자만 보이는 이전 좌표는 신뢰하지 않는다. 오래된 프레임이나 지난 관측을 표시하지 않는다.
- 매 틱 창/실행파일 조회를 추가하지 않는다. 실패한 국소 검사와 대상 조회 모두
  재검증 기한으로 제한하며, 전체 탐색의 비용 대기/한 워커/큐 없음 정책은 유지한다.
- 정상 복구는 메모리의 실행 중 영역만 갱신한다. 저장 설정/사용 체크/오버레이 위치는
  변경하지 않는다. 새 타이머/스레드/소리는 없다.
- 이동한 UI가 저장 위치에 없거나, 워커가 아직 실행 중이거나, 힌트가 너무 크면
  기존 전체 탐색을 기다린다. 모든 경우의 복구 최대 시간을 보장하는 변경은 아니다.

## 회귀 검사

`tests/test_dorcha_startup_recovery.py`는 QA의 실제 Qt/워커/원본 숫자 5/장식
재현 도구와 기존 캡처 경계 fixture를 사용한다. 비용 0.1/2/8/15초를 주입한 실패 후
정상 UI 복귀에서 새 전체 탐색 없이 5로 복구하는 것을 검사한다.
가짜 숫자만 남은 화면, 실패한 검사 후 100틱 무캡처/무대상조회, 큰 힌트/창 밖 힌트,
캡처 중 대상 변경 대조군도 포함한다. 기존 이동/종료/늦은 콜백/캡처 오류 검사는 유지한다.

- 초기 수정의 기존 도르카 관련 회귀: 107 passed (56.82초).
- 저장 위치 복구/초기 문맥/게임 대상/자원 통합/Windows 정책 검사: 72 passed (35.48초).
- 최종 추가 부정 대조군/도르카 탭/릴리즈 노트: 39 passed (12.95초).
- 최종 코드의 복구/이동/초기 문맥/게임 대상/숫자 판독: **110 passed (55.67초)**.
  실행: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest
  tests/test_dorcha_startup_recovery.py tests/test_dorcha_tracking.py
  tests/test_dorcha_roi_context.py tests/test_dorcha_game_target.py tests/test_dorcha_reader.py -q --tb=short`.
  검사 그룹 간 중복 조건은 고유 총계로 합산하지 않는다.

## 미검증 범위

Actions 무료 한도 차단에 따라 이번 일반 푸시의 Windows 실행을 시작하지 않았다.
실제 Windows 첫 실행/캡처/혼합 DPI/장시간 부하/네이티브 의존성/exe 빌드는 미검증이다.
Linux 원본 재생을 Windows 통과나 라이브 원인 확정으로 보고하지 않는다.
실제 게임에서 첫 실패 사유와 복구 동작 확인이 남아 있다. 태그/릴리즈는 하지 않는다.
