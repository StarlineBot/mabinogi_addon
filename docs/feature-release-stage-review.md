# 기능 공개 정책 및 투아림 표시 알파 분리

- 작성일: 2026-10-19
- 상태: 기획 확정. 도르카·체력바·단축바 기본 기능의 일반 공개, 자동찾기·자동설정·수집의 기존 제한 유지, 투아림 % 표시의 알파 분리와 최초 전환 시 1회 체크 해제를 사용자 승인받았다. 개발 및 독립 QA 전달용.
- 소스 확인 기준: 원격 main `6c3ce3cce94e2f38c02e824854c28ee4817134aa`.
- 목적: 투아림 % 표시만 제작자 전용으로 분리하고 세 기본 기능은 로그인 없이 사용할 수 있게 한다.
- 범위: 공개 정책과 설정 기본값의 확정 명세다. 앱 구현 변경, 신규 독립 QA 또는 릴리즈 승인이 아니다.

## 1. 공개 단계와 화면 문구 구분

- 기능 설명은 [공개용 문구 정리](feature-description-copy-spec.md)를 따른다. 단계 이름 제거와 실제 접근 제한 변경은 별개다.
- 일반 공개는 해당 기본 기능을 Discord 로그인 없이 허용한다는 의미다. 외부 API 키 등 기능에 본래 필요한 조건까지 없애는 뜻은 아니다.
- 알파는 제작자 전용이며 일반 베타 로그인 사용자도 대상이 아니다. 제작자 접근 통제는 헤일로와 일관되게 적용하고 로그인 여부만으로 허용하지 않는다.
- 공개 단계는 내부 정책으로 관리한다. 기본 기능 설명이나 배지에 반복 노출하지 않는다.
- 이 문서의 공개 범위와 최초 전환 정책은 이전 도르카·투아림 통합 명세 및 문구 정리 문서의 기존 권한 보존 규칙에 우선한다.

| 기능 | 공개 범위 | 포함 동작 |
|---|---|---|
| 도르카 15칸 바·수치 표시 | 일반 공개, 로그인 불필요 | 영역 직접 지정·보기·해제, 표시·이동·잠금·배율과 기존 자동 복구. 사용자가 누르는 자동찾기는 별도 제한 유지 |
| 생명력·마나·스태미나 체력바 | 일반 공개, 로그인 불필요 | 직접 지정·보기·해제, 표시·설정·소리/흔들림 경고. 자동찾기·수집은 별도 제한 유지 |
| 단축바 복제 표시 | 일반 공개, 로그인 불필요 | 첫 칸 직접 지정·보기·해제, 복제 표시, 기본 배치·이동·잠금·배율. 자동찾기는 별도 제한 유지 |
| 개별 자동찾기 | 기존 베타 접근 유지 | 현재 기능별 로그인 제한과 후보 승인·취소 유지 |
| 일괄 자동설정 | 기존 베타 접근 유지 | 여러 영역을 찾고 승인하는 실행은 로그인 필요. 첫 사용 안내의 기본 기능 선택·설명 전체를 로그인에 종속시키지 않음 |
| 수집·진단, 디버프 강제 탐지 방식 | 기존 접근 제한 유지 | 현재 기능별 접근 범위 보존. 헤일로 수집은 별도 제작자 전용 알파 규칙 적용 |
| 자원 오버레이의 투아림 % 표시 | 제작자 전용 알파 | 3절의 접근 제한과 1회 체크 해제 적용 |
| 믿음의 균열 헤일로 | 제작자 전용 알파 | 별도 기획안에 따른 시간 판독·수집·카운트다운·알림 검증 |

일반 투아림 알림, 일반 보스 패턴 알림, 버프·디버프 기본 추적은 현재 일반 기능이다. 새로 베타에서 제외할 대상으로 중복 분류하지 않는다. 공개 범위는 사용자 승인한 정책이며, 이번 세션에서 새 실게임 QA를 통과시킨 결과는 아니다.

## 3. 투아림 % 표시만 알파로 분리

### 3.1 대상과 유지할 동작

- 대상은 도르카 자원 오버레이에 추가된 `투아림 % 표시` 요소다. 도르카 바·숫자와 기존 투아림 임계 알림을 함께 알파로 바꾸지 않는다.
- 일반 사용자에게는 % 표시 체크를 노출하지 않고 오버레이에 해당 요소도 그리지 않는다. 일반 베타 로그인만으로 다시 노출하지 않는다.
- 제작자만 체크를 보고 켤 수 있다. 처음 사용하거나 설정이 없으면 체크되지 않은 상태로 시작한다.
- 저장값이 켜짐이어도 비대상 사용자의 실제 표시가 활성화되지 않아야 한다. UI를 숨기는 것만으로 접근 제한을 대신하지 않는다.
- 제작자 접근이 해제되면 % 표시만 중단한다. 도르카와 일반 투아림 알림을 함께 중단하지 않는다.
- 일반 사용자에게 알파 표기나 해당 체크·표시 요소만을 위한 빈 자리를 남기지 않는다. 앱 내부 표시 미리보기 구간 자체를 없애라는 요구는 아니다.
- 설정 화면의 투아림 원본 영역·원시/최근 확정값 확인과 일반 투아림 알림 설정은 유지한다. 모든 곳의 투아림 숫자를 숨기는 변경이 아니다.
- 기존 알림과 공유하는 투아림 영역·임계값·소리·안정화 상태를 알파 전환 때문에 삭제하거나 초기화하지 않는다.
- 표시 전환이나 권한 변경으로 같은 충전 주기 알림을 다시 발화시키지 않는다. 알파 표시 때문에 알림이 새로 켜지거나 꺼지지 않는다.
- 도르카 영역과 자원 오버레이의 위치·배율·잠금을 보존한다. % 표시를 쓰지 않으면 그 요소만을 위한 불필요한 처리는 하지 않는다.

### 3.2 기본값과 최초 전환

- 현재 `config.load_dorcha()`의 `showTuarim`은 명시적으로 참인 저장값만 켜진다. 새 설정의 기본값은 이미 꺼짐이며 이를 유지한다.
- 도르카 사용이나 투아림 알림 값을 복사해 % 표시를 켜지 않는다.
- 알파 정책 최초 적용 시 기존 켜짐 설정도 포함해 해당 표시 설정만 한 번 끈다. 제작자도 다시 쓰려면 명시적으로 체크한다.
- 최초 전환 이후 제작자가 다시 켜거나 끈 설정은 저장·재실행 후 보존한다. 매 실행마다 강제로 끄지 않는다.
- 최초 전환 완료 여부를 구별한다. 전환 기록과 체크 해제 저장이 실패했는데 완료로 처리하지 않으며 다른 영역·알림·배치 설정을 초기화하지 않는다.
- 비대상 사용자는 저장값과 관계없이 표시가 차단된다. 이전 설정 파일을 복원해도 제작자 접근 검사를 우회하지 못한다.

## 4. 기본 기능 일반 공개의 경계

- 일반 사용자는 직접 지정으로 도르카·체력바·단축바 기본 기능을 이용할 수 있다. 첫 사용 안내의 해당 기능 선택도 로그인 때문에 막지 않는다.
- 자동찾기·일괄 자동설정의 로그인 조건은 별도로 유지한다. 기능 선택 가능과 자동 등록 실행 가능을 같은 조건으로 묶지 않는다.
- 실제 표시·판독·경고·영역 보기에도 공개를 반영한다. 체크만 활성화하고 실행은 로그인 때문에 중단되는 상태가 되어서는 안 된다.
- 기본 기능의 로그인 제한을 없애면서 수집·자동찾기·알파 % 표시까지 무조건 허용하지 않는다.
- 현재 소스는 같은 로그인 검사 결과를 여러 동작이 사용한다. 모든 검사를 참으로 바꾸는 일괄 변경이 아니라 동작별로 위 공개 범위를 만족해야 한다.
- 수집이나 알파 표시를 사용하지 않아도 기존 도르카/체력바 판독·복구는 유지한다.
- 로그아웃 후에도 일반 공개한 기본 기능은 계속 동작한다. 다른 제한 기능은 기존 조건 또는 제작자 알파 조건을 따른다.
- 저장 영역·개별 표시·경고·위치·배율·잠금을 보존한다. 공개 정책 변경을 새 사용자 초기 설정으로 취급하지 않는다.
- 설정의 Discord 로그인 구간에는 `베타 기능을 먼저 사용해 볼 수 있습니다.` 정도의 짧은 안내만 둔다. 기능별 대상이나 접근 조건 목록을 모아두지 않는다.
- 각 화면의 로그인 요구 문구는 문구 정리 명세에 따라 제거한다. 안내 삭제가 접근 제한 삭제를 뜻하지 않는다.

## 5. Acceptance Criteria

### 5.1 투아림 % 알파 분리

1. 새 설정 또는 % 표시 설정이 없는 상태에서는 제작자라도 체크되지 않는다.
2. 일반 사용자와 일반 베타 사용자는 % 표시 체크가 없으며, `showTuarim=true`가 저장되어 있어도 오버레이에 % 요소가 나타나지 않는다.
3. 제작자가 % 표시를 켜고 꺼도 도르카 표시와 일반 투아림 알림은 독립적으로 유지된다.
4. 제작자 접근 해제 후 % 요소는 사라지지만 일반 알림·영역·소리 설정과 충전 주기 상태는 보존된다.
5. 원본/최근 판독값 확인과 공통 영역·알림 설정은 계속 사용할 수 있다.
6. 표시 전환·로그인 변경·탭 전환만으로 같은 충전 주기 알림이 중복 발화하지 않는다.
7. 기존에 % 표시가 켜진 설정으로 최초 전환하면 체크가 꺼진다. 제작자가 다시 켠 뒤 재실행하면 켜짐이 보존되고 최초 해제가 반복되지 않는다.
8. 전환 설정 저장 실패 시 성공으로 기록하지 않고 다른 영역·알림·배치 값을 손상시키지 않는다.

### 5.2 기본 기능 일반 공개

1. 비로그인 사용자가 직접 지정한 도르카·체력바·단축바의 표시와 기존 설정 조작을 사용할 수 있다.
2. 로그아웃 후에도 기본 기능은 유지되며 자동찾기·일괄 자동설정·수집 제한은 기존 범위대로 유지된다.
3. 제작자 전용 헤일로와 투아림 % 표시는 일반 공개 기능에 딸려 노출되거나 실행되지 않는다.
4. 첫 사용 안내의 세 기능 선택은 가능하되 자동설정 실행의 로그인 조건은 유지된다. 다른 일반 기능의 직접 지정에 새 제한이 생기지 않는다.
5. 기존 저장 데이터가 보존되고 기본 기능 설명에는 단계/로그인 요구 문구가 없으며 설정에는 짧은 목적 안내만 있다.

## 6. 개발 전달

- 이 문서의 공개 범위와 최초 전환 정책에 추가 사용자 결정은 없다. 제작자 식별·전환 기록 방식은 위 접근 제한과 보존 기준을 만족하도록 개발 세션에서 확인한다. 표시 이름 문자열만으로 제작자를 판별하지 않는다.
- 헤일로의 시간 판독·수집과 동기화 세부 검증 항목은 해당 기획안에 별도로 남아 있다. 이번 정책 확정이 그 항목까지 임의로 확정한 것은 아니다.
- 제품 변경 후 비로그인·일반 로그인·제작자와 기존 켜짐 설정의 최초 전환/재실행을 각각 검증한다. 문서만 작성한 상태를 구현 완료로 보고하지 않는다.
