# 도르카 자원 오버레이 기능 명세

- 작성일: 2026-10-16
- 상태: 동작 기획 확정. 사용자가 표시 구성과 추천 동작 전체에 동의했다.
- 목적: 작은 게임 UI를 읽기 어려운 전투 상황에서 도르카의 정확한 잔량과 대략적인 여유를 함께 확인한다.
- 용도: 개발 및 독립 QA 전달. 앱 구현이나 Windows 실게임 검증 완료를 뜻하지 않는다.
- 실제 치수와 초기 배치 등 시안에서 확인할 항목은 10절에 구분한다.
- 도르카·투아림의 탭 통합, 투아림 % 표시 및 독립 사용 설정은 [통합 명세](dorcha-tuarim-integration-spec.md)를 우선 적용한다.
  본 문서의 도르카 15칸 표시/판독 규칙은 유지하며, 기존 투아림과의 독립 사용은 별도 탭이 아닌 독립 체크로 보존한다.
- 표시 시안 승인 완료: 편의기능의 독립 베타 탭, 기본 OFF·위치 고정, 전체 배율 50~300%,
  오른쪽 위 숫자와 5칸씩 구분한 바. 너비 별도 조절은 추가하지 않는다.
- 2026-10-17 추가 개발 요청: 도르카 오버레이 왼쪽 끝에 투아림 퍼센트를 함께 표시한다.
  아래 2.4절은 추가 요구사항이며 구현/QA 완료를 뜻하지 않는다.

## 1. 기능 범위

- 게임 화면의 보라색 원 안에 표시되는 도르카 숫자를 읽는다.
- 도르카는 0~15의 정수 자원이며 최대치는 15로 고정한다.
- 읽은 값을 원본 게임 UI와 별개의 15칸 분할 바와 숫자로 새로 그려 표시한다.
- 게임 자원의 자연 회복과 스킬 사용에 따른 소모를 실제 판독 결과에 반영한다.
- 게임 원본 UI를 확대 복제하는 미러가 아니며, 원래 UI를 숨기거나 변경하지 않는다.
- 입력 자동화, 게임 메모리/통신 조회, 회복 주기나 스킬 사용량을 이용한 잔량 추정은 추가하지 않는다.

## 2. 표시 구성

### 2.1 분할 바

- 왼쪽부터 채워지는 동일 크기의 15칸을 제공한다. 한 칸은 도르카 1개를 뜻한다.
- 5칸씩 세 묶음으로 구분하며, 5번째/10번째 칸 다음 간격을 일반 칸 간격보다 조금 넓힌다.
- 채운 칸은 보라색, 빈칸은 어두운 회색으로 표시한다.
- 유효 값이 N이면 정확히 N칸을 채운다. 부분 채움이나 연속 게이지로 바꾸지 않는다.
- 0이면 모든 칸이 비어 있고, 15이면 모든 칸이 채워진다.
- 값이 바뀌어도 전체 너비, 칸 크기 및 묶음 간격은 변하지 않는다.

### 2.2 수치

- 2026-10-16 후속: 바의 보라색은 유지하며 숫자 가독성과 단계색 적용은
  [비교 시안 요청](dorcha-color-preview-request.md)을 먼저 따른다.
  흰색 숫자+보조 표시, 전체 숫자색, N만 색상의 세 안을 렌더해 사용자 확인 후 정책을 확정한다.
  기존 QA 전달의 '칸과 숫자 모두 색상 변경'은 최신 요청이 아니다.

- 바 위쪽 오른쪽에 현재 값과 최대치를 `13/15` 형식으로 표시한다.
- 수치는 바 기준의 고정된 위치를 사용하며 마지막으로 채워진 칸을 따라 움직이지 않는다.
- 0/한 자리/두 자리/최대값 전환 때문에 바나 주변 UI가 밀리지 않는다.
- 수치와 채운 칸은 같은 판독 결과를 사용하여 함께 갱신한다.
- 읽기 쉬운 큰 숫자를 사용하되 정확한 글자 크기, 대비 처리 및 바와의 간격은 시안으로 확인한다.

### 2.3 크기와 배치

- 기본 시안은 기존 체력바의 기본 표시 너비보다 약 1.5배 길게 구성한다.
- 이 비율은 시안의 출발점이다. 사용자가 조절한 현재 체력바 너비를 실시간으로 따라가는 동작은 아니다.
- 바와 숫자를 함께 확대/축소할 수 있다. 크기를 바꾸어도 15칸과 5칸 단위 구분을 유지한다.
- 너비만 독립적으로 조절하는 옵션의 제공 여부는 시안을 본 뒤 결정한다.
- 오버레이는 사용자가 원하는 위치로 옮길 수 있으며, 잠그면 위치가 고정되고 클릭은 게임으로 통과한다.
- 위치, 크기 및 잠금 설정을 저장하고 앱 재실행 시 복원한다.
- 저장된 도르카 수치는 재실행 시 현재 값으로 복원하지 않는다.

### 2.4 투아림 퍼센트 추가 표시 (2026-10-17 요청)

- 도르카 오버레이의 **왼쪽 끝**에 투아림 수치를 `95%` 형식으로 표시한다.
  기본 배치는 바 위 숫자 줄의 왼쪽 정렬이며, 기존 도르카 `N/15`는 오른쪽에 유지한다.
- 15칸 바와 보라색 채움은 도르카 전용으로 유지한다. 투아림 값으로 칸을 채우거나
  도르카 숫자에서 투아림 퍼센트를 계산하지 않는다. 기존 투아림 판독 결과를 재사용한다.
- 표시 추가 때문에 투아림 알림을 강제로 켜거나 기존 임계값·소리·승인 영역을 바꾸지 않는다.
  알림 OFF일 때의 표시용 판독 연결은 개발 시 명시하고, 불필요한 중복 캡처/판독을 피한다.
- 현재 유효한 판독이 없으면 `--%`로 구분한다. 이전 값이나 추정값을 현재 값처럼 표시하지 않고,
  기존 100% 안전 보류 정책을 표시 기능 때문에 임의 변경하지 않는다.
- 퍼센트 자릿수가 바뀌거나 도르카 수치가 갱신돼도 바/오버레이 위치·너비·잠금 상태가 바뀌지 않는다.
  기존 전체 배율을 함께 적용하고 두 숫자가 겹치거나 잘리지 않도록 실제 렌더를 확인한다.

## 3. 사용 설정과 투아림의 관계

- 도르카 표시는 투아림 알림과 독립적인 사용 설정을 갖는다.
- 투아림 알림을 켜지 않아도 도르카만 사용할 수 있다.
- 도르카를 끄더라도 기존 투아림 알림의 사용 여부, 임계값, 소리 및 판독 영역을 변경하지 않는다.
- 기존 체력바를 켜거나 보스 패턴 알림을 사용할 필요도 없다. 보스전에서만 보여주는 기능이 아니다.
- 사용을 끄면 도르카 오버레이를 숨기며, 다시 켤 때 마지막 모양과 배치는 유지한다.
- 앱의 전체 오버레이 일시정지 및 종료 정책에 연결한다. 별도의 전체 정지 설정을 만들지 않는다.
- 게임 활성 상태에 따른 표시와 위치 편집을 위한 앱 활성 예외는 기존 오버레이 정책과 일관되게 구성하고,
  실제 적용 조건을 설정 화면 시안과 함께 확인한다. 마우스 하이라이트의 별도 표시 정책을 그대로 가져오지 않는다.

## 4. 영역 자동찾기와 등록

- 투아림 자동찾기가 사용하는 보라색 원형 장식을 위치 단서로 활용한다.
- 원 내부 숫자가 변해도 같은 UI를 찾을 수 있어야 한다. 특정 도르카 값에만 맞는 앵커를 요구하지 않는다.
- 기존 투아림 자동찾기의 결과는 오른쪽 아래 % 영역이다. 이를 그대로 도르카 숫자 영역으로 사용하지 않는다.
- 도르카 등록 대상은 보라색 원 내부의 현재 도르카 숫자 영역이며, 0~15가 잘리지 않게 포함한다.
- 후보를 찾으면 기존 자동찾기와 같은 영역 확인 및 승인/취소 흐름을 사용한다.
- 사용자가 승인한 경우에만 도르카 영역을 저장한다. 취소/실패하면 기존 도르카 등록을 유지한다.
- 도르카 영역 승인 때문에 기존 투아림 % 영역이나 알림 설정을 자동으로 덮어쓰지 않는다.
- 투아림을 수동으로 등록한 기존 사용자도, 도르카를 쓰기 위해 투아림 알림을 다시 설정할 필요가 없다.
- 기존 저장 정보에는 보라색 원 전체 위치가 없을 수 있다. 투아림 영역이 있다는 사실만으로
  도르카도 이미 등록된 것으로 표시하지 않는다.
- 2026-10-16 추가 요청: 원본 UI를 게임 안에서 옮긴 뒤에도 게임 창 전체에서 다시 찾아 판독을 복구한다.
  이전의 지속 추종 제외 범위는 이 요청으로 대체한다. 오버레이 표시 위치와 원본 추적 위치는 별개다.
- 평상시에는 작은 숫자 영역을 읽고, 미판독이면 게임 창 전체 재탐색을 시작한다.
  재탐색은 작업 하나만 비동기로 실행하고 후보 장식 및 실제 0~15 판독을 함께 확인한다.
  게임 창 미발견 시 임의의 데스크톱 전체 캡처로 폴백하지 않는다.
- 초기 실패에는 즉시 탐색을 시도한다. 이후 연속 실패의 기본 재시도 간격은 2/4/8/10초이며,
  탐색이 비싼 환경에서는 직전 탐색 소요의 20배 이상을 추가 대기한다. 이는 비용 제한을 위한
  개발 기본값이며 모든 환경에서 특정 초 이내 복구를 보장하는 수치는 아니다.
- 재탐색으로 찾은 물리 좌표는 실행 중에만 쓰며 사용자 승인 영역·다른 기능 설정은 덮어쓰지 않는다.
  완료 시 게임 창 식별과 활성 상태를 다시 확인하고 현재 픽셀을 재판독한다. 가림/미검출/캡처 실패는
  `--/15`를 유지한다. 중지·로그아웃·기능 OFF·영역 재등록·게임 전환·종료 중 늦은 결과는 폐기한다.
- 기존 개별 자동찾기의 베타 접근 및 승인/취소 규칙은 유지한다.

## 5. 판독 및 실패 표시

| 관측 상태 | 수치 | 바 |
|---|---|---|
| 유효한 0 | `0/15` | 15칸 모두 빈칸 |
| 유효한 N, 1~14 | `N/15` | 왼쪽 N칸 채움 |
| 유효한 15 | `15/15` | 15칸 모두 채움 |
| 영역 등록 후 판독 불가/캡처 실패 | `--/15` | 보라색 채움 없음, 칸의 틀과 빈칸은 유지 |
| 기능 꺼짐/전체 정지/기존 표시 조건 해제 | 오버레이 숨김 | 오버레이 숨김 |

- 판독 실패를 실제 0으로 처리하지 않는다. `--/15`와 `0/15`를 명확히 구분한다.
- 새 판독에서 실패로 판단했다면 이전 숫자를 계속 현재 잔량인 것처럼 유지하지 않는다.
- 등록 영역이 없으면 기능 설정에서 등록 필요를 안내한다. 저장된 영역 없이 임의의 숫자를 표시하지 않는다.
- 0~15 밖의 값, 잘린 숫자 또는 구별하기 어려운 입력은 0이나 15로 보정하지 않고 판독 불가로 처리한다.
- 정상 판독이 돌아오면 그 값으로 숫자와 채움을 함께 복구한다. 실패 중 회복/소모를 추측해 중간 값을 재생하지 않는다.
- 연속 판독 안정화 방법은 개발 검증 사항이지만 빠른 실제 소모를 임의로 완만하게 만들거나
  회복만 허용하는 등 실제 자원 변화의 의미를 바꾸지 않는다.
- 도르카 숫자 폰트와 배경은 기존 투아림 %와 다르므로, % 전용 판독기의 정확도를 그대로 가정하지 않는다.

## 6. 정상 사용 흐름

1. 도르카 표시 설정을 열고 원본 도르카 UI가 보이는 상태에서 영역 자동찾기를 실행한다.
2. 원 내부 도르카 숫자가 후보 영역에 포함되는지 확인한 뒤 등록한다.
3. 도르카 표시를 켜면 현재 판독값을 숫자와 분할 바로 표시한다.
4. 잠금을 풀어 원하는 위치로 이동하고 전체 크기를 맞춘 뒤 잠근다.
5. 자연 회복 및 스킬 사용 시 바와 수치가 현재 판독값으로 함께 갱신된다.
6. 읽지 못하면 `--/15`와 채움 없는 상태를 보여준다. 다시 읽히면 현재 값으로 복구한다.
7. 앱을 재실행하면 저장한 위치와 크기를 사용하되, 표시 조건과 새 판독에 따라 현재 상태를 표시한다.

## 7. 상태 변화 및 기존 동작 보존

- 앱/게임의 실행 순서와 관계없이 현재 게임 및 유효한 영역을 기준으로 동작한다.
- 게임 종료/비정상 종료, 최소화, Windows 잠금 및 절전 시 과거 자원 값을 계속 유효한 것처럼 보여주지 않는다.
- 복귀/재실행 시 새 판독으로 상태를 결정하고 이전 오버레이의 순간 값이나 이동 애니메이션을 재생하지 않는다.
- 빠른 게임/앱 전환, 사용 체크 및 전체 일시정지 반복으로 오버레이나 판독 작업이 중복 생성되지 않는다.
- 잠금 상태에서 표시 수치가 갱신되어도 클릭 통과를 유지하고 포커스를 빼앗지 않는다.
- 위치 편집/크기 변경과 수치 갱신이 동시에 일어나도 사용자가 배치한 좌표를 덮어쓰지 않는다.
- 기존 투아림, HP/MP/STA, 보스 패턴 및 버프/디버프의 판독과 알림 정책은 변경하지 않는다.
- 게임창/모니터 이동, 해상도/DPI 및 화면 모드 변경에서 등록 영역과 표시 위치가 올바르게 처리되는지 검증한다.
- 캡처나 Windows 조회 실패가 발생해도 게임 입력을 방해하거나 앱 전체를 종료하지 않는다.
- 앱 설정에 도르카 항목이 없거나 손상됐을 때 기존 투아림/체력바 설정을 초기화하지 않는다.

## 8. 성능과 검증 범위

- 새 UI를 그리는 것과 도르카 숫자를 정확히 읽는 것은 별도 검증 대상이다.
- 0~15 전체 값, 특히 9/10 및 14/15 경계, 빠른 소모/회복, 밝고 어두운 전투 배경,
  원본 UI 가림과 배율 변화의 실제 입력으로 판독 정확도를 확인한다.
- 임의로 정상 값을 추측하여 판독 성공률을 높인 것처럼 보고하지 않는다.
- 기존 캡처/판독 흐름과 재사용 가능한 영역은 검토하되, 특정 Windows API/라이브러리/스레드 구조를 고정하지 않는다.
- 표시 또는 판독 작업이 기존 트래커의 알림을 지연시키거나 중단/복귀 후 자원을 계속 누적시키지 않아야 한다.
- 반응 지연과 오인식은 실제 소모/회복 영상 또는 시점이 확인되는 입력으로 측정한다.
  허용 지연, 갱신 주기 및 CPU 수치 기준은 측정 결과와 함께 정하며 검증 전 임의로 통과를 주장하지 않는다.
- 일반 렌더, 숫자 판독 테스트 및 Windows 실게임 검증 결과를 구분해 보고한다.

## 9. Acceptance Criteria

| ID | 검증 가능한 성공 기준 |
|---|---|
| DC-01 | 0, 1, 5, 9, 10, 13, 14, 15 입력에 대해 각각 정확한 `N/15`와 N개의 채운 칸을 함께 표시한다. |
| DC-02 | 항상 15칸이며 5칸마다 구분 간격이 있다. 값 전환으로 칸 크기/전체 너비/숫자 기준 위치가 변하지 않는다. |
| DC-03 | 초기 시안은 기본 체력바 너비의 약 1.5배이며, 바와 숫자를 함께 확대/축소해도 수치와 15칸이 잘리지 않는다. 정확한 치수는 승인 시안을 따른다. |
| DC-04 | 투아림 알림과 기존 체력바가 꺼진 상태에서도 도르카만 켜고 등록/표시할 수 있다. 도르카 설정 변경이 기존 기능 설정을 바꾸지 않는다. |
| DC-05 | 자동찾기가 % 영역이 아닌 보라색 원 내부 숫자 영역을 제시한다. 승인 시에만 도르카 설정을 저장하고 취소/실패 시 이전 등록을 유지한다. |
| DC-06 | 0~15 전체 입력이 영역에 들어가고 0/9/10/15로 숫자가 바뀌어도 특정 값만을 이유로 재등록을 요구하지 않는다. |
| DC-07 | 캡처 실패/숫자 가림/범위 밖 값은 `--/15`와 채움 없는 상태로 전환하며 `0/15`로 오인 표시하지 않는다. 정상 입력이 돌아오면 그 값으로 복구한다. |
| DC-08 | 실제 자원 감소와 증가를 모두 표시한다. 바만 예전 값으로 남거나 숫자만 새 값으로 바뀌지 않으며, 실패 중 자원량을 추측하지 않는다. |
| DC-09 | 잠금 상태에서 클릭/드래그/휠이 게임으로 통과하고, 잠금 해제 후 위치 조절이 가능하다. 위치·크기·잠금 상태가 재실행 후 복원된다. |
| DC-10 | 재실행/게임 재실행/잠금·절전 복귀 후 저장된 과거 자원량을 현재 값으로 복원하지 않고 새 판독에 따라 표시한다. |
| DC-11 | 전체 일시정지/사용 끄기/앱 종료 시 기존 표시 정책에 맞게 숨고 관련 작업을 정리한다. 반복 조작 후 중복 오버레이나 계속 증가하는 작업이 없다. |
| DC-12 | 새 판독과 표시를 켜도 기존 투아림 % 판독·알림, HP/MP/STA 및 버프/디버프/보스 기능의 설정과 동작이 유지된다. |
| DC-13 | 저자원 소리/점멸/흔들림이나 자동 입력이 추가되지 않으며 게임 원본 UI와 Windows 커서 설정을 변경하지 않는다. |
| DC-14 | 왼쪽 끝의 투아림 `95%`/`--%`와 오른쪽 도르카 `N/15`가 독립된 판독 상태를 표시한다. 퍼센트 갱신·전체 배율 변경에도 두 수치가 겹치지 않고 기존 바·잠금·위치 및 투아림 알림 설정이 유지된다. |

## 10. 시안 및 개발 확인 항목

### 승인된 초기 표시

- 기본 바 너비는 체력바 150의 1.5배인 225 논리 픽셀이고, 기본 표시 배율은 150%이다.
  기존 체력바의 사용자 설정을 읽어 너비를 따라 바꾸지 않는다.
- 기본 높이 16, 수치 영역 높이 22, 수치·바 간격 4, 칸 간격 2, 묶음 간격 5이며
  전체 배율을 함께 적용한다. 초기 수치 글꼴은 18 논리 픽셀을 기준으로 확대한다.
- 새 도르카 표시와 개별 자동찾기는 모두 기존 Discord 로그인 기반 베타로 제공한다.
  기능 사용은 기본 OFF, 최초 위치 잠금은 ON이다. 투아림/체력바/보스 기능과 독립적이다.
- 탐색 위치는 [앱 탐색 구조 명세](navigation-structure-spec.md)를 따른다.
  전투 보조 > 도르카이며 체력바 바로 다음 탭이다. 탭 이름에서만 `(베타)`를 제거하고 접근 조건은 유지한다.
  기존 일괄 자동설정 항목은 변경하지 않고 도르카 탭에서 원본을 별도 등록한다.
- 게임 활성 시 표시하며, 자기 앱 활성일 때는 이 도르카 탭을 보는 경우에만 위치 편집을
  위해 표시한다. 트레이에 숨겼어도 게임이 활성이고 사용 중이면 계속 표시한다.
- 최초 위치는 현재 주 화면의 사용 가능 영역 중앙 왼쪽을 기준으로 계산한다.
  사용자가 이동한 뒤에는 저장 좌표를 복원한다. 게임 원본 UI의 좌표와 동일시하지 않는다.
- 큰 배율의 설정 미리보기는 필요할 때 가로 스크롤을 제공해 실물 배율을 유지한다.

### 실제 환경 검증

표시 방식과 사용자 동작은 확정했다. 아래 원래 시안 검토 항목 중 표시 치수·진입 위치·
베타 접근·잠금·배율·너비 옵션·표시 조건은 위 승인안으로 확정했다. 나머지는 실제 환경에서 확인한다.

- 바의 정확한 기본 너비/높이, 글자 크기, 칸과 묶음 사이 간격 및 보라색/빈칸의 세부 색상.
- 초기 위치는 사용자가 보기 원하는 화면 중앙의 왼쪽 부근을 기준으로 시안을 제시한다.
  모든 해상도에 같은 절대 좌표를 적용하거나 게임 원본 위치와 동일하다고 가정하지 않는다.
- 너비만 독립 조절하는 옵션을 제공할지, 전체 배율만 제공할지.
- 전투 보조 내 설정 진입 위치, 최초 사용/잠금 상태, 신규 도르카 표시의 베타 접근 조건 및 배율 범위.
  기존 자동찾기 접근 조건과 도르카 표시 자체의 접근 조건을 혼동하지 않는다.
- 기존 체력바 정책과 맞춘 활성/편집 상태의 표시 조건을 시안에서 함께 설명한다.
- 숫자 판독에 필요한 실제 0~15 자료와 화면 환경별 지원 범위, 반응 지연 및 리소스 측정 결과.

개발 세션은 먼저 원본 도르카 숫자의 판독 가능성을 확인하고, 기본 체력바와 나란히 비교할 수 있는
표시 시안을 공유한다. 새 UI에 대한 동의가 숫자 판독 신뢰도 검증 완료를 뜻하지는 않는다.
확인 결과 동작 범위를 바꿔야 한다면 사용자에게 이유와 변경안을 먼저 설명한다.

현재 참고 소스는 `detect/tuarim_anchor.py`, `detect/autofind_anchors.py`,
`detect/tuarim_reader.py`, `ui/tuarim_tab.py` 및 `ui/stat_overlay.py`이다.
원 내부 숫자를 제외하고 장식을 찾는 현재 앵커와 % 전용 리더의 역할을 구분한다.
