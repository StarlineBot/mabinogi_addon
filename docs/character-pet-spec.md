# 캐릭터·데스크톱 펫 명세 (정리본 2026-11-24)

목소리 팩을 캐릭터로 바꾸고, 고른 캐릭터가 화면에서 함께 지내는 기능. 11-24 기획 대화를 한곳에 모은 문서.
**1차(MVP)는 지금 있는 다래 그림만으로 만들 수 있는 범위**로 자르고, 나머지는 '나중' 목록에 둔다(사용자 11-24: 다 정하려 하면 개발 시작을 못 함).
캐릭터별 그림·설정은 `docs/characters/<이름>.md`(다래: `docs/characters/다래.md`).

## 1. 정해진 것 (사용자 결정 11-24)
| 항목 | 결정 |
|---|---|
| 캐릭터 | 목소리 팩마다 이름·성격 있는 캐릭터. 첫 캐릭터 **다래 = 조용한 여성** |
| 그림 두 벌 | 앱 안(카드·얼굴)은 **원래 비율 상반신**, 화면을 돌아다니는 펫은 **SD(데포르메)** |
| 선택 화면 | 설정의 '목소리 고르기' → **캐릭터 고르기**. 맨 위 `화면에 캐릭터 띄우기` 스위치, 상반신 카드 **한 줄 3개 + 위아래 스크롤**, 이름은 캐릭터 색 + 흰 테두리, 카드 아래 ♥ 호감도 **바만**(0~100) |
| 고르기 | 카드를 누르면 그 목소리가 나오고 **바로 선택**, 고른 카드는 **둘레 강조** |
| 미정 캐릭터 | 실루엣 **남·여 두 장**(사용자 제작 예정) + 이름 `???` |
| 펫 위치 | 게임이 앞에 없으면 바탕화면을 돌아다님(작업 표시줄 위), **게임이 앞이면 구석으로 가서 앉음** — 구석은 **끌어서 정함**(저장) |
| 클릭 | 캐릭터 위 클릭은 캐릭터가 받음(클릭 통과 아님 — 캐릭터 크기만큼만) |
| 장식 | 졸 때 Zzz 등은 **코드로 그림**(캐릭터 색 + 흰 테두리) |
| 크기 맞추기 | 시트마다 머리 크기가 달라 **서 있는 키(앉은 계열은 쪼그림 폭)로 맞춤** — `다래.md` 참고 |

시안: 선택 화면 `docs/assets/character-select-20261124/`, 동작 `docs/characters/assets/다래_*.gif`.

## 2. 1차(MVP) 범위 — 다래만, 지금 그림으로
**펫 동작(상태)**
| 상태 | 그림(`docs/characters/assets/다래_SD/`) | 들어가는 때 |
|---|---|---|
| 서 있기 | 4면도 정면 | 기본, 걷기 사이 |
| 걷기 | 오른쪽 걷기 6프레임(왼쪽은 뒤집기) | 게임이 앞에 없을 때 가끔 |
| 놀람(서서 클릭) | 깜짝 놀란 시트 2프레임 | 서 있을 때 클릭 |
| 끌려 다니기 | 드래그 시트 4프레임 | 끌 때 |
| 떨어져 착지 → 앉기 → 일어나기 | 착지 3 + 세 가지 자세 3 | 끌다 놓을 때 |
| 쓰다듬기 | 부끄러운 스티커 세트 6프레임 | 서 있을 때 머리 위를 문지름 |
| 쪼그려 앉기 진입 → 앉아 있기 → 일어나기 | 웅크리기 3 → 무릎베개 4(졸기·Zzz) → 상승 3 | 게임이 앞으로 와서 구석에 도착했을 때 / 게임이 뒤로 갈 때 |
| 자다 깨기 | 잠에서 깨는 시트 4프레임 | 졸 때(Zzz 중) 클릭 |
| 알아챔(앉아서) | 무릎베개 '알아챔' | 앉아 있을 때 클릭·알림 |

**알림**: 고른 캐릭터 목소리로 알림(지금 목소리 팩 그대로) + 펫이 알아챔 동작 + 말풍선 한 줄.
**창**: 투명·맨 위·화면 판독 캡처 제외(`system/capture_exclusion.py`), 게임 앞/뒤 판정은 지금 오버레이와 같은 판정.
**선택 화면**: 1절대로(다래 카드 + 실루엣 4장).
**호감도**: 바만 보이고 3절 3번 규칙으로 쌓음·반복 −1. 보상은 구간 대사(알파는 0구간만).

## 3. 1차를 시작하기 전에 정할 것 — 모두 결정됨(11-24)
1. ~~선택 화면 위치~~ → **결정(11-24): 1차 탭 '캐릭터'를 설정 바로 앞에** — `전투 보조 · 파티 모집 · 편의기능 · 최적화 · 블랙박스 · 캐릭터 · 설정`(최적화·블랙박스 탭은 설정 앞에 끼워 넣는 구조라 캐릭터는 그 뒤·설정 바로 앞). 설정의 '알림 목소리'는 이 탭으로 옮기고 설정엔 알림 음량만. 7개 탭 합계 784px/창 790px(실제 탭 스타일 렌더 11-24)이라 탭 최소 폭 104→96px로 줄여 여유를 둔다.
2. ~~펫 크기~~ → **결정(11-24): 서 있을 때 키 190px**(화면 배율 100% 기준, 125%·150%면 같은 비율로 커짐). 사용자 2560×1440 스크린샷 비교 — 230px는 화면 높이의 16%로 게임 중엔 큼, 150px는 장식이 뭉개짐. 시안 `docs/assets/character-select-20261124/size_compare.png`.
3. ~~호감도~~ → **결정(11-24)**: 0~100, **하루 최대 +20**(자정 초기화). 구간 **0~24 / 25 / 50 / 75 / 100** — 구간에 들어가면 그 구간 대사가 열림(알파는 0구간 대사만, 나머지는 다음에 씀).
   | 행동 | 오르는 양 | 하루 최대 |
   |---|---|---|
   | 그날 처음 앱 켜기 | +3 | 1번 |
   | 쓰다듬기(끝까지) | +2 | 3번 |
   | 그 캐릭터 목소리 알림 받기 | +1 | 5번 |
   | 게임 중 구석에서 함께 30분 | +1 | 2번 |
   다 채우면 하루 16(상한 20 안) → 매일 꽉 채워 약 7일에 100. **반복 행동 −1**: 10초 안 클릭 5번 이상, 또는 오늘 쓰다듬기 3번을 다 채운 뒤 또 쓰다듬기 → −1 + 짜증 대사(예 '…그만 찔러…', '오늘은… 그만…'), 1분에 한 번만, 0 아래로 안 내려감. 숫자(오르는 양·횟수·상한·반복 기준)는 설정 값으로 빼 둔다(나중에 조정). 캐릭터마다 따로 저장, 로그인 사용자는 동기화.
4. ~~실루엣 그림~~ → **받음(11-24)**: 여성 `docs/characters/assets/실루엣_여.png`(투명 배경), 남성은 4종 시안(`실루엣_남_시안4종.png`) 중 **A안**(사용자 결정) → `실루엣_남.png`(A칸을 잘라 배경·라벨 지움). 카드에서는 테마 회색으로 칠해 씀. 미정 캐릭터: 부드러운·자연스러운·화난 여성 = 여 실루엣, 차분한 남성 = 남 실루엣.

**결정(11-24)**: 알파(1차)에서는 **휠 크기 조절 제외**(190px 고정). 대신 **다양한 대사를 먼저 넣는다** — 상황별 말풍선 대사 `docs/characters/다래_대사.md`(사용자 확인 11-24 — 좋음), 데이터 파일로 관리.

## 4. 나중 (1차 뒤 — 그림·결정이 더 필요)
- 행동 규칙(언제 걷고·앉고·조는지 시간·확률, 밤엔 졸기 등) 세부
- 넘어지기, 벽 타기·매달리기, 창 윗변에 앉기, 커서 따라가기
- 앉은 채로 쓰다듬기 반응(그림 2~3장 필요)
- 호감도 보상: 단계별 대사(20·40·60·80·100), 호감도에 따라 쓰다듬기 반응 바뀜(앞 시트 '표정 모음' 활용), 특별한 날 대사
- 앱 안 상호작용(제작자 잡담 자리를 캐릭터가 대신), 음성 알림 때 게임 위 상반신 얼굴
- 라이브 애니메이션(앱 안 얼굴을 살짝 움직이기)
- 다른 네 캐릭터(화난 여성부터) 컨셉·그림
- 로그인 혜택 연결(호감도 동기화)
