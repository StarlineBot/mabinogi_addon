# 도르카·투아림 설정 및 표시 통합 명세

> 2026-10-19 후속 확정: 도르카 기본 표시는 일반 공개하고, 자원 오버레이의 투아림 % 표시만 제작자 전용 알파로 분리한다. 최초 전환 시 해당 체크를 한 번 해제하며 이후 제작자 선택은 보존한다. 일반 투아림 알림과 다른 영역·배치 설정은 유지한다. [공개 정책 확정 명세](feature-release-stage-review.md)를 이 범위에 우선 적용한다.

- 작성일: 2026-10-17
- 상태: 통합 방향·독립 사용 동작·화면 배치 확정. 구현과 검증 결과는 [개발 문서](resource-integration-implementation.md)에서 구분한다.
- 대상: 도르카 표시, 도르카 오버레이에 추가한 투아림 % 표시, 기존 투아림 알림 및 각 설정 진입점.
- 목적: 같은 원본 UI에서 확인하는 자원 표시와 알림을 한 화면에서 설정하되 필요한 동작만 사용할 수 있게 한다.
- 개발 및 독립 QA 전달용이다. 코드 구현, 기존 QA 추가분의 main 반영 또는 실게임 검증 완료를 뜻하지 않는다.
- 기존 [도르카 자원 오버레이](dorcha-overlay-spec.md)의 도르카 표시 규칙과 투아림 알림 규칙은 유지한다.
  탭 분리 및 진입 위치는 본 문서를 우선 적용하고, 탐색 구조는 [탭 구조 명세](navigation-structure-spec.md)를 함께 따른다.
- 2026-10-17 사용자 확인: 새 % 표시는 기본 OFF·Discord 로그인 베타다. 이미 설정한 사람은
  기존 설정 그대로 유지하며, 기본 OFF는 해당 항목이 없는 경우에만 적용한다.
  실제 렌더의 세 사용 체크 → 표시·배치 → 판독 영역 → 알림 기준 배치와 네 표시 상태를 승인했다.
- 2026-10-18 후속 확정: [설정 화면 그룹화 및 공통 영역 설정](settings-grouping-common-resource-spec.md)의
  공통 자동/직접 지정·한 번의 후보 확인·부분 성공·공통/개별 해제 및 그룹 배치를 우선 적용한다.
  두 판독 영역과 세 표시/알림 옵션의 독립 동작, 기존 접근 조건은 유지한다.
  첫 사용 안내 체크의 의미는 [영역 등록 기반 사용](region-registration-usage-spec.md)을 따른다.

## 1. 통합 범위

- 도르카 설정과 기존 투아림 설정을 `도르카·투아림` 한 탭에서 제공한다.
- 기존 단독 투아림 탭과 단독 도르카 탭을 중복해서 남기지 않는다.
- 표시, 알림 및 영역 설정을 한곳에서 찾을 수 있게 한다. 통합을 이유로 모든 동작을 한 사용 체크에 묶지 않는다.
- 도르카의 15칸 분할 바/수치와 추가된 투아림 % 표시는 같은 자원 오버레이의 표시 요소로 다룬다.
- 투아림 %는 기존 추가 요구사항대로 바 위 숫자 줄의 왼쪽 끝에, 도르카 `N/15`는 오른쪽에 둔다.
  두 값을 켰을 때 숫자가 겹치거나 잘리지 않고 기존 전체 배율을 함께 적용한다. 실제 작업본의 배치는 시안으로 공유한다.
- 이번 통합 때문에 새로운 게이지, 소리, 저자원 경고 또는 별도 애니메이션을 추가하지 않는다.

## 2. 독립 사용 설정

| 설정 | 켰을 때 | 끄더라도 유지할 동작 |
|---|---|---|
| 도르카 표시 | 0~15의 현재 수치를 기존 15칸 바와 `N/15`로 표시 | 투아림 % 표시 및 투아림 알림 |
| 투아림 % 표시 | 현재 판독한 투아림 비율을 자원 오버레이에 표시 | 도르카 표시 및 투아림 알림 |
| 투아림 알림 | 기존 첫 알림/추가 알림 기준과 소리 설정으로 알림 | 두 표시 요소 |

- 세 설정은 각각 독립적이며 하나를 켜거나 꺼도 다른 체크를 자동으로 바꾸지 않는다.
- 투아림 알림 사용 아래에는 기존 첫 알림/추가 알림 기준과 각 소리 사용 설정을 유지한다.
- 표시가 하나라도 켜져 있고 그 요소의 접근/표시 조건을 만족하면 해당 요소를 표시한다.
- 두 표시를 모두 끄면 실제 자원 오버레이는 숨긴다. 이때 투아림 알림이 켜져 있으면 필요한 판독과 알림을 계속한다.
- 투아림 % 표시만 켜진 상태에서는 도르카 바와 `N/15`를 표시하지 않는다.
- 도르카만 켜진 상태에서는 투아림 %를 표시하지 않으며, 도르카 표시의 성공을 투아림 % 판독 성공에 묶지 않는다.
- 세 설정이 모두 꺼져 있으면 이 기능 때문에 새로운 실시간 판독이나 실제 표시를 지속하지 않는다.
  설정 영역 확인 및 기존 진단 도구의 명시적 실행은 별도로 구분한다.

### 사용 조합

| 도르카 표시 | 투아림 % 표시 | 투아림 알림 | 기대 동작 |
|---|---|---|---|
| 꺼짐 | 꺼짐 | 꺼짐 | 실제 표시 및 알림 없음 |
| 켜짐 | 꺼짐 | 꺼짐 | 도르카만 표시 |
| 꺼짐 | 켜짐 | 꺼짐 | 투아림 %만 표시 |
| 꺼짐 | 꺼짐 | 켜짐 | 표시 없이 투아림 알림만 동작 |
| 켜짐 | 켜짐 | 꺼짐 | 두 값 표시, 투아림 소리 알림 없음 |
| 켜짐 | 꺼짐 | 켜짐 | 도르카 표시와 투아림 알림 |
| 꺼짐 | 켜짐 | 켜짐 | 투아림 % 표시와 알림 |
| 켜짐 | 켜짐 | 켜짐 | 두 값 표시와 투아림 알림 |

각 조합은 해당 요소의 기존 접근 권한, 등록 영역 및 활성 상태 조건을 충족하는 경우를 기준으로 한다.

## 3. 영역 설정

- 도르카 숫자는 보라색 원 내부, 투아림 %는 원 오른쪽 아래의 다른 영역이다.
  같은 원본 UI에 속한다는 이유로 저장된 두 영역을 동일한 사각형으로 간주하지 않는다.
- 한 탭에서 두 영역의 등록 여부, 직접 지정, 자동찾기 및 지정 영역 확인에 접근할 수 있게 한다.
- 각 조작이 도르카와 투아림 중 어느 영역을 대상으로 하는지 명확히 표시한다.
- 기존 등록 영역은 그대로 사용한다. 기존 사용자가 탭 통합만으로 재등록할 필요가 없어야 한다.
- 도르카 영역을 수정해도 기존 투아림 영역을 자동으로 덮어쓰지 않으며 반대 방향도 같다.
- 원형 장식 검출을 함께 활용할 수 있지만 검출 대상, 확인 및 저장 결과는 각 영역을 구분한다.
- 후보를 찾은 사실만으로 영역을 저장하거나 다른 기능 사용 체크를 켜지 않는다.
  기존 승인/취소 정책과 실패 시 기존 설정 보존 동작을 유지한다.
- 한 번에 두 영역을 새로 등록하는 일괄 승인 동작은 이번 통합의 필수 요구가 아니다.
- 도르카만 사용하면 도르카 영역만, 투아림 표시/알림만 사용하면 투아림 영역만 필요하다.
  사용하지 않는 다른 영역을 필수 설정으로 안내하지 않는다.

## 4. 판독과 알림의 관계

- 도르카와 투아림은 각각의 유효 관측값과 판독 불가 상태를 구분한다.
- 도르카 판독 실패가 투아림 표시/알림을 중단시키거나 투아림 값을 지우는 이유가 되어서는 안 된다.
- 투아림 판독 실패가 정상 도르카 표시를 중단시키는 이유가 되어서는 안 된다.
- 유효한 도르카는 기존 `N/15` 및 N칸 채움, 판독 불가는 `--/15`와 채움 없는 상태로 표시한다.
- 투아림 표시의 유효 값은 `95%`처럼 %가 붙은 숫자로, 판독 불가는 `--%`로 표시한다.
  실패를 `0%`로 바꾸거나 오래된 표시값을 새로운 관측값처럼 알림에 넣지 않는다.
- 투아림 표시와 알림이 모두 켜져 있을 때 서로 다른 의미의 %를 판독하거나 상충하는 상태로 동작하지 않게 한다.
  기존 안정화된 값과 새로운 유효 관측의 구분, 알림 발동 및 재무장 규칙은 유지한다.
- 표시용 직전 값이나 화면 갱신만으로 같은 임계 알림을 반복 발생시키지 않는다.
- % 표시를 켜고 끄는 동작이나 탭 이동이 기존 투아림 알림을 초기화하여 같은 주기에 재발화시키면 안 된다.
- 투아림 % 표시만 켜도 알림 기능을 켤 필요 없이 해당 값이 갱신되어야 한다.
- 기존 판독 범위, 100% 직후 초기화 및 저대비 배경의 제한을 검토한다. 표시 통합 자체를
  0~100% 전 구간 판독 신뢰도 개선 완료로 설명하지 않는다.
- 기존 100% 안전 보류 정책을 표시 통합 때문에 임의로 변경하지 않는다.
- 캡처/판독의 중복을 줄일 수 있는지는 구현 시 검토한다. 특정 공용 클래스, 타이머, 스레드 또는
  하나의 캡처 방식으로 기술 구현을 고정하지 않고 위 독립 동작과 관측 일관성을 기준으로 검증한다.

## 5. 접근 권한과 표시 제어

- 기존 도르카 표시의 베타 접근과 기존 투아림 알림의 접근 조건은 각자 유지한다.
- 같은 탭 안에 있다는 이유로 투아림 알림까지 Discord 로그인 필수로 변경하지 않는다.
- 탭 이름에는 `(베타)`를 붙이지 않는다. 베타 제한이 있는 개별 조작은 실제 접근 조건을 안내한다.
- 로그아웃하면 권한이 필요한 표시/조작만 기존 정책대로 중단한다.
  기존에 일반 사용자가 쓸 수 있는 투아림 알림까지 함께 중단하지 않는다.
- 투아림 % 표시는 사용자 확인에 따라 도르카와 같은 Discord 로그인 베타로 제공한다.
  로그아웃 시 저장된 사용 체크를 OFF로 덮어쓰지 않고 실제 표시/표시용 판독만 중단한다.
- 위치, 크기, 잠금 및 클릭 통과는 기존 자원 오버레이의 동작을 유지한다.
- 도르카 표시를 꺼도 투아림 % 표시가 켜져 있으면 해당 오버레이의 위치와 크기를 계속 조절할 수 있어야 한다.
- 두 표시 요소를 전환하는 동작만으로 저장된 위치/배율/잠금 상태를 초기화하지 않는다.
- 전체 오버레이 일시정지, 게임/앱 활성 상태, 트레이 숨김 및 잠금/절전 후 복귀는 기존 기능별 정책을 유지한다.
  표시 중단을 이유로 투아림 알림의 기존 일시정지 정책까지 임의로 확대하지 않는다.
- 앱 종료 후 실제 오버레이와 판독 관련 작업이 남지 않으며, 재실행 시 과거 관측값을 현재 값으로 복원하지 않는다.

## 6. 설정 이전과 호환성

- 기존 도르카 사용 여부는 도르카 표시 사용 여부로 보존한다.
- 기존 투아림 알림 사용 여부, 첫/추가 기준값 및 소리 사용 여부를 그대로 보존한다.
- QA에서 추가한 투아림 % 표시 설정이 있으면 그 사용 여부와 관련 설정도 보존한다.
- 도르카 영역과 투아림 영역, 자원 오버레이 위치/배율/잠금 상태를 유지한다.
- 서로 다른 사용 값을 하나로 합치거나, 예전 설정 중 하나가 켜져 있다는 이유로 나머지 두 설정까지 켜지 않는다.
- 구버전에 새 % 표시 항목이 없을 때만 OFF로 초기화한다. 저장된 % 표시 항목이 있으면 유지한다.
  기존 투아림 알림 체크를 % 표시 체크로 자동 복사하지 않는다.
- 설정 없음/손상/구버전에서 이 기능과 무관한 버프·디버프·체력바·메모·프리셋 설정을 초기화하지 않는다.
- 설정을 저장하지 못하면 기존 오류 안내 정책을 따르며 성공한 것처럼 표시하지 않는다.

## 7. 탭·첫 사용 안내·투어

- 통합 탭은 전투 보조의 체력바 다음에 `도르카·투아림`으로 둔다.
- 효과·알림 묶음에서 독립 투아림 탭을 제거한다. 2단 가로 탭 구조는 유지한다.
- 기존 투아림 및 도르카로 이동하던 내부 진입 요청은 모두 통합 탭으로 연결한다.
  투아림 알림을 설정하려던 요청은 통합 화면의 해당 설정이 보이게 한다.
- 단계별 첫 사용 안내의 투아림 체크는 기존처럼 투아림 알림만 제어한다.
  안내에서 투아림을 켰다는 이유로 도르카나 % 표시까지 켜지 않는다.
- 영역 자동설정의 기존 투아림 항목은 여전히 % 영역을 뜻한다. 도르카 영역으로 대체하지 않는다.
- 도르카를 단계별 첫 사용 안내의 새 필수 항목으로 추가하거나 등록 성공을 투어 진입 조건으로 만들지 않는다.
- 도움말/미등록 영역 안내/투어에서 통합 탭 이름과 실제 위치를 사용한다.
  독립 투아림 탭 또는 도르카 탭이 별도로 남아 있는 것처럼 안내하지 않는다.
- 탭 개수와 인덱스가 달라져도 보스 패턴 알림, 체력바, 계산기 및 파티 이동 대상이 바뀌지 않아야 한다.
- 버프 시작 조건, 투어 접근 조건 및 승인된 투어 종료 후 복귀 동작은 이번 통합으로 변경하지 않는다.

## 8. 사용자 흐름

1. 전투 보조 > 도르카·투아림을 연다.
2. 사용할 표시와 알림을 각각 선택한다. 필요한 영역만 등록한다.
3. 표시를 사용할 경우 기존 미리보기와 배치 조작으로 위치/크기를 맞추고 잠근다.
4. 투아림 알림을 사용할 경우 기존 첫/추가 알림 기준과 소리를 조절한다.
5. 게임에서 두 값의 표시와 알림을 선택한 조합대로 사용한다.
6. 한쪽 판독이 실패하면 그 요소만 판독 불가로 전환하고 정상인 다른 요소는 유지한다.
7. 두 표시를 꺼도 알림이 켜져 있으면 표시 없이 기존 투아림 알림을 받는다.

## 9. Acceptance Criteria

| ID | 검증 가능한 성공 기준 |
|---|---|
| DT-01 | 전투 보조의 체력바 다음에 도르카·투아림 탭이 하나만 있으며 독립 투아림/도르카 탭은 중복 표시되지 않는다. |
| DT-02 | 세 사용 체크의 8개 조합을 2절 표대로 사용할 수 있다. 다른 체크나 알림 임계값이 선택에 따라 자동 변경되지 않는다. |
| DT-03 | 두 표시가 모두 꺼져도 투아림 알림이 켜져 있으면 % 관측과 기존 임계 알림이 동작하며 실제 자원 오버레이는 보이지 않는다. |
| DT-04 | 알림을 끄고 % 표시만 켜도 숫자가 갱신된다. 도르카만 켜면 % 영역 미등록/판독 불가 때문에 도르카 표시가 중단되지 않는다. |
| DT-05 | 도르카 실패/투아림 정상, 도르카 정상/투아림 실패, 둘 다 실패를 각각 주입하면 해당 요소만 판독 불가로 표현하고 실패를 0으로 표시하지 않는다. |
| DT-06 | % 표시 체크와 탭 이동을 반복해도 같은 투아림 주기의 알림이 중복 발화하지 않는다. 기존 회복/초기화 관측 후 재무장과 첫/추가 알림 동작은 유지한다. |
| DT-07 | 로그인하지 않아도 기존 일반 투아림 알림을 사용할 수 있다. 도르카 및 개별 자동찾기의 기존 베타 접근은 그대로 유지한다. |
| DT-08 | 기존의 서로 다른 도르카/투아림 사용 설정과 영역, 소리, 임계값, 배치가 통합 및 재실행 후 보존되고 새 설정이 다른 체크를 임의로 켜지 않는다. |
| DT-09 | 각 영역의 자동찾기 승인/취소가 정확한 대상을 저장/유지하며 사용하지 않는 다른 영역을 필수 등록으로 요구하지 않는다. |
| DT-10 | 기존 안내의 투아림 선택은 알림만 제어하고 투아림 영역 자동설정은 % 영역을 등록한다. 각 진입점과 투어는 새 탭과 해당 설정으로 이동한다. |
| DT-11 | 도르카를 끄고 %만 표시하는 상태에서도 배치 조작과 잠금/클릭 통과가 동작하며, 두 표시 전환 후 저장된 위치/크기가 바뀌지 않는다. |
| DT-12 | 두 표시와 알림을 반복 변경하거나 잠금/절전/게임 재실행/종료를 거쳐도 중복 작업과 남은 오버레이가 없고 기존 알림 정책이 유지된다. |

## 10. 개발 전 확인 및 시안

- QA에서 추가한 % 표시 작업본의 소스 위치/반영 상태, 판독 경로 및 실제 지원 범위를 확인한다.
  현재 main 조회에서 확인되지 않았다는 사실만으로 사용자 작업이 없었다고 판단하지 않는다.
- 기존 알림과 추가 표시가 같은 % 판독 정의와 유효 관측을 사용하는지 확인한다.
- 새 % 표시 항목이 없는 구버전의 기본값은 OFF, 접근은 Discord 로그인 베타로 사용자 확인을 마쳤다.
- 통합 화면의 영역 설정, 세 사용 체크, 알림 기준, 자원 오버레이 배치 조작을 렌더로 공유한다.
  기본 2단 탭/창 폭 안에서 표시하고 불필요한 상위 사용 체크나 내부 탐색 단계를 추가하지 않는다.
- 도르카만/%만/둘 다/둘 다 판독 불가의 실제 표시 시안을 확인한다.
- 소스 검토, 렌더, 자동 테스트 및 Windows 실게임 판독/알림 검증을 구분해 보고한다.
