# 개발자 후원 — 시작하기 (기획 조사 2026-11-26)

사용자 11-26: '화면만 읽던 초기 앱이면 후원이 눈치 보였는데, 캐릭터 작업까지 하니 후원을 넣어도 될 것 같다 — 해 본 적이 없으니 어떻게 시작하는지 정리'.

## 순서 요약
1. **넥슨에 먼저 물어봄**(무료, 가장 중요) — 아래 메일 초안.
2. 앱에 **넥슨 출처 표기** 넣기(후원과 상관없이 이미 의무).
3. 받을 곳 고르기 — 국내 게이머 기준 **투네이션** 우선, 필요하면 GitHub Sponsors 추가.
4. 세금·회사 규정 확인 — 후원금은 종합소득세 신고 대상(매년 5월).
5. 앱에는 **작은 링크 하나**만(기능 잠금·보상 없음).

## 1. 넥슨 규정 — 왜 먼저 물어봐야 하나
- **넥슨 오픈 API 이용약관(한국어)**: 이용자가 프로그램을 제공하며 사용자로부터 'API 서비스 이용에 대한 대가 및 프로그램 등의 이용에 대한 대가(금전, 정보 제공 등 일체의 유·무형의 대가)'를 받을 때는 **홈페이지 내 안내된 내용에 따라야** 하고, 게임 IP 사용 가이드 등 회사 정책·법령을 어기면 안 됨. 후원금도 '금전 대가'로 볼 수 있음.
- **영문 약관**: 게임 데이터는 플레이어 경험을 높이는 개인적 용도, 광고·수익화 관련 서비스에 넘기거나 판매 금지, 앱 안에 넥슨을 데이터 출처로 밝히되 넥슨 보증·제휴처럼 보이지 않게.
- **넥슨 게임 IP 사용 가이드**: 영상·팬아트 같은 2차 창작물은 무료 플랫폼에서 **광고·후원금 수익 허용**(그 밖의 수익 방식은 금지). 하지만 **앱 같은 디지털 콘텐츠는 고객센터에 개별 문의**하라고 안내.
- 이 앱은 ① 오픈 API(경매장·거뿔 등)를 쓰고 ② 버프·보스 아이콘 등 **게임 화면에서 딴 그림 191개**를 판정용으로 담고 있음 → 두 규정이 다 걸림. 캐릭터 그림은 자체 제작이라 넥슨 IP가 아님.
- 결론: '무료 앱 + 자발적 후원 링크(기능 차이 없음)'가 괜찮은지 **넥슨 답을 받고** 넣음. 답이 '괜찮다'면 그 메일을 보관.

### 문의 메일 초안 (오픈 API 문의처 help_openapi@nexon.co.kr — 약관에 적힌 주소, 보내기 전 약관 페이지에서 한 번 더 확인)
```
제목: 무료 팬 제작 도구에 자발적 후원 링크를 넣어도 되는지 문의

안녕하세요. 마비노기 플레이어용 무료 Windows 도우미 앱을 개인이 만들어 배포하고 있습니다.
- 기능: 게임 화면을 읽기만 해서 버프·디버프 시간을 표시(입력 자동화·메모리 읽기 없음),
  NEXON Open API로 경매장 시세·거뿔 기록 조회.
- 게임 화면에서 딴 아이콘 일부를 화면 판정용으로 앱에 포함하고 있습니다.
- 앱은 계속 무료이고, 후원 여부에 따른 기능 차이·보상은 없습니다.

질문
1. 앱 정보 화면에 외부 후원 페이지(투네이션 등) 링크를 넣고 자발적 후원을 받아도 되는지
2. 된다면 지켜야 할 조건(표기 문구, 금지 사항 등)
3. 게임 아이콘을 판정용으로 포함하는 것에 대해 따로 필요한 절차가 있는지
4. (유료 아이템을 검토 중이면) 앱 안의 자체 제작 캐릭터·의상(넥슨 IP 아님)을 앱 전용 화폐로 판매해도 되는지 — 그 기능 자체는 넥슨 API·게임 데이터를 쓰지 않음
5. 배포 앱에 개발자 API 키 하나를 넣어 모든 사용자가 같이 써도 되는지

감사합니다.
```
(게임 IP 쪽은 넥슨 고객센터 1:1 문의에 같은 글을 넣어도 됨.)

## 2. 앱에 넥슨 출처 표기 (후원과 별개로 필요)
- 넥슨 오픈 API 가이드: 서비스·앱에 **'Data based on NEXON Open API'** 문구를 적어 달라고 함. 지금 앱에는 이 문구가 없음(코드 검색 11-26).
- 다른 넥슨 API 앱(boss_planner 0.6.1)은 데이터를 보여 주는 화면·설정 화면에 같은 문구를 넣고, API로 받아 저장한 데이터는 30일 안에 다시 받도록 맞춤.
- 위치(제안): 앱 정보/설정 화면 아래 + API 데이터를 보여 주는 탭(경매장 시세·거뿔·파티) 상태 줄 끝에 작은 회색 글씨. 정해지면 DEV.

## 4. 세금·회사 규정
- 국세청: 후원 계좌 등으로 받은 돈은 **명칭과 관계없이 종합소득세 신고 대상**. 계속·반복이면 사업소득, 일시적이면 기타소득. 신고는 **매년 5월**.
- 플랫폼 정산 내역을 모아 두면 신고가 쉬움. 애매한 건 **국세청 126 상담(무료)**.
- 직장인이면 회사 취업규칙의 겸업 조항도 한 번 봄.

## 5. 앱에 넣는 방식 (기획 원칙 — 넥슨 답이 '괜찮다'일 때)
- **후원 여부로 기능·호감도·옷이 달라지지 않음**(유료화로 보일 여지를 없앰 — 약관의 '대가' 조항과도 관련).
- 앱 정보(또는 설정) 화면에 '개발자 응원하기' 작은 링크 하나 + 한 줄 감사 글. 첫 실행 팝업·주기적 알림 없음.
- 릴리즈 노트에 한 줄로 알림. 화면은 렌더해서 사용자 확인 뒤 DEV.

## 6. 후원이 아니라 '판매'라면 (사용자 11-26 — 동행 캐릭터·전용 의상을 전용 화폐로)
- **넥슨 쪽이 더 분명하게 걸림**: 약관의 '프로그램 등의 이용에 대한 대가(금전 등)'는 후원보다 판매에 더 정확히 해당. 파는 캐릭터·옷이 넥슨 IP가 아니어도, **넥슨 API·게임 아이콘을 쓰는 같은 프로그램 안에서** 돈을 받는 것이라 → 넥슨 답을 받은 뒤에만. 위 문의 메일 4번 질문.
- **소비자 법은 타로 앱과 같음**: 결제 직전 '열람·적용 시작 뒤 환불 불가' 고지 + 동의(없으면 환불 제한 주장 못 함), 충전만 하고 안 쓴 화폐는 환불, 미성년자 결제는 보호자 동의 없으면 취소 가능, 사업자등록·통신판매업 신고, 결제대행(PG) 계약.
- **전용 화폐**: 이 앱 안에서만 쓰면 선불전자지급수단(금융위 등록) 아님. 다른 곳에서도 쓰게 하면 등록 대상이 될 수 있음.
- **뽑기(무작위 상자)로 팔지 않기**: 직접 사는 방식으로만 — 무작위 판매는 확률 표시 등 규제·민원 부담이 큼.
- **AI로 그린 그림 판매**: AI 기본법 표시 의무는 AI 서비스를 제공하는 쪽 의무라 그림을 써서 파는 것 자체는 해당 없음(정부 11-21 발표 — 개인이 AI로 만든 웹툰 연재는 표시 의무 없음). 다만 AI 그림은 저작권 보호를 받기 어려워 남이 베껴도 막기 어려움. GPT 그림 상업 이용은 OpenAI 약관상 가능.
- **기술**: exe 안에서만 확인하면 쉽게 뚫리므로 구매·보유는 서버(로그인 계정)에서 확인해야 함.
- **기획 메모**: 호감도로 여는 옷(50·100)과 파는 옷은 따로 — 호감도 보상을 돈으로 건너뛰게 하면 호감도 시스템의 의미가 줄어듦.

## 7. 자캐(전용 캐릭터) 제작 — 사용자 아이디어 11-26
- 계기: 테스터가 Starline(사용자 자캐)을 보고 '자기 캐릭터도 넣고 싶다', 장난으로 5천 원 얘기에 '너무 하고 싶다'. 사용자 안: 전용 캐릭터 2만 원, 동행 카드 뒤 실루엣 자리에 '?' 네모 카드 + '전용 캐릭터를 만들어 보세요' 링크.
- 기획 판단: **수요 신호로는 아주 좋음.** 다만 이건 후원이 아니라 **판매**(돈을 내면 앱에 그 사람 캐릭터가 생김 = 프로그램 이용 대가) → 넥슨 약관 문제가 그대로(앱 분리 안 함·수익화 보류 결정과 같은 이유). 앱 안 '?' 카드에서 결제로 이어지는 링크는 가장 직접적인 형태.
- 다른 확인거리: 목소리 — ElevenLabs 무료 요금제 결과물은 상업 이용 불가·출처 표기 필요, 유료 기간 결과물은 해지 뒤에도 상업 가능(`characters/녹음목록.md` '목소리 라이선스'). 테스터 자캐는 그 사람 창작물이라 사용 동의 필요. 캐릭터 하나 = 4면도·SD 15~20동작·걷기·말하기·목소리 30여 개 → 2만 원은 작업량에 비해 매우 낮음.
- 기획 제안: 지금은 **돈 받지 않고 테스터 감사로 한 명 만들어 보기**(작업 시간·만족도·다른 사람 반응을 재는 실험) → '?' 카드는 결제 링크 대신 '새 동행이 준비 중' 예고로. 유료는 동행이 홀로 서는 때(넥슨과 무관해질 때) 다시.
