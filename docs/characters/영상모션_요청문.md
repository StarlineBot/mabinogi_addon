# 영상 모션 요청문 — 모든 캐릭터 공통 (Gemini, 2026-11-27)

Starline에서 통과한 방식(0.59.0). 캐릭터 이름·동작 줄만 바꿔 쓴다. Starline 기록은 `Starline_영상모션_작업표.md`.

## 순서
1. **마스터 레퍼런스**(그림 생성) → 기획이 디자인·색·그림체 확인
2. 기획이 마스터 FRONT·SIDE를 잘라 **시작 그림**(초록 배경) 만듦 — `<이름>/<이름>_영상시작_정면.png`·`_옆모습.png`
3. **서 있기 영상** → 기획이 첫 장을 `<이름>/영상/0_서있기_시작.png`로 뽑음(이후 동작 시작 그림)
4. **걷기 영상**(옆모습 시작 그림)
5. **나머지 동작 영상**(0_서있기_시작.png 시작) — 한 채팅에서 몰아서 해도 됨
- 올리는 곳 `docs/characters/assets/<이름>/영상/번호_동작.gif`, **다운로드 버튼으로 원본 파일**(채팅에 붙이면 한 장짜리 그림이 됨).
- 영상 첨부는 **그림 한 장만**(마스터 시트를 첨부하면 다른 캐릭터가 나옴).

## 1. 마스터 레퍼런스 (그림 생성 — 첨부 2장)
- 첨부 ① 그 캐릭터 4면도: 다래 `다래/SD/다래 SD 캐릭터 4면도 모델 시트.png` · 레나 `레나/SD/레나_4면도.png` · 이안 `이안/SD/남성 치비 캐릭터 4면도 모델 시트.png` · 아리아 `아리아/SD/귀여운 숲속 소녀 캐릭터 턴어라운드.png`
- 첨부 ② `Starline/Starline_마스터레퍼런스.png`
```
첫 번째 첨부는 이 캐릭터의 디자인(정면·옆·뒤), 두 번째 첨부는 다른 캐릭터의 마스터 레퍼런스 시트야.
첫 번째 캐릭터로, 두 번째와 똑같은 형식과 그림체의 마스터 레퍼런스 시트를 만들어줘.

[두 번째 그림과 같게]

- 그림체: 선 굵기, 채색 방식(맑고 또렷한 셀 채색), 명암 넣는 정도, 밝기
- SD 비율: 머리와 몸 비율, 키 느낌

- 두 번째 캐릭터(토끼귀, 금빛 후광, 꼬리 등)의 디자인은 하나도 가져오지 마
```

## 2. 서 있기 영상 (첨부: `<이름>_영상시작_정면.png`)
```
첨부 그림 속 캐릭터가 그대로, 제자리에 가만히 서 있는 짧은 반복 애니메이션을 만들어줘.
- 카메라·캐릭터 위치·크기 고정, 화면 밖으로 움직이지 마
- 캐릭터 디자인·체형·옷·색·그림체·표정은 첨부 그대로, 배경은 초록 단색 그대로
- 숨 쉬듯 몸이 아주 살짝 오르내리고 좌우로 살짝 흔들리며, 가끔 천천히 눈을 깜빡여
- 마지막엔 처음 자세로 돌아와서 끝나게(끊김 없이 반복되게)
```
- 성격 한 줄 더하면 좋음(예: 다래 '졸린 듯 천천히 눈을 깜빡여', Starline '씩 웃는 표정 그대로').

## 3. 걷기 영상 (첨부: `<이름>_영상시작_옆모습.png`)
```
첨부한 그림 속 캐릭터가 그대로 오른쪽을 본 채, 제자리에서 걷는 짧은 반복 애니메이션을 만들어줘.
카메라와 캐릭터 위치·크기는 고정, 앞으로 나아가지 말고 제자리 걷기.
걸을 때 몸이 위아래로 거의 움직이지 않게, 통통 튀지 말고 차분한 걸음으로.
캐릭터 디자인·체형·옷·색은 첨부 그림 그대로, 배경은 초록 단색 그대로.
```
- 걷는 모양을 바꾸고 싶으면 한 줄 추가(예: Starline '한 손은 주머니에서 빼지 말고 반대쪽 팔만 흔들어').

## 4. 나머지 동작 (첨부: `<이름>/영상/0_서있기_시작.png`)
공통 요청문 + 동작 한 줄.
```
첨부 그림 속 캐릭터가 그대로, 제자리에서 아래 동작을 하는 짧은 애니메이션을 만들어줘.
- 카메라·캐릭터 위치·크기 고정, 화면 밖으로 움직이지 마
- 캐릭터 디자인·체형·옷·색·그림체·표정은 첨부 그대로, 배경은 초록 단색 그대로
- 동작은 차분하게, 몸이 통통 튀지 않게
- 마지막엔 처음 자세로 돌아와서 멈춰
```
- 앉은 채 끝나는 동작(웅크리기→구석 앉기)은 마지막 줄을 뺌. 이어지는 동작(일어나기, 떨어지기·착지)은 앞 영상 장을 기획이 뽑아 시작 그림으로 줌.
- 동작 줄 예시는 Starline 작업표 '동작 목록'. 캐릭터별 동작 목록은 서 있기 통과 뒤 기획이 정리.
