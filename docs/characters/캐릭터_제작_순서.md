# 새 캐릭터 만드는 순서 — 단계별 첨부 그림·요청문 (2026-11-24)

사용자 11-24: Starline을 다시 그리면서 겪은 문제(체형·머리 크기·그림체가 시트마다 달라짐)를 다음 캐릭터에서 반복하지 않게, **단계마다 무엇을 첨부하고 무엇을 요청할지** 한곳에 정리.
캐릭터 문서는 `docs/characters/<이름>.md`, 그림은 `docs/characters/assets/<이름>/`(SD 시트는 `SD/`). 예시는 다래·아리아·이안·레나·Starline 문서.

---

| 단계 | 만들 것 | **첨부할 그림** | 받은 뒤 |
|---|---|---|---|
| 0 | 컨셉 정하기(이름·성격·말투·색·목소리) | (없음 — 참고 그림이 있으면 저장만) | 기획이 `<이름>.md` 작성 |
| 1 | 앱 카드용 **상반신**(또는 전신) | ① 컨셉·얼굴 참고 그림 ② **그림체 기준 `assets/아리아/아리아_상반신.png`** | 기획이 크기·투명 배경 확인 → `<이름>_상반신.png` |
| 2 | **기준 SD 서 있기** (2프레임) | ① 1단계 결과 ② **체형 기준 SD 한 장**(아래 '체형 기준') | **기획이 체형·머리 크기를 재서 통과해야 3단계로** |

| 4 | 대사집·녹음 | (없음) | 기획이 `<이름>_대사.md`, 녹음목록 |
| 5 | 앱에 넣기 | (없음) | 기획 → DEV → QA |

- 다리가 긴 SD: `assets/Starline/SD/Starline_서있기.png`

## 지켜야 할 것 (겪은 문제 → 막는 법)

| 겪은 문제 | 캐릭터 | 막는 법 |
|---|---|---|
| 시트마다 머리 크기·등신이 달라 동작이 바뀔 때 얼굴·몸이 커졌다 작아짐 | 이안(쓰다듬기 113%), Starline(불꽃·끌기 1.13~1.17) | **2단계 서 있기를 먼저 확정**하고, 3단계는 그 한 장만 첨부. 짧은 체형·다른 체형 그림을 같이 첨부하지 않기 |
| 그림 생성 도구가 'SD'라고 하면 머리 큰 땅딸막한 체형으로 돌아감 | Starline 서 있기 재시도 | 요청문에 '첨부 그림 위에 겹쳐 놓았을 때 머리·어깨·허리·다리 길이가 같게', '일반적인 SD처럼 머리를 키우거나 몸을 줄이지 마' |
| 프레임마다 몸을 새로 그려 말하기·쓰다듬기가 꿈틀거림 | 다래·아리아·레나 | '바뀌는 부분만 바꾸고 나머지는 픽셀 단위로 같게' — 그래도 다시 그려지면 앱이 입·얼굴만 합성(빌드에서 처리) |
| 시트마다 머리색·피부색이 조금씩 다름 | 아리아·레나·다래 | 앱 빌드에서 서 있기 색에 맞춤(ΔE < 3) — 요청문에 색 코드도 적기 |
| 배경에 옅은 막(반투명)이 깔림 | 아리아 끌기 | '완전히 투명한 배경(옅은 색·반투명 막·얼룩 없이)' |
| 그림끼리 붙어 있거나 흩어져 배치·너무 작음 | Starline 말하기 첫 판 | '균일한 격자, 이웃 칸과 닿지 않게, 그림 하나 키 400px 이상' |
| 두 프레임 크기가 달라 '두근두근' | 이안 떨어지기 | 떨어지기는 **1장**으로 요청 |
| 상반신이 가로형 | 레나·Starline | 1단계 요청문에 '세로형, 다른 캐릭터 카드와 같은 비율(1199×1312 정도)' |
| 4면도·비율 비교에 라벨·글자가 붙어 잘림 | 다래·이안 | '라벨·글자 없이', 칸 사이 충분히 띄우기 |
| 동작 시트의 **몸 전체가 몇 % 크게** 그려짐(머리·몸·귀가 함께 큼) | Starline 불꽃(+7%), 재채기(머리 +5%·몸 −3.5%) | 3단계 요청문에 '첨부 서 있기 위에 겹쳤을 때 키·눈 높이·귀 길이까지 같게'. 받으면 기획이 **같은 자세 프레임끼리 실루엣·눈 높이**로 잼(머리 폭만 재면 놓침) |
| 말하기 프레임 중 **몇 장만 발·바지·망토 끝이 다르게** 그려짐(한 장은 샌들이 겹쳐 두 개) | Starline 말하기 강조 2장 | 요청문에 '**허리 아래(다리·발·옷자락)는 모든 프레임에서 첫 프레임과 똑같이 — 입·눈·팔만 바뀜**'. 받으면 발 띠(아래 12%)를 기준 프레임과 비교 |
| 같은 동작이 **두 시트로 나뉘어 색감이 다름**(한쪽 탁함·한쪽 진함) — 클릭할 때마다 색이 오르내림 | Starline 말하기 시작/반복(채도 65 ↔ 73, 서 있기 69) | 한 동작은 **한 대화에서 이어서** 만들고 앞 시트를 첨부해 '첫 번째 첨부와 같은 색감(채도·밝기)'. 받으면 머리·피부뿐 아니라 **옷 중간 톤·채도**도 서 있기와 비교 |
| 다시 그린 시트가 **예전 짧은 체형·졸린 눈매로 돌아감**(그림체가 바뀜) | Starline 말하기·구석 첫 판 | 3단계는 **기준 서 있기 한 장만** 첨부(예전 시트를 같이 첨부하지 않기), '눈매·얼굴은 첨부와 같게' |
| 카드(상반신)에서 **캐릭터 시그니처가 잘림**(손 든 포즈) | Starline 카드 | 1단계 요청 때 '시그니처 포즈(예: 들어 올린 손)가 세로형 안에 다 들어오게'. 카드 자르기는 얼굴 가운데가 기본이라, 시그니처가 옆에 있으면 자르는 위치를 따로 정함 |

**그래도 비율이 조금 깨질 때(사용자 11-24 '어쩔 수 없는 건 있음')**: 그림 생성 도구는 같은 요청에도 체형이 조금씩 흔들림. 그래서 ① 시트를 받을 때마다 기획이 기준 서 있기와 얼굴 크기·키 비율을 재고, ② **±5% 안이면 그대로 씀** — 앱이 시트마다 머리 크기 기준으로 배율을 맞춰 얼굴 크기는 같게 보이게 함, ③ 그보다 크게 다르면 그 시트만 다시 그림(이안 쓰다듬기 113%, Starline 서 있기 0.87 같은 경우).

### 다시 그릴 때 가이드 (사용자 11-25 규칙 — 다래 걷기·착지·일어나기에서 효과 확인)
- 비율이 틀린 시트를 **다시 그릴 때는 항상 가이드 그림**을 첫 번째로 첨부: 칸마다 맨 왼쪽(또는 줄마다 맨 앞)에 **기준 서 있기**를 넣고 나머지는 빈 칸, 모든 칸에 같은 높이의 **분홍 가로선**(헤일로·귀 끝 위 / 정수리 / 눈 / 턱 / 치마 끝 / 바닥), 파란 칸 테두리. 예: `assets/다래/SD/가이드_걷기.png`.
- 요청문엔 '빈 칸에 그리고, 머리·눈·턱이 기준과 같은 선에 오게 — 선에 맞추면 저절로 같아짐'. **'머리를 몇 % 줄여', '다리를 길게' 같은 방향·숫자 지시는 쓰지 않음**(GPT가 그것만 과하게 따라 다른 캐릭터가 나옴 — 사용자 11-25).
- 결과에 기준 칸·선·테두리가 남아도 됨 — 기획이 색으로 지우고(분홍 R>170·B>170·G<110, 파랑 R<90·G>120·B>190), 기준 칸 키를 서 있기 키에 맞추는 배율로 나머지 칸을 넣음.
- 기획이 가이드를 만드는 법: 서 있기 원본에서 각 높이를 재 선을 긋고, 칸 크기 = 기준 그림 + 여백(예: 560×700).
- **문제없는 캐릭터의 새 옷**은 다시 그리는 게 아니라 옷만 바꾸는 것이라 가이드 대신 **전체 프레임 시트**(`새옷_전체프레임_한번에.md`)를 씀.

### 시트를 받을 때 기획 점검 목록 (Starline 11-25에서 배움 — 이 순서로 재고 넘김)
1. 프레임 수·칸 배치가 요청과 같은지, 배경 옅은 막 없는지
2. **같은 자세 프레임끼리**(첫·끝 프레임 ↔ 서 있기) 실루엣 배율, 키, **눈 높이**, 눈 간격 — 머리 폭만 보면 '몸 전체가 큰' 경우를 놓침. ±3% 넘으면 원인 확인, ±5% 넘으면 다시 그리기
3. **발 띠**(그림 아래 12%)를 기준 프레임과 비교 — 말하기·쓰다듬기처럼 제자리 동작은 발이 그대로여야 함
4. 색: 머리·피부 ΔE, **옷 중간 톤 Lab·채도** — 한 동작이 여러 시트면 시트끼리도 비교
5. 눈매·얼굴이 서 있기와 같은지(예전 그림체로 돌아가지 않았는지) 눈으로 확인
6. 카드용 상반신이면 카드 틀(224×280, 머리 위 20px)에 넣었을 때 시그니처가 보이는지

앱 쪽에서 정해진 것(요청문에 반영할 필요는 없음): 서 있는 키 190px로 그림(원본은 285px로 만듦), 그림 전환은 겹치지 않고 바로 바꿈(잔상 방지), 말하기는 입만 바꿔 끼움.

템플릿 5절에 한 줄 추가: `* 이미지 비율: 세로형 — 상반신은 다른 캐릭터 카드와 같은 세로 비율(약 1199×1312), 투명 배경`.

## 2단계 — 기준 SD 서 있기 (가장 중요)

첨부: ① 1단계 결과(전신 또는 상반신) ② **체형 기준 SD 한 장**.
받으면 기획에 '서 있기 받았어'라고 알려 주기 → 기획이 체형 기준과 얼굴 크기·키 비율을 재서 통과/다시를 알려 줌.

```markdown
첨부한 첫 번째 이미지는 [이름]의 캐릭터 그림, 두 번째 이미지는 이 앱에서 쓰는 SD 체형 기준이야.
첫 번째 캐릭터를 두 번째 이미지와 **같은 체형**의 SD로 그려줘. 이 그림이 앞으로 모든 SD 동작의 기준이 돼.

## 캐릭터 — [이름]
* [한 줄 소개 — 종족·직업·성격]
* 외형: [머리 모양·색(#코드)], [눈 색], [특징]
* 의상: [상의·하의·신발·색(#코드)]
* 장식: [장신구 — 펫 크기에서 뭉개지지 않게 단순하게]

## 가장 중요한 조건 — 두 번째 이미지와 같은 체형
* 머리 크기와 키의 비율(등신), 다리 길이, 팔 길이, 어깨 폭을 두 번째 이미지와 똑같이
* 두 번째 이미지 위에 겹쳐 놓았을 때 머리 크기·어깨 높이·허리 높이·발 위치가 같아야 해
* 일반적인 SD처럼 머리를 더 키우거나 몸·다리를 짧게 줄이지 마
* 그리기 전에 두 번째 이미지에서 **머리 높이(토끼귀·후광 같은 장식 제외) : 전체 키** 비율을 먼저 숫자로 알려 주고, 그 비율 그대로 그려줘
* 다 그린 뒤 두 번째 이미지와 같은 키로 나란히 놓고 머리 크기·다리 길이가 같은지 스스로 확인해서, 다르면 고쳐서 보여줘

## 만들 것 — 서 있기 (2프레임, 2열 × 1행)
* Frame 1: 기본 서 있기 — [성격이 드러나는 기본 자세·표정]
* Frame 2: Frame 1과 같은 자세, 눈만 감은 눈 깜빡임 — 바뀌는 부분: 눈만

## 규격
* 두 프레임 캔버스 크기 동일, 바닥선·하단 중앙 기준점 고정, 그림 하나 키 400px 이상
* 머리부터 발끝까지 잘리지 않는 전신, 각 칸 안에 완전히 포함하고 이웃 칸과 닿지 않게
* 완전히 투명한 배경(옅은 색·반투명 막·얼룩 없이)
* 텍스트·라벨·프레임 번호·격자선·그림자·효과선·이펙트 없음
```

## 3단계 — 나머지 SD 동작

첨부: **2단계 서 있기 한 장만.** 아래 '공통 머리말'을 맨 앞에, 그다음 동작별 본문을 붙여 한 덩어리로 요청(Starline 예시: `Starline_SD요청문.md`).
권하는 순서: 걷기 → 끌기 → 떨어지기 → 착지 → 쓰다듬기 → 대기 번갈아 → 구석 → 말하기. 시트를 받을 때마다 기획이 재서 알려 줌.

### 공통 머리말 (모든 동작 요청 맨 앞)
```markdown
첨부한 이미지는 [이름]의 기준 SD 서 있기야. 이 그림과 **같은 체형·같은 그림체**로 데스크톱 펫 앱에서 쓸 SD 애니메이션 스프라이트 시트를 만들어줘.

## 캐릭터 — [이름]
* [한 줄 소개·성격]
* 외형·의상·장식: [2단계와 같은 내용, 색 코드 포함]

## 가장 중요한 조건 — 기준과 같은 체형, 프레임 간 일관성
* 첨부 그림 위에 겹쳐 놓았을 때 머리 크기, 어깨 높이, 허리 높이, 다리 길이가 같아야 해 — 일반적인 SD처럼 머리를 키우거나 몸·다리를 줄이지 마
* 서 있는 자세가 나오는 프레임은 첨부 그림과 키·머리 크기가 같게, 앉거나 매달린 자세도 머리 크기는 같게
* 그리기 전에 첨부 그림의 **머리 높이(장식 제외) : 전체 키** 비율을 먼저 숫자로 알려 주고, 모든 프레임을 그 비율로 그려줘
* 다 그린 뒤 첨부 그림과 같은 키로 나란히 놓고 머리 크기·다리 길이가 같은지 스스로 확인해서, 다르면 고쳐서 보여줘
* 아래 '바뀌는 부분'만 바꾸고 머리카락·윤곽선·의상 주름은 프레임마다 새로 그리지 마
* 머리색·피부색·옷 색은 첨부 그림과 같은 색으로

## 공통 규격
* 모든 프레임 캔버스 크기 동일, 바닥선·하단 중앙 기준점 고정, 그림 하나 키 400px 이상
* 머리부터 발끝까지 잘리지 않는 전신, 각 칸 안에 완전히 포함하고 이웃 칸과 닿지 않게, 균일한 격자
* 완전히 투명한 배경(옅은 색·반투명 막·얼룩 없이)
* 텍스트·라벨·프레임 번호·격자선·그림자·효과선·땀·느낌표·이펙트 없음(동작 설명에서 허용한 것만 예외)
```
