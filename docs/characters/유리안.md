# 캐릭터 설정 — 유리안(가칭, 이름 미확정)

- 상태: **컨셉 이미지만 받음(사용자 11-24)**. 이름 '유리안'은 가칭 — 이안과 '안'이 겹쳐 확정 아님(사용자 11-24). 이름이 바뀌면 이 문서·그림 폴더 이름도 바꾼다.
- 컨셉 이미지: `docs/characters/assets/유리안/유리안_컨셉.jpeg`(768×1024, 배경 있음 — 참고용).
- 사용자 설명(11-24): **맑은 목소리의 미남형** 캐릭터. 목소리 팩은 새로 녹음 예정(지금 팩 5개에 없음 — 6번째).
- 컨셉 이미지에서 보이는 것: 은백색 짧은 머리(앞머리가 한쪽 눈을 살짝 가림), 회청색 눈, 부드러운 미소, 남색 + 금 장식의 귀족풍 제복(높은 깃·금 자수 소매), 흰 크라바트, 반투명 흰 망토, 푸른 보석 금 브로치, 흰 사선 벨트. 우아하고 깨끗한 왕자·기사 느낌.
- 색 주의: 메인 남색 + 금 포인트가 **이안(남색 정장 + 금 시계·배지)과 겹침** — 펫 크기(190px)에서 둘이 같은 색 덩어리로 보일 수 있음. 이 캐릭터는 은백·흰 + 하늘색을 앞세우고 남색은 줄이는 쪽을 제안(미확정).
- 정할 것: 이름, 목소리 팩(새 녹음), 성격·말투, 색 확정, 나머지 컨셉 → `design-request-template.md` 형식으로.
- 받은 그림은 `assets/유리안/`(SD 시트는 `SD/`)에.
