# 캐릭터 설정 — 시엘 (목소리: 맑은 목소리 미남형, 새 녹음 예정)

- 상태: **이름·색 확정, 컨셉 이미지 받음(사용자 11-24)**. 이름 **시엘**(가칭 유리안은 이안과 '안'이 겹쳐 바꿈 — 후보 시엘·노엘·엘리오·루시엔 중).
- 컨셉 이미지: `docs/characters/assets/시엘/시엘_컨셉.jpeg`(768×1024, 배경 있음 — 참고용).
- 사용자 설명(11-24): **맑은 목소리의 미남형** 캐릭터. 목소리 팩은 새로 녹음 예정(지금 팩 5개에 없음 — 6번째).
- 컨셉 이미지에서 보이는 것: 은백색 짧은 머리(앞머리가 한쪽 눈을 살짝 가림), 회청색 눈, 부드러운 미소, 남색 + 금 장식의 귀족풍 제복(높은 깃·금 자수 소매), 흰 크라바트, 반투명 흰 망토, 푸른 보석 금 브로치, 흰 사선 벨트. 우아하고 깨끗한 왕자·기사 느낌.
- 색 주의: 메인 남색 + 금 포인트가 **이안(남색 정장 + 금 시계·배지)과 겹침** — 펫 크기(190px)에서 둘이 같은 색 덩어리로 보일 수 있음. → **결정(사용자 11-24): 은백·흰 + 하늘색**을 앞세우고 남색은 줄임(이안과 구분).
- 정할 것: 목소리 팩(새 녹음), 성격·말투, 나머지 컨셉 → `design-request-template.md` 형식으로.
- 받은 그림은 `assets/시엘/`(SD 시트는 `SD/`)에.
