```markdown

## 가장 중요한 조건 — 기준 이미지와 같은 비율

이전에 만든 시트들은 머리 크기와 등신이 기준 이미지와 달라서, 앱에서 동작이 바뀔 때마다 얼굴이 커졌다 작아졌다 했어.
이번에는 반드시 아래를 지켜줘.

* 머리 크기(머리 폭·높이), 머리와 몸의 비율(등신), 팔다리 길이와 굵기를 첨부한 기준 이미지와 똑같이
* 캔버스 안 캐릭터 크기도 기준 이미지와 같게 — 서 있는 자세가 나오는 프레임은 기준 이미지와 키·머리 크기가 같아야 함
* 얼굴(조금 각진 얼굴, 짙은 갈색 눈), 흑갈색 짧은 머리, 남색 캐주얼 정장(넥타이 없음), 짙은 갈색 구두, 왼쪽 손목 금색 손목시계, 재킷 깃의 작은 금색 배지를 기준 이미지와 같은 모양·색·외곽선 굵기·채색으로
* 프레임마다 머리카락·윤곽선·의상 주름을 새로 그리지 말고, 아래에서 '바뀌는 부분'으로 적은 곳만 바꿔줘

## 공통 규격

* 모든 프레임의 캔버스 크기 동일, 바닥선과 하단 중앙 기준점 고정
```

## 1. 쓰다듬기 (6프레임, 3열 × 2행)
```markdown
## 쓰다듬기(Petting) — 6프레임, 3열 × 2행

머리를 쓰다듬어도 몸은 전혀 움직이지 않고 기준 서 있기 자세 그대로, 표정만 약간 짜증 난 얼굴로 바뀜('…또요?' 정도의 담담한 짜증).
머리 각도·어깨·팔다리는 모든 프레임에서 기준 서 있기와 같게. 쓰다듬는 손에 머리 윗부분 머리카락만 아주 살짝 눌림. 손·커서는 그리지 마.

* Frame 1: 기본 무표정, 시선만 살짝 위를 향함 — 바뀌는 부분: 눈동자
* Frame 2: 미간을 살짝 찌푸리기 시작 — 바뀌는 부분: 눈썹
* Frame 3: 미간을 찌푸리고 눈을 가늘게 뜬 짜증 표정 — 바뀌는 부분: 눈썹, 눈
* Frame 4: 짜증 표정 그대로 눈동자만 옆으로 피함 — 바뀌는 부분: 눈동자
* Frame 5: 짜증 표정 그대로 입꼬리만 살짝 내려감 — 바뀌는 부분: 입
* Frame 6: 표정이 풀리며 기본 무표정으로 돌아옴

Frame 3~5는 반복 재생해도 자연스럽게 이어지게, 몸·머리 위치와 윤곽은 모든 프레임에서 완전히 같게.
볼 홍조, 미소, 움츠리기, 고개 기울이기는 넣지 마.
```

## 2. 끌기 (4프레임, 2열 × 2행)
```markdown
## 끌기(Drag) — 4프레임, 2열 × 2행

머리 위쪽을 마우스로 잡혀 공중에 매달린 상태. 놀라거나 당황하지 않고 들린 대로 팔다리가 축 늘어진 무표정(입만 아주 조금 벌어짐).
스스로 버둥거리지 않고, 흔들리는 힘에 따라 다리가 살짝 굽혀지는 정도. 재킷 자락·소매는 중력 방향으로 늘어짐.
머리 크기는 기준 서 있기와 같게(매달렸다고 머리를 키우지 마). 머리 꼭대기(잡히는 곳) 위치는 모든 프레임에서 같게.

* Frame 1: 팔다리가 아래로 늘어진 기본 자세
* Frame 2: 몸이 흔들리며 왼쪽 다리가 살짝 굽혀짐 — 바뀌는 부분: 왼다리, 팔 끝
* Frame 3: 기본 자세로 돌아오는 중간 — 바뀌는 부분: 다리, 팔 끝
* Frame 4: 몸이 흔들리며 오른쪽 다리가 살짝 굽혀짐 — 바뀌는 부분: 오른다리, 팔 끝

손·커서·밧줄 등 들어 올리는 물체는 그리지 마.
```

## 3. 착지 (3프레임, 3열 × 1행)
```markdown
## 착지(Land) — 3프레임, 3열 × 1행

떨어지던 이안이 두 발로 착지해 무릎으로 충격을 받고 바로 바르게 서는 동작. 넘어지거나 손을 짚지 않음. 처음부터 끝까지 무표정.
모든 프레임의 머리 크기는 기준 서 있기와 같게 — 무릎을 굽혀 키만 낮아지고 머리는 커지지 않게.

* Frame 1: 두 발이 바닥에 닿으며 무릎이 살짝 굽혀짐, 팔은 몸 옆에서 살짝 뜸
* Frame 2: 무릎을 조금 더 굽혀 충격을 받음(몸만 살짝 낮아짐)
* Frame 3: 무릎을 펴고 두 손을 내린 기준 서 있기 자세 — 첨부한 서 있기 그림과 완전히 같게

모든 프레임의 발바닥 선과 가로 중심은 같게.
```

## 4. 구석: 웅크리기 → 앉아 기다리기 → 일어나기 (3 + 4 + 3, 시트 3장)
```markdown
## 구석 대기 — 시트 3장

게임 중 화면 구석에서 쪼그려 앉아 손목시계를 보며 기다리는 동작. 모든 프레임에서 머리 크기는 기준 서 있기와 같게(앉았다고 머리를 키우지 마).

### A. 웅크리기 — 3프레임, 3열 × 1행
* Frame 1: 기준 서 있기 자세(첨부 그림과 같게)
* Frame 2: 무릎을 굽혀 내려가는 중간 자세
* Frame 3: 쪼그려 앉은 자세, 왼손목의 시계가 보이게 팔을 무릎 위에 — 앉아 기다리기 Frame 1과 같은 그림

### B. 앉아 기다리기 — 4프레임, 2열 × 2행
* Frame 1: 쪼그려 앉아 왼손목 시계를 보는 기본 자세, 무표정
* Frame 2: 같은 자세, 시선만 정면으로 — 바뀌는 부분: 눈동자
* Frame 3: 같은 자세, 눈 감은 눈 깜빡임 — 바뀌는 부분: 눈
* Frame 4: 같은 자세, 작게 한숨 쉬는 입 — 바뀌는 부분: 입
몸·팔·다리·머리 위치는 4프레임 모두 같게.

### C. 일어나기 — 3프레임, 3열 × 1행
* Frame 1: 앉아 기다리기 Frame 1과 같은 자세
* Frame 2: 무릎을 펴며 일어나는 중간 자세
* Frame 3: 기준 서 있기 자세(첨부 그림과 완전히 같게)
```

## 5. 말하기 (시작 2 · 반복 6 · 끝 2, 시트 3장)
```markdown
## 말하기(Talk) — 시트 3장

이안은 말수 적고 차분한 사무관이라 몸짓은 작고 절제되게, 표정은 무표정에 가깝게.
기본 말하기 자세는 두 손을 가슴 앞에 모으고 왼손목 시계가 보이는 자세. 모든 프레임에서 머리 크기·키는 기준 서 있기와 같게.

### A. Talk Enter — 2프레임, 2열 × 1행
* Frame 1: 기준 서 있기에서 두 손이 가슴 앞으로 반쯤 올라온 중간 자세
* Frame 2: 기본 말하기 자세 — Talk Loop Frame 1과 완전히 같은 그림

### B. Talk Loop — 6프레임, 3열 × 2행
* Frame 1: 기본 말하기 자세, 입 다묾 — 기준 그림
* Frame 2: 입만 살짝 벌림
* Frame 3: 입만 조금 더 벌림
* Frame 4: 강조 — 오른손을 가볍게 펴서 앞으로 내밀며 말함(왼손은 그대로), 고개 아주 조금 끄덕임 — 바뀌는 부분: 오른손·팔, 고개 각도 조금, 입
* Frame 5: Frame 4와 1의 중간, 입 벌림
* Frame 6: Frame 1과 같은 자세, 눈만 감은 눈 깜빡임
Frame 2·3은 입만 다르고 나머지는 Frame 1과 픽셀 단위로 같게.

### C. Talk Exit — 2프레임, 2열 × 1행
* Frame 1: 두 손을 내리는 중간 자세, 입 다묾
* Frame 2: 기준 서 있기 자세(첨부 그림과 완전히 같게)
```

## 6. 알림 말하기 — 시계 가리키기 (6프레임, 3열 × 2행)
```markdown
## 알림 말하기 — 6프레임, 3열 × 2행

버프 시간을 알려 줄 때 왼손목의 시계를 오른손 검지로 톡톡 가리키며 말하는 동작. 무표정, 차분하게.
모든 프레임에서 몸·머리 위치와 머리 크기는 기준 서 있기와 같게, 팔과 입만 바뀜.

* Frame 1: 왼손목을 가슴 앞으로 들어 시계를 보여 주는 자세, 입 다묾
* Frame 2: 오른손 검지로 시계를 가리킴, 입 살짝 벌림
* Frame 3: 검지로 시계를 톡 두드림, 입 조금 더 벌림
* Frame 4: Frame 2와 같은 자세, 입 다묾
* Frame 5: Frame 3과 같은 자세, 입 살짝 벌림
* Frame 6: Frame 1과 같은 자세, 눈 깜빡임
```

## 7. 걷기 (6프레임, 3열 × 2행)
```markdown
## 걷기(Walk Cycle) — 6프레임, 3열 × 2행

오른쪽을 바라보는 측면 방향의 차분한 걸음. 무릎을 높이 들지 않고 보폭은 기준 체형에 맞게 자연스럽게.
측면이라도 머리 크기는 기준 서 있기와 같게 — 옆모습이라고 머리를 키우거나 머리카락 부피를 늘리지 마.

* Frame 1: 앞발이 땅에 닿는 자세
* Frame 2: 체중이 앞발로 이동하는 자세
* Frame 3: 뒷발이 앞으로 지나가는 자세
* Frame 4: 반대쪽 발이 땅에 닿는 자세
* Frame 5: 반대쪽 발에 체중이 이동하는 자세
* Frame 6: Frame 1로 자연스럽게 이어지는 자세

6프레임 간격을 고르게, 팔은 다리와 반대로 작게 흔들고, 머리와 몸통의 위아래 움직임은 아주 작게.
캔버스 안에서 이동하지 않는 제자리 걷기.
```
