# 다래 대사 (2026-11-24 — 사용자 확인: 좋음)

- 말풍선 글자 대사. 알림 목소리(`assets/sounds/조용한 여성/`)는 지금 녹음 그대로 쓰고, 그 알림 때 말풍선은 녹음 내용과 같은 뜻으로 짧게.
- 말투: 작고 느긋하게, 말끝을 흐림(…), 무심한 듯 챙김. 존댓말 반말 섞지 않고 **부드러운 반말**로 통일(바꾸려면 알려 주기).
- 한 상황에 여러 줄을 두고 무작위로 고름(같은 줄 연속 금지). 한 줄은 말풍선 두 줄(약 30자) 안.
- 나중에 호감도 단계(20·40·60·80·100)마다 줄을 더하는 구조 — 이 초안은 **처음(0단계) 대사**.
- 저장 위치(개발): 제작자 잡담처럼 데이터 파일(`dialogues.json` 같은 형식)로 — 앱 배포 없이 대사를 늘릴 수 있게.
