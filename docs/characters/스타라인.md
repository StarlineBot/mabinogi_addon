# 캐릭터 설정 — 스타라인 (Starline)

- 상태: **컨셉 정하는 중(사용자 11-24)** — 사용자 본인의 게임 캐릭터. 제작자 프로필(섯다라인, 8bit 선글라스)과는 다른 캐릭터.
- 컨셉 그림: `docs/characters/assets/스타라인/스타라인_컨셉.webp`(사용자 제공 11-24, 1024×1536 투명 배경 전신). 받은 그림은 `assets/스타라인/`(SD 시트는 `SD/`)에.

## 정해진 것 (사용자 11-24)
- **천년의 마법사**. 기본적으로 **토끼귀가 있는 수인**, **상어 이빨**.
- 색:
  - 메인 `#3A0729`(RGB 58·7·41, 짙은 자주·와인)
  - 머리 `#FFD8B4`(밝은 살구·크림)
  - 장식 `#D8AA5E`(금)
  - 옷: 검정 `#000000` + 메인 `#3A0729`
- 컨셉 그림에서 보이는 것: 남성, 짙은 피부, 무릎까지 오는 풍성한 웨이브 장발(크림), 노란 눈, 토끼귀(안쪽 분홍), 상어 이빨을 드러낸 씩 웃는 얼굴, 긴 검은 손톱, 손가락마다 금 반지·금 팔찌·금 사슬, 머리 뒤 금빛 가시 후광(가운데 검은 고리) + 양옆에 떠 있는 눈 달린 금 장식 2개 + 보라 매듭 술 장식, 검은 셔츠(자주 줄무늬 조끼), 자주 허리띠, 금 장식 자주·검정 망토(안감 자주 무늬), 검은 통바지, 빨강·검정 끈 샌들.

- **목소리(사용자 11-24)**: **새로 녹음** — 맑고 장난기 있는 목소리.
- **성격(사용자 11-24)**: **익살스럽고 악당에 가까운** 성격.
- **이름 색(사용자 11-24)**: 메인색 `#3A0729` 글자 + **금색 `#D8AA5E` 외곽선**(어두운 글자가 잘 보이게). 말풍선 테두리도 같은 조합 제안.
- **그림(사용자 11-24)**: 컨셉 그림은 참고용, **다른 캐릭터 그림체로 다시 그려 달라고 요청할 예정** → 요청문은 템플릿으로 정리.

## 정할 것
1. ~~목소리~~ → 새 녹음(맑고 장난기)
2. ~~성격~~ → 익살스럽고 악당에 가까움 — 말투(반말/존댓말, 말버릇)는 정할 것
3. SD에서 장식을 얼마나 줄일지: 머리 뒤 가시 후광 + 떠 있는 눈 장식 2개 + 망토 + 장신구가 많아 190px 펫에서는 뭉개짐 → 후광 하나만 단순하게, 떠 있는 장식 생략 제안
4. ~~그림체~~ → 다시 그림
