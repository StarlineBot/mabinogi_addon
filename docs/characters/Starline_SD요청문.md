# Starline SD 요청문 (2026-11-24)

사용자 11-24: 모션별로 **머리말까지 전부 포함한 한 덩어리**씩 복사할 수 있게. 순서대로 — **0번(기준 SD)을 먼저 받고**, 1~7번은 0번에서 받은 서 있기 그림을 첨부해 요청.
받은 시트는 `docs/characters/assets/Starline/SD/`에(0번 서 있기는 `Starline_SD_기준.png`로 저장하면 이후 요청에 그대로 첨부).

|---|---|---|

## 0. 기준 SD — 서 있기 + 4면도 (가장 먼저)

첨부: 다시 그린 Starline 전신 그림(아직 없으면 `assets/Starline/Starline_컨셉.webp`) + `assets/아리아/SD/양쪽 포즈의 꽃장식 소녀 캐릭터 스프라이트.png`(다른 캐릭터 SD 등신 참고)

```markdown
첨부한 이미지는 Starline의 기준 그림이야. 이 기준을 바탕으로 데스크톱 펫 앱에서 쓸 SD 캐릭터 애니메이션 스프라이트 시트를 제작해줘.

## 캐릭터 — Starline

* 천 년을 산 대마법사, 토끼귀가 있는 수인 남성, 상어 이빨
* 성격: 익살스럽고 능청스러우며 악당에 가까움 — 늘 여유만만하고 거만하게 씩 웃음, 남을 놀리는 걸 즐김
* 외형: 무릎까지 오는 크림색(#FFD8B4) 웨이브 장발, 머리 위로 솟은 토끼귀(겉 크림·안쪽 연분홍), 짙은 갈색 피부, 노란 눈, 상어 이빨 미소, 긴 검은 손톱
* 의상: 검은 셔츠 + 짙은 자주(#3A0729) 줄무늬 조끼, 짙은 자주 허리띠, 검은 통바지, 검정·짙은 자주 망토(금 테두리), 검은 굽 샌들(짙은 자주 끈)
* 장식: 금(#D8AA5E) 반지·팔찌·사슬, 머리 뒤에 작고 단순한 금빛 가시 후광 하나(떠 있는 다른 장식 없음)

## 만들 것 — 기준 SD (시트 2장)

다른 캐릭터와 같은 SD 비율(약 2.5등신 — 두 번째 첨부 이미지와 같은 머리·몸 비율, 키 기준 같은 크기)로 Starline의 SD 기준 그림을 만들어줘.
이후 모든 SD 애니메이션이 이 그림을 기준으로 만들어져.

### A. 서 있기 — 2프레임, 2열 × 1행
* Frame 1: 기본 서 있기 — 한 손은 주머니, 다른 손은 허리 옆에 느슨하게, 고개를 살짝 들고 상어 이빨을 보이며 씩 웃음
* Frame 2: Frame 1과 같은 자세, 눈만 감은 눈 깜빡임 — 바뀌는 부분: 눈만

### B. 4면도 — 4프레임, 4열 × 1행(칸 사이를 충분히 띄워 서로 닿지 않게)
* 정면 / 45도 측면 / 90도 측면(오른쪽을 봄) / 후면 — 같은 크기·같은 바닥선, 라벨·글자 없이

## 공통 규격

* 모든 프레임의 캔버스 크기 동일, 바닥선과 하단 중앙 기준점 고정
* 머리부터 발끝까지 잘리지 않는 전신(토끼귀 끝·후광·긴 머리 끝·망토 자락 포함), 각 프레임은 자기 칸 안에 완전히 포함
* 완전히 투명한 배경(옅은 색·반투명 막·얼룩 없이)
* 텍스트, 프레임 번호, 격자선, 그림자, 효과선, 땀·느낌표·분노 표시 없음
* 마법 이펙트(빛·불꽃·마법진·반짝임)도 그리지 마
* 기존 그림과 같은 그림체, 외곽선 굵기, 채색 방식, 시점

실제 데스크톱 애플리케이션에서 프레임 단위로 잘라 쓸 리소스이므로 기준과의 비율 일치와 프레임 간 일관성을 최우선으로 해줘.
```

```markdown
* Frame 1: 기준 서 있기에서 오른손을 가슴 높이로 들어 손바닥을 위로 폄 — 바뀌는 부분: 오른팔·손
* Frame 2: 손바닥 위에 작은 불꽃이 피어오름, 불꽃을 내려다보며 히죽 — 바뀌는 부분: 불꽃, 시선
* Frame 3: 불꽃이 조금 더 커져 흔들림 — 바뀌는 부분: 불꽃 모양만
* Frame 4: 손을 쥐어 불꽃을 끄며 팔을 내리는 중간 자세 — 바뀌는 부분: 오른팔·손(불꽃 없음)

불꽃은 손바닥 위 작은 것 하나만(짙은 자주와 금빛이 섞인 마법 불꽃, 손 크기 정도). 몸·머리·왼팔·다리는 모든 프레임에서 기준과 같게.
```

```markdown
## 만들 것 — 걷기 (6프레임, 3열 × 2행)

오른쪽을 바라보는 측면 방향. 가슴을 쫙 펴고 턱을 살짝 든 채 거만하게 느릿느릿 걷는 걸음(한 손은 주머니, 다른 팔은 크게 흔듦). 표정은 여유로운 씩 웃음.

* Frame 1: 앞발이 땅에 닿는 자세
* Frame 2: 체중이 앞발로 이동하는 자세
* Frame 3: 뒷발이 앞으로 지나가는 자세
* Frame 4: 반대쪽 발이 땅에 닿는 자세
* Frame 5: 반대쪽 발에 체중이 이동하는 자세
* Frame 6: Frame 1로 자연스럽게 이어지는 자세

바뀌는 부분: 다리, 흔드는 팔, 망토 자락·머리카락 끝의 작은 흔들림. 측면이라도 머리 크기는 기준과 같게(옆모습이라고 머리를 키우지 마).
프레임 간격을 고르게, 머리와 몸통의 위아래 움직임은 아주 작게, 캔버스 안에서 이동하지 않는 제자리 걷기.
```

```markdown
머리 위쪽(후광 아래 머리 꼭대기)을 마우스로 잡혀 공중에 매달린 상태. 당황하지 않고 팔짱을 낀 채 고개를 젖혀 위(마우스)를 올려다보며 "아앙?" 하고 시비 거는 표정(한쪽 눈썹을 치켜올리고 상어 이빨을 드러내며 비웃음).
팔짱은 모든 프레임에서 유지, 다리는 늘어져 있다가 건들건들 흔들림. 토끼귀는 위로 젖혀짐.

* Frame 1: 팔짱 끼고 매달려 위를 올려다보는 기본 자세, 다리는 늘어짐
* Frame 2: 왼다리를 건들 흔듦 — 바뀌는 부분: 왼다리, 망토 자락 끝
* Frame 3: 기본 자세로 돌아오는 중간 — 바뀌는 부분: 다리
* Frame 4: 오른다리를 건들 흔듦 — 바뀌는 부분: 오른다리, 망토 자락 끝

머리 꼭대기(잡히는 곳) 위치는 모든 프레임에서 같게. 팔짱·얼굴·몸통·머리 각도는 모든 프레임에서 같게.
손·커서·밧줄 등 들어 올리는 물체는 그리지 마.

## 공통 규격

* 모든 프레임의 캔버스 크기 동일, 바닥선과 하단 중앙 기준점 고정
* 머리부터 발끝까지 잘리지 않는 전신(토끼귀 끝·후광·긴 머리 끝·망토 자락 포함), 각 프레임은 자기 칸 안에 완전히 포함
* 완전히 투명한 배경(옅은 색·반투명 막·얼룩 없이)
* 텍스트, 프레임 번호, 격자선, 그림자, 효과선, 땀·느낌표·분노 표시 없음
* 마법 이펙트(빛·불꽃·마법진·반짝임)도 그리지 마
* 기존 그림과 같은 그림체, 외곽선 굵기, 채색 방식, 시점

실제 데스크톱 애플리케이션에서 프레임 단위로 잘라 쓸 리소스이므로 기준과의 비율 일치와 프레임 간 일관성을 최우선으로 해줘.
```

```markdown
### B. Talk Loop — 6프레임, 3열 × 2행

* Frame 6: Frame 1과 같은 자세, 눈만 감은 눈 깜빡임

### C. Talk Exit — 2프레임, 2열 × 1행
```

```markdown
## 캐릭터 — Starline

* 천 년을 산 대마법사, 토끼귀가 있는 수인 남성, 상어 이빨
* 성격: 익살스럽고 능청스러우며 악당에 가까움 — 늘 여유만만하고 거만하게 씩 웃음, 남을 놀리는 걸 즐김

## 만들 것 — 구석 대기 (시트 3장)

게임 중 화면 구석에서 기다리는 동작. 바닥에서 살짝 떠서 책상다리로 앉아, 검지를 빙빙 돌리며 작은 마법진을 그리는 모습. 심심해하면서도 즐거운 씩 웃음.

### A. 앉기 — 3프레임, 3열 × 1행
* Frame 1: 기준 서 있기 자세(첨부 그림과 같게)
* Frame 2: 무릎을 굽히며 몸이 살짝 떠오르는 중간 자세
* Frame 3: 바닥에서 살짝 떠서 책상다리로 앉은 자세, 오른손 검지를 세움 — 앉아 있기 Frame 1과 같은 그림

### B. 앉아 있기 — 4프레임, 2열 × 2행
* Frame 1: 떠서 책상다리로 앉아 오른손 검지 끝에 작은 마법진(손바닥 크기의 금빛 원형 문양)이 그려지는 모습
* Frame 2: 검지를 돌려 마법진이 조금 회전한 모습 — 바뀌는 부분: 검지 끝 위치, 마법진 각도
* Frame 3: 계속 돌림 — 바뀌는 부분: 검지 끝 위치, 마법진 각도
* Frame 4: 계속 돌림, 눈 깜빡임 — 바뀌는 부분: 검지 끝 위치, 마법진 각도, 눈
몸·다리·머리·왼팔은 4프레임 모두 같게. Frame 4에서 Frame 1로 자연스럽게 이어지게.

### C. 일어나기 — 3프레임, 3열 × 1행
* Frame 1: 앉아 있기 Frame 1과 같은 자세(마법진 없음)
* Frame 2: 다리를 풀고 내려와 서는 중간 자세
* Frame 3: 기준 서 있기 자세 — 첨부한 서 있기 그림과 완전히 같게
```
