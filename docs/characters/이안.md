# 캐릭터 설정 — 이안 (목소리 팩: 차분한 남성)

- 상태: **이름·컨셉 일부 확정(사용자 11-24)**. 나머지는 나중에 `design-request-template.md` 형식으로 채운다.
- **컨셉(사용자 11-24)**: 남성, **30대**(중년까지는 아님), **미남은 아니지만 깔끔한 외모**, **존댓말**을 씀. 목소리(차분한 남성, 낮고 짧게 담백하게)와 맞게 차분하고 단정한 사람.
  - 말투 근거: 지금 녹음(예전 TTS 문장 기준 '비바체 연장하세요', '투아림 부스트 발동 직전입니다')도 존댓말 — 대사도 '-요/-습니다'로.
  - 정할 것: 직업·역할(판타지 세계관), 외형 특징 1~2개(한눈에 기억될 것), 의상, 성격 한 줄.
- 이름 후보였던 것: 시온·이안·루카·카엘 → **이안**.
- 목소리: 목소리 팩 `차분한 남성`(**예전 녹음 그대로 사용** — 사용자 11-24: 구 녹음본이어도 자연스러워 다시 녹음 안 함). 측정(11-24): 음높이 중앙 111Hz(하위10% 76~상위10% 186Hz), 평균 −16.0dB, 한 마디 평균 1.5초(가장 짧음), 7.3음절/초 → 낮고 짧게 담백하게 끊어 말함.
- 색(제안, 미확정): 남색·회색 + 금 — 깔끔한 30대 인상과 맞음.
- 캐릭터 탭: 그림이 생길 때까지 지금처럼 실루엣(남) + `???`.
