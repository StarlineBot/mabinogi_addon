(다른 캐릭터에 쓸 때는 첨부만 그 캐릭터 옆모습으로 — 프롬프트는 그대로)

```
SD 캐릭터 애니메이션 제작 공통 규칙
첨부한 원본 캐릭터 이미지를 Master Reference로 지정한다.
이번 작업은 새로운 캐릭터를 디자인하거나 기존 캐릭터를 재해석하는 작업이 아니다. 동일한 2D 게임 캐릭터의 프레임 단위 애니메이션 리소스를 제작하는 작업이다.

1. 캐릭터 외형 고정 (Character Identity Lock)
* 원본 캐릭터의 얼굴 형태, 눈, 코, 입, 귀를 유지한다.
* 머리카락의 형태, 길이, 색상, 세부 디테일을 유지한다.
* 원본의 등신과 머리, 몸통, 팔다리 비율을 유지한다.
* 의상, 장신구, 신발의 디자인과 색상을 변경하지 않는다.
* 새로운 디테일을 임의로 추가하거나 기존 디테일을 제거하지 않는다.

2. 그림체 고정 (Art Style Lock)
* 원본의 외곽선 굵기와 색상을 유지한다.
* 원본의 색상 팔레트와 채색 방식을 유지한다.
* 명암 단계, 그림자 색상, 광원 방향을 유지한다.
* 디테일 수준을 높이거나 낮추지 않는다.
* 캐릭터를 미화하거나 새로운 그림체로 재해석하지 않는다.

3. 위치 및 카메라 고정 (Spatial Lock)
* 모든 프레임의 캔버스 크기를 동일하게 유지한다.
* 카메라 각도, 시점, 원근감, 확대 비율을 고정한다.
* 캐릭터의 기본 신체 크기를 동일하게 유지한다. 모든 프레임에서 키와 머리 크기는 첨부 원본과 같게 한다.
* 모든 프레임은 동일한 중심축과 기준 좌표를 사용한다.
* 동작에 필요한 이동 외에는 캐릭터 위치를 변경하지 않는다.
* 캐릭터의 어떠한 부분도 캔버스 밖으로 잘리지 않도록 한다.

4. 애니메이션 규칙 (Animation Rules)
* 모든 프레임은 동일한 캐릭터가 연속적으로 움직이는 장면이어야 한다.
* 각각의 프레임을 독립적인 일러스트처럼 제작하지 않는다.
* 명시적으로 요청한 움직임만 변경한다.
* 움직이지 않는 부위는 가능한 한 원본 픽셀을 유지한다.
* 이전 프레임과 다음 프레임 사이에 외형이나 색상이 갑자기 변하지 않도록 한다.
* 루프 애니메이션은 마지막 프레임에서 첫 프레임으로 자연스럽게 연결되어야 한다.

5. 출력 규칙
* 배경은 실제 알파 채널을 가진 투명 배경으로 제작한다.
* 배경 장식, 바닥 그림자, 텍스트, 프레임 번호, 워터마크를 넣지 않는다.
* 프레임별로 캐릭터를 확대하거나 축소하지 않는다.
* 스프라이트 시트의 모든 셀은 동일한 크기와 여백을 사용한다.

6. 우선순위
캐릭터 외형 일관성 > 프레임 간 연속성 > 위치 및 크기 일관성 > 동작의 자연스러움 > 이미지의 미적 완성도
움직임을 개선하기 위해 캐릭터 디자인을 임의로 수정하지 않는다.
이번 작업에서 별도로 명시한 변경 사항 외에는 원본을 최대한 보존한다.


이번 애니메이션 제작 요청
애니메이션 이름: Walk
프레임 수: 8
배치: 4열 × 2행 스프라이트 시트
반복 여부: 무한 루프
원본 캐릭터의 제자리 걷기 애니메이션을 제작한다.

* Frame 01: 왼발이 앞으로 나와 지면에 닿는 자세
* Frame 02: 왼발에 체중이 실리는 자세
* Frame 03: 오른발이 왼발을 통과하는 자세
* Frame 04: 오른발이 앞으로 이동하는 자세
* Frame 05: 오른발이 앞으로 나와 지면에 닿는 자세
* Frame 06: 오른발에 체중이 실리는 자세
* Frame 07: 왼발이 오른발을 통과하는 자세
* Frame 08: 왼발이 앞으로 이동하며 첫 프레임으로 연결되는 자세

팔은 다리 움직임과 반대 방향으로 자연스럽게 움직인다.
얼굴과 머리의 크기, 신체 비율, 의상 디테일은 모든 프레임에서 동일하게 유지한다.
캐릭터가 캔버스 안에서 실제로 전진하지 않도록 하며, 중심축과 지면 기준선을 고정한다.
동작에 필요한 팔다리 움직임과 미세한 상하 움직임만 허용한다.

추가 조건
* 캐릭터는 첨부 원본처럼 오른쪽을 향한 옆모습이다. 정면이나 다른 각도로 바꾸지 않는다.
* 두 다리는 같은 색, 같은 명암, 같은 모양으로 그린다. 왼발과 오른발을 색이나 어둡기로 구별하지 않는다.
* 모든 프레임에 팔을 두 개 다 그린다. 한 팔이 앞으로 가면 다른 팔은 뒤로 가고, 몸 뒤쪽 팔은 일부가 몸에 가려져도 된다. 소매와 손은 어깨에서 자연스럽게 이어진다.
* 8개 프레임은 모두 서로 다른 자세다. 같은 자세를 두 번 그리지 않고, 이웃한 프레임끼리는 조금씩만 바뀌어 부드럽게 이어진다.
* 발이 지면에 닿는 프레임에서는 모든 프레임의 발바닥 높이를 같은 기준선에 맞춘다.
```


## 아리아 다시 시도용 (사용자 11-26 — 8장 시험이 '5~8번이 1~4번과 같은 발', '앞을 보며 옆으로 미끄러짐')
첨부 **한 장만**: `아리아/SD/아리아_옆모습_기준.png` → 저장 `아리아/SD/아리아_걷기_8장시험2.png` — **새 대화**. 위 공통 규칙 전문 + 아래 '이번 애니메이션 제작 요청'으로 바꿔 붙이기.

```
이번 애니메이션 제작 요청
애니메이션 이름: Walk
프레임 수: 8
배치: 4열 × 2행 스프라이트 시트
반복 여부: 무한 루프
원본 캐릭터의 제자리 걷기 애니메이션을 제작한다.

방향
* 첨부 원본처럼 오른쪽을 향한 옆모습으로 걷는다. 앞쪽(보는 사람 쪽)이나 비스듬한 방향으로 돌리지 않는다.

다리 — 1~4번과 5~8번은 서로 반대 발
* Frame 01: 보는 사람 쪽 다리가 앞으로 나와 부츠 뒤꿈치가 바닥에 닿음, 먼 쪽 다리는 뒤
* Frame 02: 보는 사람 쪽 다리에 체중, 먼 쪽 부츠가 뒤에서 들림
* Frame 03: 먼 쪽 다리가 보는 사람 쪽 다리 옆을 지나감
* Frame 04: 먼 쪽 다리가 앞으로 뻗음
* Frame 05: 먼 쪽 다리가 앞으로 나와 부츠 뒤꿈치가 바닥에 닿음, 보는 사람 쪽 다리는 뒤 (01과 반대)
* Frame 06: 먼 쪽 다리에 체중, 보는 사람 쪽 부츠가 뒤에서 들림
* Frame 07: 보는 사람 쪽 다리가 먼 쪽 다리 옆을 지나감
* Frame 08: 보는 사람 쪽 다리가 앞으로 뻗으며 01로 이어짐
* 5~8번을 1~4번과 같은 그림으로 그리지 않는다. 4장마다 앞에 나오는 부츠가 바뀐다.

팔 — 8장 동안 앞뒤로 딱 한 번 왕복
* 보는 사람 쪽 팔의 손: 01 가장 앞 / 02 앞 / 03 몸 옆 / 04 뒤 / 05 가장 뒤 / 06 뒤 / 07 몸 옆 / 08 앞
* 이웃한 프레임끼리 손이 조금씩만 움직이고, 중간에 방향을 바꿔 되돌아가지 않는다. 08에서 01로 '앞 → 가장 앞'으로 조금만 이동한다.
* 먼 쪽 팔은 늘 반대 방향. 모든 프레임에 팔을 두 개 다 그린다(먼 쪽 팔은 몸 뒤라 소매 끝·손만 보여도 됨). 보는 사람 쪽 팔은 주황 리본·머리카락보다 앞에 그린다.

그 밖
* 두 다리는 같은 색·같은 명암. 치마 밑단은 다리 따라 살짝 흔들리고, 03·07에서 몸이 아주 살짝 위로.
* 캐릭터가 캔버스 안에서 전진하지 않도록 중심축과 지면 기준선을 고정한다.
* 배경은 진짜 투명(알파 채널), 흰색·체크무늬로 칠하지 않는다.
```
