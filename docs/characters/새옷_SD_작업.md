# 새 옷 SD — 한 번에 작업하기 (2026-11-25)

새 옷 8벌의 SD를 이 문서 하나로 끝까지 한다. 캐릭터별 GPT 대화에서 위에서부터 차례로. 근거·검토는 `의상_요청문.md`, 옷 그림은 `assets/<이름>/의상/<옷>/`.

## 순서 (옷 1벌마다)
1. **기준 서 있기** — 아래 'A. 기준 서 있기' 요청문 + 첨부 2장 → 저장 `의상/<옷>/SD/`에 원래 서 있기 시트 이름 그대로 → 올리고 기획에 알림(비율·색 측정, 통과하면 2로).
2. **나머지 시트 전부** — 'B. 공통 요청문'을 **매번 그대로** 붙여 넣고, 첨부만 바꿈: ① 체크리스트의 원래 시트 ② 1에서 만든 새 옷 서 있기. 저장은 `의상/<옷>/SD/`에 **원래 파일 이름 그대로**(앱이 같은 이름으로 찾음).
3. 다 올리면 기획이 한꺼번에 측정 → DEV.

- 경로는 모두 `docs/characters/assets/` 아래. 소품(다래 양 인형·아리아 밀짚모자·레나 마법서)은 SD에서 빼고 상반신 카드에만(기획 제안 — 바꾸려면 알려 주기).
- 시트 수(옷 1벌, 기준 서 있기 포함): 다래 17 · 아리아 20 · 레나 14 · 이안 16 — 8벌 합계 134장. 호감도 100 모션은 정해지면 추가. 한 벌씩 끝내고 올려도 됨(올린 옷부터 측정).
