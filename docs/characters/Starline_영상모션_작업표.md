# Starline 영상 모션 작업표 (2026-11-27 — 시험판)

GPT·Gemini 이미지로 프레임 시트를 그리면 장마다 따로 그려져 톤·머리 결·자세가 흔들림(11-26~27 며칠 반려).
**영상(Gemini 애니메이션)은 첫 장면을 이어 그려서 장끼리 흔들리지 않음** — 걷기 2차로 확인(머리 흔들림 1.8%, 다리 번갈아 정상,
시작 그림↔영상 머리 ΔE 1.5). 그래서 Starline 전 동작을 영상으로 다시 만든다. 이 문서는 시험 뒤 고친다.

## 원칙
- **영상 하나 = 동작 하나.** Gemini 결과가 3초(0.1초 × 30장)라 한 동작만 들어감. 여러 동작을 한 영상에 넣지 않음.
- **시작 그림은 동작끼리 같은 한 장**을 씀(서 있기에서 시작하는 동작은 모두 0단계 서 있기). 첨부는 그 한 장만 — 여러 그림이 든 시트(마스터 레퍼런스)를 첨부하면 첫 장면이 못 돼 다른 캐릭터가 나옴(11-27 확인).
- 배경은 초록 단색(시작 그림이 이미 초록). 요청문은 짧게.
- 받을 때 **다운로드 버튼으로 원본 파일**(GIF/mp4). 채팅에 붙이면 한 장짜리 그림이 됨.
- 올리는 곳: `docs/characters/assets/Starline/영상/`, 이름 `번호_동작.gif`(예: `1_대기불꽃.gif`). 시험은 `T1_대기불꽃.gif`처럼.
- 기획이 하는 일: 초록 빼기 → 한 바퀴/동작 구간 찾기 → 앱 장 수·시간에 맞춰 고르기 → 크기(서 있기 키 282) → 톤 확인(걷기 2차 기준) → GIF. 도구 `docs/characters/도구/Starline_새디자인/vw_key.py`·`vw_pick.py`.
- 판정은 기획이 숫자로 '통과' / '이것만 다시'로 짧게.

## 시험 — 여러 세션에서 같게 나오는가 (먼저 할 것)
- 중간 결과(11-27): 따로 만든 서 있기 영상 ↔ 걷기 2차 — 어두운·중간·머리 ΔE 2~5(같은 톤), 피부 13(얼굴 그늘 차이 — 동작마다 확인).
- 0단계 통과 그림 + 아래 **1 대기 불꽃** 요청문을 **새 채팅 3개**에 똑같이 넣어 3개 받음 → `T1_대기불꽃.gif`·`T2_…`·`T3_…`.
- 기획이 재는 것: 세 결과끼리 톤(머리·피부·어두운 부분 ΔE), 키·머리 크기, 끝 장 ↔ 시작 그림 겹침, 동작 길이.
- 판정: 세 개가 같은 범위면 → 나머지 동작은 한 번씩만 만들면 됨. 많이 다르면 → 동작마다 2~3개 받아 고르는 방식으로.

## 공통 요청문 (모든 동작 맨 앞에 붙임)
```
첨부 그림 속 캐릭터가 그대로, 제자리에서 아래 동작을 하는 짧은 애니메이션을 만들어줘.
- 카메라·캐릭터 위치·크기 고정, 화면 밖으로 움직이지 마
- 캐릭터 디자인·체형·옷·색·그림체·표정은 첨부 그대로, 배경은 초록 단색 그대로
- 동작은 차분하게, 몸이 통통 튀지 않게
- 마지막엔 처음 자세로 돌아와서 멈춰
```
