# 호감도 의상 — 컨셉과 요청문 (2026-11-24)

근거: `docs/character-pet-spec.md` 3-2절(호감도 2차 — 의상 2벌, 50·100 해금, Starline은 대사만).
의상은 **지금 옷과 다른 컨셉·보상감**, 여성 캐릭터는 100이 50보다 드러나는 쪽. 선: 어깨·팔·등이 드러나는 정도까지(속옷·나체·성적인 자세 없음).

## 의상 표

| 캐릭터 | 50 해금 | 100 해금 |
|---|---|---|
| 다래 | **프릴 잠옷 원피스 — 후드 없음**(사용자 11-24) | **하얀 오프숄더 프릴 원피스**(사용자 11-24) |
| 아리아 | **가벼운 티셔츠 차림**(사용자 11-24) | **가벼운 여름 드레스**(사용자 11-24) |
| 레나 | 연구실 차림 — 흰 셔츠·짧은 치마·안경(기획 제안, 사용자가 다래·이안만 바꿔 유지 11-24) | **팔이 드러나는 몸에 붙는 빨간 원피스 + 화려한 장식**(사용자 11-24) |
| 이안 | **넥타이 + 3버튼 조끼**(사용자 11-24) | **길드 고위 정복**(사용자 11-24) |

- 8벌 확정(11-24 — 레나 50만 기획 제안을 그대로 둔 것). 50·100 배치는 '덜 특별한 옷 → 50, 더 화려하거나 드러나는 옷 → 100' 기준으로 기획이 정함.
- 지금 옷의 상징물은 유지: 다래 뿔·헤일로·열쇠 펜던트, 아리아 주황 리본·흰 꽃 핀, 레나 검은 레이스 초커, 이안 손목시계.

## 만드는 순서 (의상 1벌마다)

새 캐릭터와 달리 **얼굴·머리·체형은 이미 있음** → 옷만 바꾸는 요청. 지금 그림을 첨부해 '옷만 바꿔'로 요청해야 비율·얼굴이 안 바뀜.

| 단계 | 첨부 | 만들 것 |
|---|---|---|
| 1. 전신 의상 컨셉 | `assets/<이름>/<이름>_상반신.png` (+ 레나는 `레나_컨셉.jpeg`, 다래는 `조용한여성_컨셉.webp`) | 새 옷을 입은 전신 1장 — 이후 모든 단계의 옷 기준 |
| 2. 카드 상반신 | 지금 상반신 + 1단계 전신 | 지금 상반신과 **같은 구도·크기·세로 비율(1199×1312 정도)**, 옷만 바꿈 |
| 3. SD 시트(약 12~22장) | **지금 SD 시트 그 동작 한 장** + 1단계 전신 | 첨부 시트와 **포즈·프레임 수·배치·크기 그대로**, 옷만 바꿈 → 앱이 지금 자르는 위치를 그대로 씀 |

받은 SD 시트는 지금처럼 서 있기 대비 머리·몸 비율(±5%)과 머리·피부색을 재고 넘긴다(`캐릭터_제작_순서.md`).

## 1단계 요청문 (공통 틀)

```
첨부한 그림의 캐릭터 [이름]에게 새 옷을 입힌 전신 캐릭터 컨셉 아트를 그려줘.

## 그대로 유지
- 얼굴(얼굴형·눈매·눈 색·표정), 머리 모양·머리색, 체형·신체 비율(6~7등신), 그림체·채색 톤은 첨부 그림과 같게
- [유지할 상징물]

## 바꿀 것 — 옷
[아래 캐릭터별 옷 설명]

## 규격
- 머리부터 발끝까지 보이는 전신, 정면 또는 약간 비스듬한 정면, 자연스럽게 선 자세
- 단색 중립 배경, 세로형 2:3, 디자인이 잘 보이는 부드러운 조명
- 선정적인 자세·과장된 신체 표현 없이
```

### 캐릭터별 옷 설명

**다래 100 — 하얀 오프숄더 프릴 원피스**
- 어깨가 드러나는 흰 오프숄더 원피스, 가슴선 위로 여러 겹 흰 프릴, 짧은 퍼프 소매(팔에 걸침)
- 치마는 무릎 정도 길이, 여러 겹 흰 프릴 페티코트, 밑단에 아주 연한 라벤더 리본 한 줄
- 흰 리본 초커 + 열쇠 펜던트(지금 펜던트 그대로), 흰 메리제인 구두
- 지금 검은 고딕 드레스와 반대 — '흑 → 백'. 뿔·헤일로는 그대로(헤일로 보석 푸른색 유지)
- 메인 흰색, 보조 아주 연한 라벤더, 포인트 은색(펜던트)

**다래 50 — 프릴 잠옷 원피스(후드 없음 — 머리를 가리지 않고 지금 드레스 실루엣에서 덜 바뀌게, 사용자 11-24)**
- 지금 드레스와 비슷한 길이·퍼짐의 무릎길이 잠옷 원피스, 검정 바탕에 연한 라벤더 프릴(목둘레·소매 끝·밑단), 긴 소매(손등까지 살짝 덮음)
- 머리에는 아무것도 쓰지 않음(뿔·헤일로·머리 그대로), 목에 지금 검은 리본 대신 연라벤더 리본 + 열쇠 펜던트
- 작은 흰 양 인형을 한 팔에 안음(SD에선 걷기·끌기 동작에서도 계속 안고 있음), 폭신한 검은 실내화

**아리아 50 — 가벼운 티셔츠 차림**
- 살짝 넉넉한 크림색 반팔 티셔츠(앞에 작은 주황 꽃 그림), 연두색 무릎길이 플레어 스커트 또는 연청 반바지
- 가벼운 흰 스니커즈, 허리에 지금 약초 주머니를 작은 크로스백으로 바꿔 멤
- 주황 리본·흰 꽃 핀 유지

**아리아 100 — 가벼운 여름 드레스**
- 어깨끈이 가는 흰·연한 살구색 여름 드레스(어깨·팔 드러남), 가슴 아래 주황 리본 허리끈, 종아리까지 오는 하늘하늘한 치마(작은 꽃무늬)
- 챙 넓은 밀짚모자(주황 리본 띠)는 손에 들거나 씀, 가는 끈 샌들
- 머리 한쪽으로 늘어뜨림·주황 리본·흰 꽃 핀 유지

**레나 50 — 연구실 차림**
- 흰 셔츠, 맨 위 단추 두 개 풀고 소매를 팔꿈치까지 걷음, 짙은 남색 짧은 플리츠 치마, 검은 니삭스·로퍼
- 가는 금테 안경, 검은 레이스 초커 유지, 한 손에 마법서

**레나 100 — 몸에 붙는 빨간 원피스 + 화려한 장식**
- 민소매(팔이 다 드러남) 몸에 붙는 진한 빨간 원피스, 무릎 위~무릎 길이, 한쪽 옆트임
- 화려한 금 장식: 가슴 아래·허리에 마법진 무늬 금 자수, 금 팔찌 양쪽, 드롭 귀걸이, 머리에 작은 금 장식 핀
- 검은 레이스 초커 유지(빨간 원피스와 대비), 검은 하이힐
- 메인 진한 빨강(눈 색과 맞춤), 포인트 금색, 머리 하늘·파랑 그대로

**이안 50 — 넥타이 + 3버튼 조끼**
- 재킷 벗은 모습: 흰 셔츠(소매 단정히), 남색 3버튼 조끼(단추 셋 다 채움), 짙은 남색 넥타이(작은 금 넥타이핀)
- 조끼와 같은 남색 슬랙스, 짙은 갈색 구두
- 손목시계·길드 배지(조끼 가슴에) 유지

**이안 100 — 길드 고위 정복(승진한 모습 — 지금 정장 컨셉의 격 올림, 사용자 11-24)**
- 무릎 위까지 오는 남색 긴 제복 코트(더블 금단추, 허리 벨트), 양어깨 금 견장, 오른쪽 가슴에서 어깨로 이어지는 금 장식줄
- 안에 흰 셔츠·남색 넥타이, 남색 슬랙스, 검은 긴 구두, 흰 장갑
- 왼쪽 가슴에 지금보다 큰 금색 길드 배지, 왼쪽 손목 손목시계(장갑 위로 보이게)
- 표정은 지금처럼 무표정, 자세는 반듯하게

## 3단계 SD 요청문 (공통 틀 — 동작마다 시트 한 장씩)

```
첫 번째 첨부 그림은 [이름]의 SD 스프라이트 시트, 두 번째는 같은 캐릭터의 새 옷 전신 그림이야.
첫 번째 시트를 그대로 다시 그리되 옷만 두 번째 그림의 옷으로 바꿔줘.

## 반드시 같게
- 프레임 수, 칸 배치(열·행), 각 프레임의 포즈·위치·크기
- 머리 크기, 어깨·허리·다리 길이(겹쳐 놓았을 때 같아야 함) — 일반적인 SD처럼 머리를 키우거나 몸을 줄이지 마
- 얼굴·표정·머리 모양·머리색([머리색 코드])·피부색
- 투명 배경, 그림자 없음

## 바꿀 것
- 옷과 신발만 두 번째 그림과 같게. 치마·소매·망토 같은 천은 첨부 시트의 움직임(걷기·끌기 등)에 맞게 자연스럽게
```

- 말하기 시트도 같은 방법(앱은 입만 바꿔 끼우므로 얼굴이 원본과 같아야 함).
- 시트가 많은 다래(18)·아리아(22)는 지금 앱이 쓰는 시트만 요청(캐릭터 문서의 시트 표 기준).
