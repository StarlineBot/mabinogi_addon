# 걷기 다시 그리기 — 다섯 캐릭터 + 착장 (2026-11-25)

사용자 11-25: '전 캐릭 걷기를 자세히 뜯어보면 어색해서 다 고쳐야 하니, **한 번에 배포**'(QA 전달). 0.57.0은 지금 후보 그대로(이안 걷기 v3 포함) 게시 → **걷기는 다래·아리아·레나·이안·Starline + 착장 펫(이안 넥타이 조끼·아리아 티셔츠 차림) 전부 묶어 다음 버전 하나로**.

## 왜 어색했나 (공통)
- 모두 '다리 벌림 ↔ 모음' 반걸음 반복 구조 — 자세히 보면 발이 어색(사용자: 레나·다래·Starline·아리아·이안 모두).
- **어색함을 처음 눈치채는 곳은 팔**(사용자 11-25) — 반걸음만 반복하면 팔이 한쪽으로 가다 튀어 돌아옴. 레나는 팔이 앞뒤로 움직여 전체는 덜 어색.
- GPT는 **왼쪽·오른쪽 다리를 구별해 그리지 못함**(이안 v4) → 다리는 구별이 필요 없는 반걸음 6자세 ×2.
- 가이드에 팔 선이 하나면 **팔을 하나만 그림**(이안 v6 '팔이 빠짐') → 가이드에 두 팔 모두.

## 방법 (이안 v7로 시험 중 — 통과하면 나머지 넷에 같은 틀)
- 12장 한 바퀴. 다리: 반걸음 6자세 ×2(초록 선 둘, 같은 색). 팔: 보는 쪽(주황)·먼 쪽(노랑) 두 팔이 늘 반대로 12장에 걸쳐 앞→뒤→앞.
- 캐릭터마다 가이드 = 그 캐릭터 지금 걷기 0번(크기 기준, 줄마다 맨 왼쪽) + 분홍 높이 선 + 빈 칸 12개에 다리·팔 선. 엉덩이·어깨 높이·다리 길이는 그 캐릭터 그림에서 잼(치마·로브는 다리 선이 치마 아래로).
- 요청문은 이안 v7과 같은 글에 캐릭터 이름·옷만 바꿈. **시트마다 새 대화.**
- 앱: 걷기 12장, 한 장 시간 반(걸음 박자 그대로) — DEV.

## 순서
1. **이안 v7**(기본 옷) → 기획 GIF(예전 ↔ 새, 앱 크기·앱 프레임 시간, 12→1 이음매) → 사용자 확인.
2. 통과하면 기획이 **다래·아리아·레나·Starline 가이드·요청문**을 한 번에 만듦(이 문서 아래 표에 추가).
3. 캐릭터마다: 사용자 생성 → 올림(원본 파일, 화면 캡처 말고) → 기획 측정 + GIF → 사용자 확인.
4. 착장: 기본 걷기 통과 뒤 **옷만 바꾸기**(첨부 ① 통과한 기본 걷기 ② 그 옷 `전체프레임_1.png` 결과) → GIF → 확인. 대상: 이안 넥타이 조끼, 아리아 티셔츠 차림(지금 있는 착장 펫). 다래·레나 새 옷은 아직 SD가 없어 걷기 통과 뒤 그 옷 전체 프레임 시트를 새 걷기로 다시 만들어 줌.
5. 전부 확인되면 한 번에 DEV → QA가 한 번에 확인·후보.

## 받을 때 점검 (기획 — 캐릭터마다)
- 다리: 반걸음 6자세가 선대로(접촉 → 내려앉음 → 지나감 → 뻗음), 1~6과 7~12가 같은지, **이웃 장끼리 다리 구역이 다른지**(같은 자세 연달아 없음 — 1−IoU 0.15 이상).
- 팔: **모든 장에 두 팔**, 늘 반대 방향, 1 가장 앞 → 7 가장 뒤 → 12에서 1로 부드럽게.
- 크기: 기준(지금 걷기 0번) 대비 키·머리(위 42%) 실루엣 ±5%, 바닥 선.
- 옷·색: 기준과 같음, 두 다리 같은 색.
- (QA 11-25) **반복 이음**: 6장째 → 1장째(그리고 12 → 1) 다리 구역 1−IoU 0.15 이상 — 6자세 끝에서 두 다리 위치가 처음과 뒤바뀐 상태로 끝나 1로 자연스럽게 이어지는지.
- (QA 11-25) **두 다리 명암 차이 없음**: 아래 40% 두 다리 평균 밝기 차가 작게 — 먼 쪽 다리를 어둡게 하면 반복할 때 같은 다리만 늘 뒤에 있어 '한쪽 다리만 끄는' 걸음이 됨. (이안 v3·v4 요청문의 '먼 쪽 다리 어둡게'는 이번 틀에서 쓰지 않음.)
- GIF: 예전 ↔ 새 나란히, 앱 크기·한 장 시간, 2바퀴 이상.
