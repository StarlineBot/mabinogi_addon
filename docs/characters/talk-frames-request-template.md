# 말하기 프레임 요청문 (템플릿, 2026-11-24)

사용 순서: ① 사용자의 '말하기 포즈 시안 3가지' 요청문으로 A/B/C안을 받음 → ② 하나 고른 뒤 아래 본문을 같은 대화에 보냄([ ] 칸만 채움).
앱 방식(명세 '말하기 모션' 제안, 사용자 11-24): 몸은 한 장 고정 + **입만 바꾸기**, 서 있기 ↔ 말하기 자세는 **사이 프레임 1장**으로 팔만 움직임. 그래서 프레임끼리 **머리·얼굴·몸 위치가 완전히 같아야** 함(입·눈·팔만 다름) — 그림 생성 도구가 프레임마다 몸을 새로 그리면 꿈틀거려 보임.

---

선택한 말하기 포즈는 [A안 / B안 / C안]이야. 이 포즈를 기준으로 데스크톱 펫 앱에서 사용할 말하기(Talk) 애니메이션 스프라이트 시트를 제작해줘.

앱에서는 몸은 한 장으로 고정하고 입과 눈만 바꿔서 말하는 모습을 만들고, 기본 대기 자세와 말하기 자세 사이는 팔만 움직이는 중간 프레임으로 이어서 재생할 거야.
그래서 프레임끼리 머리·얼굴·몸통·다리의 위치, 크기, 윤곽, 머리카락 모양이 픽셀 단위로 최대한 똑같아야 해. 아래에 적은 부분만 바꿔줘.

## 8프레임 구성 (4열 × 2행)

1행 — 자세 전환

* Frame 1: 기존 기본 대기 자세, 입 다묾(기존 서 있기 그림과 같은 자세)
* Frame 2: Frame 1과 Frame 3의 중간 — 팔(과 손)만 선택한 포즈 쪽으로 반쯤 움직인 자세, 입 다묾
* Frame 3: 선택한 말하기 포즈, 입 다묾 — 이 프레임이 말하기의 기준(말 끝 자세)
* Frame 4: Frame 3과 같은 포즈, 눈만 감음(눈 깜빡임용), 입 다묾

2행 — 입 모양 (모두 Frame 3과 같은 포즈, 입만 다름)

* Frame 5: 입을 조금 벌림
* Frame 6: 입을 크게 벌림('아' 모양)
* Frame 7: 입을 옆으로 벌림('이' 모양)
* Frame 8: 입을 동그랗게 오므림('오' 모양)

## 바꿔도 되는 부분과 안 되는 부분

* Frame 1 → 2 → 3: 팔·손 위치만 바뀜. 머리 위치·각도, 얼굴, 몸통, 다리, 발 위치는 세 프레임 모두 같게
  (선택한 포즈에 고개 기울임이 있다면 Frame 3~8에서만 같은 각도로 유지하고, Frame 2는 그 중간 각도)
* Frame 3 ~ 8: 입(Frame 5~8)과 눈(Frame 4)만 바뀜. 팔, 손, 머리, 몸, 머리카락, 의상 주름은 Frame 3과 완전히 같게
* 입 모양은 작은 펫 크기(키 약 190px)에서도 차이가 보이도록 또렷하게, 하지만 얼굴 형태가 바뀌지 않게
* 표정(눈썹·눈매·볼)은 선택한 포즈의 표정을 Frame 3~8에서 그대로 유지

## 캐릭터 디자인 유지

* 기존 SD 캐릭터의 얼굴, 헤어스타일, 의상, 장신구, 색상, 신체 비율, 외곽선 굵기, 채색 방식
* 기존 대기 및 걷기 애니메이션과 동일한 캐릭터 크기
* [캐릭터별 필수 요소: 예) 이안 — 남색 정장·넥타이 없음, 왼쪽 손목 금색 손목시계, 무표정에 가까운 절제된 표정]

## 스프라이트 시트 규격

* 총 8프레임, 4열 × 2행의 균일한 격자
* 왼쪽에서 오른쪽, 위에서 아래 순서로 배치
* 모든 프레임의 캔버스 크기 동일
* 모든 프레임의 바닥선 및 하단 중앙 기준점 동일, 발 위치 완전히 고정
* 머리부터 발끝까지 잘리지 않는 전신 이미지(든 손이 칸 밖으로 나가지 않게)
* 완전히 투명한 배경(옅은 색·반투명 막·얼룩 없이)
* 기존 애니메이션과 동일한 시점 및 방향

## 금지 사항

* 프레임마다 머리카락 모양, 윤곽선, 의상 주름을 새로 그리지 마
* 프레임마다 캐릭터 크기, 위치, 비율을 바꾸지 마
* 말풍선, 대사, 텍스트, 음표·땀·반짝임 등 이펙트, 외부 소품, 그림자, 프레임 번호, 격자선은 넣지 마

실제 데스크톱 애플리케이션에서 프레임 단위로 잘라 입·눈만 바꿔 끼우는 방식으로 쓸 이미지이므로, 프레임 간 일관성을 최우선으로 해줘.

## 사용자 형식(Enter 2 / Loop 6 / Exit 2)으로 쓸 때 — 11-24 이안 B안
사용자가 쓰는 요청문(Talk Enter 2·Loop 6·Exit 2, 시트 3장)에 아래만 끼워 넣는다(본문은 11-24 대화로 전달).
- '가장 중요한 조건 — 프레임 간 일관성' 절: 바뀌는 부분 외 머리·얼굴·몸·머리카락·윤곽 픽셀 단위로 같게.
- 프레임마다 '바뀌는 부분' 명시: Loop 2·3 = 입만, Loop 4 = 한쪽 손·고개 조금·눈썹·입, Loop 5 = 4와 1의 중간, Loop 6 = 1과 같은 자세 + 눈 깜빡임.
- 연결: Enter 2 = Loop 1 같은 그림, Exit 2 = 기존 Idle 같은 그림.
- 앱 재생(예정): Enter 1번 → Loop 1~3 입 반복(입만 바꾸기) → 강조 4·5는 한 문장에 한 번 정도 → Exit.
