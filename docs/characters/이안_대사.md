# 이안 대사 (2026-11-24 — 알파에 넣음, 데이터라 고치면 바로 반영)

- 형식·규칙은 `다래_대사.md`와 같음(한 상황 여러 줄 중 무작위·같은 줄 연속 금지, 한 줄 약 30자 안, 데이터 파일로 관리 — 앱 배포 없이 고칠 수 있음).
- 말투: **존댓말(-습니다/-요), 짧고 담백하게**, 감정 표현 적음, 일정·시간을 챙기는 길드 사무관. 혼잣말만 독백체('…군').
- 다래·아리아와 다른 상황: 졸지 않음(자다가 클릭 없음), 서 있기와 번갈아 **시계 보는 중 클릭**(아리아의 '머리 쓰다듬는 중 클릭' 자리), 떨어지면 두 발 착지(아파하지 않음).
