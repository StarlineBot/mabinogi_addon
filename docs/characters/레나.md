# 캐릭터 설정 — 레나 (목소리 팩: 화난 여성)

- 상태: **이름 확정, 컨셉 이미지·색 받음(사용자 11-24)**. 나머지 컨셉은 나중에 `design-request-template.md` 형식으로 채운다.
- 컨셉 이미지: `docs/characters/assets/레나/레나_컨셉.jpeg`(배경 있음 — 참고용). 보이는 것: 허리까지 오는 **은청색(창백한 하늘빛 은발) 생머리**, **붉은 눈**, 자신만만한 미소, **검은 드레스 + 금 장식**(금 초커 → 사용자가 검은 레이스 초커로 바꿈·가슴 금 장식), **붉은 테두리의 흰 망토**.
- **의상(사용자 11-24)**: **검은 오프숄더 드레스**(어깨가 드러나게), 목에 **검은 레이스 초커**(컨셉 그림의 금 초커 대신). **망토 없음(사용자 11-24)** — 흰 망토는 빼고 금 장식만 남김(진홍 포인트는 눈·드레스 장식으로). 체형: 성인 여성(20대), **가슴은 조금 크게**. 표정: **기본이 화난 얼굴**(사용자 11-24 — 찌푸린 눈썹·날카로운 눈매가 평소 얼굴).
- **머리(사용자 11-24)**: **허리 아래까지 오는 긴 장발**, **한쪽 옆머리만 귀 뒤로 넘김**(캐릭터의 오른쪽 — 아리아는 왼쪽을 넘겨서 반대로, 바꾸려면 알려 주기), 앞머리 **풀뱅**(이마를 덮는 일자 앞머리), 머리색은 **연한 하늘색보다 조금 더 진한 하늘색**(컨셉 그림의 창백한 은청보다 한 단계 진하게 — 대략 `#8DB4DC` 근처). 
- **성격(사용자 11-24)**: 기본적으로 늘 화가 나 있는 **화가 많은 츤데레** — 정석 츤데레(새침·수줍음)보다 불같은 쪽. 자존심이 세고 지는 걸 싫어하며, 말이 직설적이고 쉽게 욱함. 남에게 약한 모습·고마움을 들키는 걸 싫어해 더 화를 냄. 그래도 결국 챙겨 주고, 아주 가끔 진심이 새어 나옴(그러고는 또 화냄).
  - 참고로 든 기존 작품 캐릭터 이름은 성격 느낌만 빌림 — 요청문·문서에는 이름을 쓰지 않고, 외형·의상도 따라 하지 않는다.
- 한눈에 기억될 특징: **검은 레이스 초커 + 풀뱅**(사용자 11-24 — 초커가 있어 목에 더 넣지 않음). 화난 눈매가 풀뱅 아래로 보이는 얼굴이 레나의 인상.
- 말투: 녹음이 전부 화난 톤의 반말 → 말풍선은 한 톤 누그러뜨린 새침한 반말(`레나_대사.md`, 사용자 11-24 '적당히 고쳐').
- **색(사용자 11-24 — 이 그림의 색)**: 머리 하늘색(진하게, 11-24), 옷 검정 + 흰 망토, 포인트 **진홍(눈·망토 테두리) + 금**. 이름·말풍선 색 제안 진홍 `#C8323F`(미확정).
  - 겹침 검토: 다래(검정·흰 옷이지만 머리 크림, 눈 라벤더 — 레나는 은청 머리·붉은 눈이라 구분), 이안(남색 + 금 — 금 포인트만 같음), 아리아(주황 — 이전 제안의 '빨강·주황'에서 주황이 빠져 안 겹침), **시엘(은백·흰 + 하늘 — 밝은 머리·흰 옷이 비슷)** → 펫 크기에서 구분되게 레나는 **검은 드레스(몸통이 어두움)를 꼭 유지**, 시엘은 밝은 옷을 유지.
- 이름 후보였던 것: 루비·카렌·레나·홍아 → **레나**.
- 목소리: 목소리 팩 `화난 여성`(11-22 추가 녹음, 11개·파티 알림 없음 → 기본 녹음으로). 측정(11-24): 음높이 중앙 400Hz(다섯 팩 중 가장 높음, 하위10% 246~상위10% 500Hz), 평균 −18.9dB, 한 마디 평균 2.0초, 5.1음절/초 → 높고 또박또박 느리게, 앙칼지고 새침한 느낌.
