# Starline 새 디자인 그림 처리 순서 (11-27)

1. `옷_다시그림_자르기.py Starline 새디자인 4 '{}' no '{"1":6,"2":4,"3":5,"4":2,"5":3,"6":1}'` — 칸 자르기·앱 크기(IoU 자동 매칭이 2·3번 파일을 헷갈려 직접 지정). 출력 `의상/새디자인/다시_앱크기/`
2. `sl_tidy.py` — 사이 모션 10(앱에 기본 없음): 새 서 있기 배율 × 모션별 공통 머리 맞춤(0.962 / 0.955)
3. `lowlid.py 다시_앱크기/ 다시_앱크기/` — 어깨 털기(motion_tidy10a) 아래 눈가 진한 테두리 지움(사용자 11-27)
4. `sl_norm.py` — 받은 장마다 색이 조금씩 달라 걷기 장(파일 6) 기준으로 장 단위 색 맞춤 → `장색맞춤/`
5. `sl_final.py <이 폴더>` — 털색 아이보리(`sl_iv2.ivory2`: 분홍 계열 중 피부보다 덜 주황인 곳, 이·흰자·귀 안쪽 진분홍 제외) → `새디자인_앱크기/`(넘길 것) + 비교 그림·전체 동작 GIF
   - 시안 톤까지 맞추기는 피부가 붉어져서 뺌(털색만).
중간 폴더(`다시_앱크기`, `장색맞춤`)는 다시 만들 수 있어 커밋하지 않음.
