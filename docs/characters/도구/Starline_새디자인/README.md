# Starline 새 디자인 그림 처리 순서 (11-27)

1. `옷_다시그림_자르기.py Starline 새디자인 4 '{}' no '{"1":6,"2":4,"3":5,"4":2,"5":3,"6":1}'` — 칸 자르기·앱 크기(IoU 자동 매칭이 2·3번 파일을 헷갈려 직접 지정). 출력 `의상/새디자인/다시_앱크기/`
2. `sl_tidy2.py.txt` — 사이 모션 10은 모션마다 한 장에 다시 그린 것(`의상/새디자인/사이모션10/어깨금장_다시.png`·`소매팔찌_다시.png`, 3열×4행, 사용자 11-27)을 씀: 서 있기 키 배율 × 모션 공통 머리 맞춤(0.97 / 0.975)
   - (이전: 86칸 시트에 흩어진 칸을 `sl_tidy.py.txt`로 자르고 `lowlid.py.txt`로 어깨 털기 눈가를 지웠음 — 장마다 머리 결이 달라 자글자글해서 다시 그림. 새 그림은 눈가 선이 없어 `lowlid.py.txt` 안 씀)
4. `sl_norm.py.txt` — 받은 장마다(사이 모션 두 장은 각각 한 묶음). 색(a·b)만 띠별 평균 맞춤, 밝기(L)는 띠별 차이 평균만큼 한 번에 옮김(띠별 L·표준편차까지 맞추면 머리 잔결이 10% 진해짐 — 사용자 11-27) 색이 조금씩 달라 걷기 장(파일 6) 기준으로 장 단위 색 맞춤 → `장색맞춤/`
5. `sl_final.py.txt <이 폴더>` — 털색 아이보리(`sl_iv4.ivory2`): 색을 영역별로 고르게 편 뒤(mean shift) 분홍(머리)/주황(피부) 각도로 가르고(밝은 곳 L>190은 머리 쪽으로 넓게) 마스크를 중앙값으로 다듬음. 귀 안쪽 진분홍 제외 → `새디자인_앱크기/`(넘길 것) + 비교 그림·전체 동작 GIF.
   - 이전판(사용자 11-27 지적): v2 `sl_iv2` 픽셀마다 → 머리가 자글자글, v3 `sl_iv3` 장마다 표본 통계 → 몇 장(장난 불꽃 마지막·걷기 중간 등)에서 얼굴·손까지 머리로 잡혀 피부가 회색. v4는 피부 픽셀 96~99% 그대로, 장끼리 피부 평균 L ±2·a ±1.
   - 시안 톤까지 맞추기는 피부가 붉어져서 뺌(털색만).
중간 폴더(`다시_앱크기`, `장색맞춤`)는 다시 만들 수 있어 커밋하지 않음.

## GIF 만들 때(사용자 11-27 'PNG는 괜찮은데 GIF가 자글자글')
- GIF는 256색까지라 장마다 따로 색을 고르면(이전 방식) 안 움직이는 칸도 장마다 색이 바뀌어 반짝임(서 있기 칸 장끼리 차 1.26 → 0). 지금은 모든 장이 한 팔레트를 쓰고 점찍기(디더링) 없음(`sl_final.py.txt`의 `gif_frames`, `cmp_gif.py.txt`). 앱은 PNG를 쓰므로 이 문제 없음.
