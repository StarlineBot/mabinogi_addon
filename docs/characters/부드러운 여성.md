# 캐릭터 설정 — 부드러운 여성 (진행 중)

- 상태: **컨셉 정하는 중**(11-24). 정해지면 `design-request-template.md` 형식으로 이 문서를 채우고 이름이 정해지면 `docs/characters/<이름>.md`로 바꾼다.
- 목소리: 목소리 팩 `부드러운 여성`(11-22 새 녹음). 측정(11-24): 음높이 중앙 271Hz(다섯 팩 중 두 번째로 높음), 평균 −20dB, 6.4음절/초 → 높고 상냥하게 보통 속도.

## 정해진 것
- **색(사용자 결정 11-24 — B안 '햇살')**: 머리 밝은 금발·살구빛, 옷 크림·연두, 포인트(이름·말풍선 테두리) 주황 `#F5A25D`. 다래(검정·크림 + 라벤더, 고딕)와 반대로 밝고 따뜻한 아침 분위기.

1. 컨셉 이미지(있으면) 또는 방향
