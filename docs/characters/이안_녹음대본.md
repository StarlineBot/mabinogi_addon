# 이안 목소리 다시 녹음 대본 (2026-11-25, 사용자 '이안 대사 정리 — 녹음 새로 하게')

왜: 지금 이안 팩 `차분한 남성/`은 Google TTS(`ko-KR-Chirp3-HD-Algieba`)로 만든 파일 — 자연스럽지만 톤을 마음대로 조절하기 어려워 **새 목소리로 팩 전체를 다시 녹음**(사용자 11-25). 이 문서 하나로 녹음 → 넣기까지 끝나게 정리.

## 목소리 방향 (녹음 도구의 목소리·스타일 고를 때)
- **30대 초중반 남성, 낮고 차분한 목소리.** 모험가 길드 사무관 — 말수는 적지만 할 일은 정확히 챙기는 사람.
- **담백하게, 감정은 아주 조금만.** 문장 끝은 올리지 않고 내려서 끝냄(질문만 살짝 올림). 웃음·과장 없음.
- 빠르기: 보통보다 아주 조금 빠르게(지금 녹음 7.3음절/초) — 끊어 말하는 보고체. 한 마디 1.5~3초.
- `…`는 0.3~0.5초 쉼(망설임·속마음). 쉼표는 짧은 쉼.
- 호감도 대사(구간 25→100)로 갈수록 아주 조금씩 부드럽게 — 100만 가장 따뜻하게.
- 참고: 지금 녹음 음높이 중앙 111Hz(낮은 편) — 비슷하거나 조금 높아도 됨.

## 파일 형식·넣는 곳
- mp3, 44.1kHz·128kbps(다른 팩과 같게), 앞뒤 무음은 0.1초 안으로 자르기, 음량은 알림 녹음끼리 비슷하게.
- **새 팩 폴더에 넣기**: `src/mabinogi_addon/assets/sounds/담백한 남성/`(이름은 임시 — 바꾸려면 알려 주기). **A·B는 팩 폴더 바로 아래, C는 그 안 `대사/` 폴더**.
- **지금 `차분한 남성/`(TTS)은 그대로 남김**(사용자 11-25 — 다른 캐릭터 목소리 후보). 단 그 팩의 `인사.mp3`는 '이안입니다'라서, 다른 캐릭터에 쓸 때 인사만 새로 만들어야 함.
- 새 팩 파일이 들어오면 DEV가 이안의 목소리 팩을 `차분한 남성` → 새 팩으로 바꿈(기획이 넘김). 그 전까지 이안은 지금 TTS 그대로.
- 파일 이름은 표 그대로(띄어쓰기 포함) — 앱이 이 이름으로 찾음. 새 팩에 없는 파일은 소리 없이 말풍선만 → 31개를 다 넣은 뒤에 팩을 바꾸는 게 좋음.
- `파티 알림.mp3`는 녹음 안 함(파티 알림은 모든 팩이 기본 소리 — 앱 규칙).
- 다 넣고 푸시하면 기획이 길이·음량·무음을 재서 DEV/QA로 넘김.
