# 새 옷 SD — 전체 프레임 한 번에 (2026-11-25, 사용자 '문제가 전혀 없는 캐릭터는 모든 프레임을 하나의 그림으로')

대상: **문제없던 캐릭터 — 이안·아리아**(사용자 11-25 '이안·아리아는 아무 문제 없음'). 다래는 시트별(`새옷_SD_작업.md` + 가이드), 레나도 문제없다면 같은 방식으로 시트 만들어 줄 수 있음.

## 시트
- `assets/<이름>/의상/전체프레임/전체프레임_1~5.png` — 앱이 지금 쓰는 **모든 프레임**(서 있기·걷기·끌기·착지·쓰다듬기·구석·말하기 등, 기본 동작 추가·호감도 25·75 모션 포함)을 **앱과 같은 크기**로 칸마다 하나씩(4×4 = 16칸, 파란 칸 테두리, 발 밑을 칸 아래에 맞춤). 이안 66프레임, 아리아 79프레임 → 각 5장.
- 왜 5장으로 나눴나: GPT 그림은 한 장이 최대 약 1024×1536이라 프레임을 한 장에 다 넣으면 칸 하나가 너무 작아져 뭉개짐(앱은 프레임 키 285px로 씀). 16칸이면 칸 하나가 약 256×384로 충분.
- `칸_목록.json`: 몇 번째 장 몇 번째 칸이 어떤 프레임인지(DEV가 받은 그림을 다시 자를 때 씀).

## 쓰는 법 (옷 1벌마다 — 같은 요청문을 5번, 첨부만 1~5장 바꿔 가며)
1. 첨부: ① `전체프레임_N.png` ② 그 옷 `의상/<옷>/전신.png`(옷 디자인 참고)
2. 아래 그 옷의 요청문을 그대로 붙여 넣기
3. 결과를 `의상/<옷>/전체프레임_N.png`로 저장 → 5장 다 되면 올리고 알려 주면 기획이 칸별로 원본과 비율·색을 재서 DEV로
- 결과 칸 중 몇 개만 이상하면 그 칸만 시트별 방식(`새옷_SD_작업.md`의 B 공통 요청문 + 가이드)으로 다시 그림

## 다시 그릴 때는 가이드 (사용자 11-25 규칙)
- 문제가 있어 **다시 그리는** 시트는 항상 가이드 그림(기준 서 있기 + 높이 선) 위에 그리게 함 — 숫자('20% 줄여')로 지시하면 과하게 바뀌어 다른 캐릭터가 됨. 만드는 법·예시: `캐릭터_제작_순서.md` '다시 그릴 때 가이드'.

## 16칸이 계속 실패할 때 — 나눈 시트 (사용자 11-25 '이안 2장이 계속 다르게 그려짐')

왜 2장만 어렵나: 1장은 거의 다 **서 있는 자세**(서 있기·시계·걷기·끌기)라 옷만 바꾸기 쉬움. 2장은 **떨어지기(공중)·착지·웅크리기·앉기**처럼 팔다리가 접혀 조끼·넥타이가 가려지는 자세와, **거의 똑같은 쓰다듬기 6칸**이 한 장에 섞여 있음 → GPT가 자세를 '알아서' 고치거나 칸끼리 맞춰 버림. 또 같은 대화에서 1장을 그린 직후라 **1장 그림을 다시 끌어다 쓰는** 일이 잦음.

바꾼 것:
1. **동작별로 나눈 작은 시트**(칸 8개 중 5~7칸): `이안/의상/전체프레임/나눔_2-1_떨어지기_착지.png`, `나눔_2-2_쓰다듬기.png`, `나눔_2-3_웅크리기_앉기.png`. 칸 대응은 `나눔_칸_목록.json`.
2. 각 시트 **첫 칸(초록 테두리) = 통과한 1장의 '새 옷 SD 서 있기'** — GPT가 같은 그림 안에서 '정답 옷·크기'를 보고 따라 그림(다시 그리기 가이드와 같은 원리). 초록 칸은 결과에서 버림.
3. 옷 참고 첨부는 일반 비율 전신 대신 **통과한 1장 결과**(이미 SD로 옷이 정리된 그림) — 전신을 붙이면 키·등신이 따라감.
4. **시트마다 새 대화**에서 요청(앞 결과를 다시 끌어다 쓰지 않게). 이안 세션 안에서 하려면 요청 첫 줄에 '앞에서 만든 그림은 무시'.
   - 사용자 11-25: 같은 대화에서 2-1 다음 2-2를 요청하니 **계속 2-1 결과만 나옴** — 같은 대화에서는 GPT가 '방금 만든 그림을 고치는' 편집으로 받아들여 첨부를 무시함. 문장으로는 잘 안 막힘 → **2-2·2-3은 반드시 새 대화**(GPT 프로젝트를 쓰면 같은 프로젝트 안의 새 채팅도 됨).
