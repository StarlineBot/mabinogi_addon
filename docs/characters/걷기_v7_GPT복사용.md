# 걷기 다시 그리기 — GPT 복사용 (사용자 11-26 '10장짜리가 낫다 — 이렇게 다른 캐릭터 걷기 다시 만들 수 있게')

**방법 = 이안 v7**: 가이드(칸마다 초록 다리 선 둘 + 주황·노랑 두 팔 선) 12장을 그린 뒤, 기획이 GIF로 **잘 이어지는 장만 골라 배치**(이안은 12장 중 10장 1·2·3·4·6·8·9·10·11·12, 한 장 0.108초 = 한 바퀴 1.08초). 사용자 GPT 정리 프롬프트(가이드 없이 8장)로도 시험했지만 3바퀴 GIF 비교에서 **10장이 더 나음**(사용자 11-26).

## 쓰는 법 (캐릭터마다)
1. **새 대화**에서 아래 그 캐릭터 블록의 첨부 2장 + 요청문 그대로 붙여 넣기.
2. 결과를 표시된 이름으로 저장소에 올림(원본 파일 — 화면 캡처 말고).
3. 기획: 칸마다 키·머리(±5%)·두 다리 명암·두 팔·이웃 장 차이 측정 → **고른 배치 GIF(3바퀴, 제자리·이동)** 를 보여 줌 → 사용자 확인.
4. 다섯 캐릭터 + 착장이 다 모이면 한 번에 DEV(다음 버전).
- 순서는 자유. 결과가 이상한 칸이 있으면 그 칸만 다시 그리기 요청문을 따로 만들어 줌.
- **가이드 때문에 멋대로 나오면(대안)**: 이안 시험처럼 옆모습 한 장만 첨부하는 `걷기_시험_프롬프트_GPT복사용.md`로 — 첨부 `<이름>/SD/<이름>_옆모습_기준.png`(앱 걷기 0번을 키 480으로 키운 것, 11-26 만들어 둠). 그 결과도 같은 방식(측정 → 골라 배치 GIF)으로 비교.
- 처음 한 캐릭터는 가이드로 해 보고, 결과를 보고 나머지를 같은 방식으로 갈지 정하면 헛수고가 적음.
