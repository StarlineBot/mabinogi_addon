# 호감도 의상 — GPT 붙여넣기용 (2026-11-24)

> **새 옷 SD는 `새옷_SD_작업.md` 하나로 한 번에**(사용자 11-25) — 옷마다 기준 서 있기 + 공통 요청문 + 체크리스트. 아래 ③-0·③은 같은 내용.

캐릭터별 GPT 대화(처음 그 캐릭터를 만든 대화)에 순서대로 붙여 넣는다. 설명·근거는 `의상_요청문.md`.

- **순서(옷 1벌마다)**: **①② 전신 + 상반신 한 번에(추천, 사용자 11-25)** → **③-0 새 옷 SD 서 있기 한 장 → 기획 측정** → ③ 나머지 SD 시트(동작마다 한 장씩). 따로 할 땐 ① 전신 → ② 상반신, 또는 ②-A 상반신만 먼저.
- **비율 문제(사용자 11-25 — 다래·아리아 전신이 자꾸 머리가 크고 몸이 작아짐)**: ①②와 ①에 캐릭터별 **나이·등신**을 넣음. 그래도 머리가 크게 나오면 '머리를 지금보다 작게, 다리를 더 길게' 한 줄을 더해 다시 요청.
- **상반신만 먼저 할 때**(사용자 11-25): 옷마다 **②-A**를 쓰면 전신 없이 바로 상반신. 나중에 ①전신을 만들 때는 **②-A로 만든 새 상반신도 같이 첨부**하고 ①에 '윗옷은 첨부한 새 상반신과 똑같이' 한 줄을 더해 붙여 넣기 — 상반신과 전신의 옷이 어긋나지 않게(SD는 전신을 기준으로 그림).
- **첨부**: 대화가 길면 GPT가 처음 그림을 정확히 기억하지 못할 수 있음 → ①에는 처음 전신(또는 상반신) 그림, ②에는 처음 상반신 그림, ③에는 **그 동작의 처음 SD 시트**를 같이 첨부하면 가장 정확함(문장은 첨부가 있든 없든 그대로 써도 됨).
- 다 만든 그림은 `docs/characters/assets/<이름>/의상/<옷 이름>/`에 올리면 기획이 원본과 비율·색을 재서 알려 줌.
