# 아리아 대사 (초안 2026-11-24 — 알림 말풍선은 녹음 받아쓰기 반영, 상황별 대사는 사용자 확인 전)

- 말풍선 글자 대사. 형식·규칙은 `다래_대사.md`와 같음(한 상황 여러 줄 중 무작위·같은 줄 연속 금지, 한 줄은 말풍선 두 줄 약 30자 안, 데이터 파일로 관리, 이 초안은 처음(0구간) 대사).
- 말투: **다정한 언니** — 밝고 상냥한 반말, 먼저 챙기고 걱정해 줌. 다래의 '…'(말끝 흐림) 대신 **'~'·'!'와 '헤헤'**로 구분. 존댓말로 바꾸려면 알려 주기.
- 앉아 있을 때 졸지 않음(머리 안고 앉아 웃는 캐릭터) — 다래의 '자다가 클릭' 대신 **'머리 쓰다듬는 중 클릭'**.

## 클릭
**서 있을 때 클릭(놀람)**
- 앗, 깜짝이야! 불렀어?
- 응? 무슨 일 있어?

- 어머, 간지러워!
- 뭐 도와줄 거 있어?

**머리 쓰다듬는 중 클릭(서서)**

**앉아 있을 때 클릭**
- 응, 여기서 잘 보고 있어~
- 사냥은 순조로워?
- 조금 더 앉아 있을게. 힘내!
- 다치면 바로 말해, 알았지?
