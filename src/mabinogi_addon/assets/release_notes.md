## v0.4.3

**2색 체력바 판독 + 버프 알림 중복을 잡았어요.**

- **보스 체력바가 2색(파랑+초록, 금+빨강 등)일 때 HP%를 잘못 읽던 문제**를 고쳤어요. 이제 바 색이 몇 개든 숫자만 정확히 읽어요. (포인셰·레넨 회한 등)
- **버프 알림이 "연장"될 때 또 울리던 문제**를 고쳤어요. 비바체·행진처럼 시간이 다시 차오르는 버프에서 30초·10초 알림이 반복해서 울리던 걸 잡았어요 — 한 버프당 **한 번씩만**, 완전히 사라졌다 새로 걸릴 때만 다시 울려요.

## v0.4.2

**보스 패턴 경고 타이밍·오작동을 바로잡았어요.**

- **경고가 임계값에 정확히 떠요.** 예: 80% 패턴이면 **85%(준비)**와 **81%(임박)**에 떠요. 예전엔 한 칸 늦게(84%/80%) 떴어요. 문구도 "준비/임박"으로 구분해요.
- **보스가 없거나 바가 숨었을 땐 경고가 안 떠요.** 보스가 사라지거나 패턴 중 체력바가 숨었을 때 화면을 숫자로 잘못 읽어 **엉뚱한 경고가 뜨던 문제**를 고쳤어요(패턴 동안엔 직전 값을 유지).
- **투아림 숫자 판독을 개선**했어요. 96처럼 두 자리에서 한 자리를 놓쳐 알림을 건너뛰던 문제가 줄어요.
- **버프 만료 직전 깜빡여 알림이 0초쯤 또 울리던 문제**를 고쳤어요.

## v0.4.1

## v0.3.29

**보스 패턴 미리 알림이 추가됐어요. (BETA · 디스코드 로그인 전용)**

보스 체력바를 읽어서, 패턴이 나오는 체력%에 다가오면 화면 가운데 크게 미리 알려줘요. WoW의 DBM처럼요. 각 구간의 5% 전(예고)·1% 전(진입) 두 번 알립니다.

> BETA 기능이라 **설정 탭에서 디스코드 로그인한 분만** 쓸 수 있어요. "보스 패턴 알림 [BETA]" 탭에서 켜세요.

- 지원 보스: **고목의 페타크 / 레넨의 미이르 / 레넨의 미이르 : 회한 / 엇갈린 운명의 포인셰 / 펠롬.** (새 보스는 이름·패턴을 추가해 늘려갈 예정)
- 보스 영역은 **기본 위치로 이미 잡혀 있어요**(2560×1440 기준). 해상도가 다르거나 안 맞으면 "영역 수정"으로 보스 체력바에 맞추면 돼요.
- 켜기 전에 탭에서 **"식별된 보스 / 현재 HP%"가 실제와 맞는지** 먼저 눈으로 확인하세요.
- 체력바 색이 변해도(초록·노랑·빨강 등) HP%를 읽을 수 있게 다듬었어요.
